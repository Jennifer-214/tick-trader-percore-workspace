# `.E.1` Foundation — D-class decomposition, BY-SPINE lens

## 0. The thesis under test

D-214 rejected the single-keystone framing as over-lumped → **THREE ORTHOGONAL SPINES**:

- **SPINE-1 fill-completeness** — the fill path: `FillEvent<F>` normalization, A16 intra-session partial-accumulate (weighted-avg re-entry + keep-slot-open), Class 46 SELL-side partial-reduce (`handle_sell_fill:1234` whole-close bug), A20 warm-tail replay, A21 venue-net qty leg, the single-owner-`disk_file` event-log. Governing spec: `fill-path-completeness-and-normalization-discipline.md` (RBP Class 46).
- **SPINE-2 cross-thread coherence** — the torn-read CLASS (9 sites, 3 LIVE capital-control): the GLOBAL aggregator single-writer + seqlock-published snapshot, the A22 `CoreContext::intended_*` pack, the A29 GUI-drag→`live_*` write, conc-5 submit_queue single-producer. Governing spec: `cross-thread-multiword-read-consistency-discipline.md`.
- **SPINE-3 per-node/per-cluster purity** — H22: NodeState ownership (no cross-node iteration), NEW-1 per-cluster relocation of the capital-authority predicate, A34 per-cluster concentration governor. Governing spec: `per-node-purity-scale-invariance.md` (H22).

**The thesis:** do spine-aligned ships produce CLEANER seams (each spine independently verifiable) than the synthesis's layer-aligned `.E.1a/b/c`?

**Finding (stated up front, defended in §5):** the spines are clean *verification* axes but NOT clean *rollback-anchor* axes — because all three spines READ AND WRITE the same `NodeState` struct (`:371-432`) and inherit the same Core→Node rename surface. A pure by-spine cut would force each spine ship to re-touch the shared layout, destroying bisectability (cut-line principle 3: data-layout before consumers). The correct decomposition therefore **lifts the shared mechanical substrate (guards + rename + layout) into foundation ships BENEATH the spines**, then runs the three spines as the capital-correctness ships on top. This is a HYBRID — mechanical-by-layer foundation, capital-logic-by-spine superstructure — and it is STRICTLY better than either pure lens (defended §5).
