### N-2 (NEW-1 CRITICAL): SLOW_PATH_GATE_AUTOPOPULATE_ENGINE_WIDE CALL SIGNATURE drifted (Class 15)

**Class 15 instance — NEW at v1.7.2.** Plan body Step B.3 v1.7.2 line 691 says:
> "SlowPathCycleOneCore body MUST call `SLOW_PATH_GATE_AUTOPOPULATE_ENGINE_WIDE(state, cfg)` at body entry"

Actual macro signature at `SlowPathGateRegistry.hpp:236`:
```cpp
#define SLOW_PATH_GATE_AUTOPOPULATE_ENGINE_WIDE(state, _cfg_arg) \
    do { \
        const auto& _gate_cfg = (_cfg_arg); \
        uint16_t _new_flags = 0; \
        FOREACH_SLOW_PATH_GATE(X_AUTOPOP_ENGINE_WIDE_WALK) \
        (state).flags = _new_flags; \  // ← writes to `(state).flags` directly
        (void)_gate_cfg; \
    } while (0)
```

The macro's first arg is the **GateState struct** (with a `.flags` member directly writable), NOT the EventLoopState. Both canonical call sites pass `state->global_gate_state` (the member):
- `ControllerEventLoop.hpp:2335` — `SLOW_PATH_GATE_AUTOPOPULATE_ENGINE_WIDE(state->global_gate_state, *config);`
- `ControllerEventLoop.hpp:3555` — `SLOW_PATH_GATE_AUTOPOPULATE_ENGINE_WIDE(state->global_gate_state, cfg);`

**Correct call from helper body** (where `state` is `EventLoopState<F>&` reference per plan body Decision H):
```cpp
SLOW_PATH_GATE_AUTOPOPULATE_ENGINE_WIDE(state.global_gate_state, cfg);
```

NOT `SLOW_PATH_GATE_AUTOPOPULATE_ENGINE_WIDE(state, cfg)` (which would try to do `state.flags = _new_flags` and would fail to compile — `EventLoopState<F>` has no `.flags` member).

**Severity:** CRITICAL — plan body's literal proposed call would NOT COMPILE. Caught BEFORE coding. Sister to the v1.7→v1.7.1 CRITICAL fix (scope/state mismatch) — this is the SISTER call-signature side that the v1.7.1 amendment cycle MISSED.

**Recommendation:** v1.7.3 amend Step B.3 + Pre-coding concern #12 + line 691 to use `SLOW_PATH_GATE_AUTOPOPULATE_ENGINE_WIDE(state.global_gate_state, cfg)`. Also amend Step B.3a documentation at line 708 if it cites the wrong form.
