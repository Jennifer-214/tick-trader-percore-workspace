# v5.11 Reference: Surgical Optimization Points

**Purpose:** This document provides the exact implementation suggestions for the 13 parts of the `LATENCY_OPTIMIZATION_AUDIT.md`, serving as the technical source of truth for the `v5.11` Optimization Sprint.

---

### Part 1: Hot Path (`ExecutionCore.hpp`)
1. **Template Elision:** Move `lat_enabled` from an atomic load to `template <unsigned F, bool LAT_ENABLED> void ExecutionCore_Tick(...)`.
2. **Vectorized Gates:** Pack `live_tp` (Leg A) and `live_tp_b` (Leg B) into a `__m512i`. Use `_mm512_cmpge_epu64_mask` to evaluate both simultaneously.
3. **SIMD CMOV:** Use `_mm512_mask_blend_epi64` to select between `live_tp` and `cached_params.sg_take_profit_price` for both legs in one cycle.
4. **Branchless Pushing:** Use bitwise logic for the ring buffer: `head += (can_enter | can_exit_a | can_exit_b);` with an unconditional write to the slot.
5. **Permission Alignment:** Move `uint8_t permission` to a new struct member at the end of `ExecutionCoreState`, prefixed with `alignas(64) uint8_t padding[64];`.

### Part 2: Slow Path (`RollingStats.hpp`, `LinearRegression3X.hpp`)
1. **O(1) Regression:** Update `sum_y`, `sum_y2`, `sum_xy` by subtracting `buffer[tail]` and adding `new_val` instead of looping over `W`.
2. **Reciprocal LUT:** Create `static constexpr FPN<F> RECIP_LUT[129]` where `RECIP_LUT[n] = 1.0 / n`. Replace `FPN_DivNoAssert(sum, n)` with `FPN_Mul(sum, RECIP_LUT[n])`.
3. **Wide FPN Vectorization:** Implement `FPN_MagAddN` for `N=4` and `N=8` using `_mm512_add_epi64` and handling carries via `_mm512_add_epi64` + `_mm512_cmpgt_epu64_mask`.
4. **RollingStats Padding:** Isolate `price_avg` and `price_slope` using `alignas(64)` to separate the GUI-read fields from the producer-written ring buffer indices.

### Part 3: Architectural Invariants
1. **Static Assert Zero-VTable:** Add a `static_assert(!std::is_polymorphic<ExecutionCoreState>::value)` to ensure no one adds a virtual function.
2. **Dense LUTs:** Ensure `StrategyId` to `GateParameters` mappings are flat arrays, never `std::unordered_map`.

### Part 4: peripheral Subsystems
1. **simdjson:** Replace `strstr` logic in `BinanceCrypto.hpp` with a `simdjson::dom::parser` instance reused in the ingest thread.
2. **OMS Spin-Wait:** Replace `sleep_for` with `for (int i=0; i<1000; ++i) _mm_pause();` then `futex_wait`.
3. **ML AOT:** Use a header-only transpiler for XGBoost trees to remove external library dynamic dispatch.

### Part 5: Bandit AVX-512
1. **8-Arm Parallelism:** Pack `double weights[8]` into `__m512d`. Normalize using `_mm512_div_pd(w, _mm512_set1_pd(sum))`.

### Part 6: Tail Variance
1. **Background Logging:** Use a dedicated `SPSCRing<OrderEvent>` for the drainer to hand off events to a low-priority I/O thread.
2. **Memory Locking:** Call `mlockall` immediately after config parsing in `main()`.

### Part 7: Allocator Eradication
1. **Monolithic Arena:** Allocate 1GB using `mmap(MAP_ANONYMOUS | MAP_PRIVATE | MAP_HUGETLB | MAP_POPULATE)`. Partition this for Pool and Buddy allocators.
2. **Zero-Alloc DataStream:** Replace any `std::string` usage in WebSocket URL builders with `snprintf` into stack buffers.

### Part 8: Parsing Efficiency
1. **Single-Pass Parser:** Design a custom `BinanceParser` that tokenizes the JSON once and returns a struct with all fields pre-extracted.
2. **fast_float:** Replace `atof` with `fast_float::from_chars`.

### Part 9: OMS Variance
1. **MPSC Queue:** Use a lock-free Multi-Producer Single-Consumer queue for cores to submit orders to the OMS.
2. **Slot Indexing:** clientOrderId: `oms_<guid>_<slot_idx>`.

### Part 10: Concurrency
1. **Snapshot Seqlock:** Add `uint64_t seq` to `TUISnapshot`. Producer increments before/after copy. GUI reader retries if `seq` is odd or changed.

### Part 11: FPN Libraries
1. **Newton-Raphson Divide:** Implement `__uint128_t` division using reciprocal multiplication to keep execution in the integer pipe.
2. **Assembly Overrides:** Use `asm ("adc %1, %0" ...)` for `FixedPoint64` magnitude additions to utilize the hardware carry flag directly.

### Part 12: HFT foundations
1. **TCP_NODELAY:** Verify `setsockopt(IPPROTO_TCP, TCP_NODELAY)` on all data and order sockets.
2. **MXCSR Tuning:** Set FTZ and DAZ bits in `main()` to prevent FPU subnormal microcode stalls.

### Part 13: Hardware Tuning
1. **NUMA Bind:** Use `numactl --cpunodebind=0 --membind=0` for the production run script.
2. **NIC Coalescing:** `ethtool -C <interface> rx-usecs 0` in the deployment runbook.
