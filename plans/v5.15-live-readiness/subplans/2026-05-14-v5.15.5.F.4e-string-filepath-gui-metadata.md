## Step 1 — Add tt:: specializations for KIND_STRING + KIND_FILE_PATH (~100 LOC)

**File:** `CoreFrameworks/CfgFieldDispatch.hpp` (extend)

### KIND_STRING parser:
```cpp
template <> inline void cfg_parse_field<CfgFieldDescriptor::KIND_STRING>(
        void* cfg_root, const CfgFieldDescriptor& desc, const char* val) {
    char* target_base = cfg_dispatch_target<CfgFieldDescriptor::KIND_STRING>(cfg_root, desc.lives_in_struct);
    char* target = target_base + cfg_field_offset(desc);
    size_t buf_len = desc.payload.as_string.buf_len;  // fixed-size buffer length encoded in payload
    strncpy(target, val, buf_len - 1);
    target[buf_len - 1] = '\0';  // ensure null termination
}
```

**Critical: fixed-size buffer (no malloc).** Cfg struct uses `char[N]` arrays (256 is typical) for string fields. No `std::string` in cfg struct (per `DOCS/STRATEGY_AND_CODING_RULES.md` — no malloc on data plane). The descriptor encodes `buf_len` in the payload so the parser knows the bounds.

### KIND_FILE_PATH parser:
```cpp
template <> inline void cfg_parse_field<CfgFieldDescriptor::KIND_FILE_PATH>(
        void* cfg_root, const CfgFieldDescriptor& desc, const char* val) {
    // Same as KIND_STRING parse; file_path is just a string with GUI hint metadata
    cfg_parse_field<CfgFieldDescriptor::KIND_STRING>(cfg_root, desc, val);
    // Optional: warn if file doesn't exist (cosmetic; some paths may not exist at load time)
}
```

### Save specializations:
```cpp
template <> inline void cfg_save_field<CfgFieldDescriptor::KIND_STRING>(
        FILE* fp, const void* cfg_root, const CfgFieldDescriptor& desc) {
    const char* target_base = cfg_dispatch_target<CfgFieldDescriptor::KIND_STRING>(
            const_cast<void*>(cfg_root), desc.lives_in_struct);
    const char* val = target_base + cfg_field_offset(desc);
    fprintf(fp, "%s=%s\n", desc.cfg_field_name, val);
    // Note: no quoting for now; assume cfg values don't contain newlines or '='
}
```

### Render specializations:
```cpp
template <> inline bool cfg_render_field<CfgFieldDescriptor::KIND_STRING>(
        void* val_ptr, const CfgFieldDescriptor& desc) {
    char* buf = static_cast<char*>(val_ptr);
    size_t buf_len = desc.payload.as_string.buf_len;
    
    // Check IS_SECRET metadata bit for password masking:
    ImGuiInputTextFlags flags = 0;
    if (desc.metadata_flags & CfgFieldDescriptor::IS_SECRET) {
        flags |= ImGuiInputTextFlags_Password;
    }
    return ImGui::InputText(desc.label, buf, buf_len, flags);
}

template <> inline bool cfg_render_field<CfgFieldDescriptor::KIND_FILE_PATH>(
        void* val_ptr, const CfgFieldDescriptor& desc) {
    char* buf = static_cast<char*>(val_ptr);
    size_t buf_len = desc.payload.as_string.buf_len;
    bool changed = ImGui::InputText(desc.label, buf, buf_len);
    // Optional: ImGui::SameLine(); ImGui::Button("Browse..."); (future polish; not in .F.4d scope)
    return changed;
}
```

## Step 4 — cfg.example auto-generator (~80 LOC)

```cpp
// CoreFrameworks/CfgExampleGenerator.hpp (NEW)

void Cfg_GenerateExample(FILE* fp, CfgFieldDescriptor::LivesInStruct filter) {
    fprintf(fp, "# Auto-generated cfg.example for %s\n", lives_in_struct_name(filter));
    fprintf(fp, "# Generated by Cfg_GenerateExample at boot time.\n");
    fprintf(fp, "# DO NOT EDIT manually — changes will be overwritten.\n\n");
    
    // Group by section, then by primary applies_to_strategy_cat for readability:
    const char* prev_section = nullptr;
    const char* prev_cat_name = nullptr;
    
    #define EMIT_CFG_EXAMPLE_LINE(kind, name, label, section, meta, payload, tooltip, \
                                   strat, op_mode, regime, risk, requires_cfg, lives_in) \
        if ((lives_in) == (filter)) { \
            /* Section header if changed */ \
            if (!prev_section || strcmp(prev_section, section) != 0) { \
                fprintf(fp, "\n# ===== %s =====\n", section); \
                prev_section = section; \
            } \
            /* Field comment + value */ \
            fprintf(fp, "# %s\n", tooltip); \
            cfg_example_emit_default<CfgFieldDescriptor::KIND_##kind>(fp, #name, g_cfg_field_descriptors[FIELD_IDX_##name]); \
        }
    FOREACH_CFG_FIELD(EMIT_CFG_EXAMPLE_LINE)
    #undef EMIT_CFG_EXAMPLE_LINE
}

void Cfg_GenerateAllExamples(const char* base_dir) {
    // One file per lives_in_struct value:
    Cfg_GenerateExample_ToFile(base_dir, "engine.cfg.example", STRUCT_CFG);
    Cfg_GenerateExample_ToFile(base_dir, "backtest.cfg.example", STRUCT_BACKTEST_CFG);  // only if .F.4i shipped
    // ... future: controller.cfg.example, secrets.cfg.example, training.cfg.example (v5.15.6) ...
}
```

`cfg_example_emit_default<KIND_X>` emits the default value per Kind:
- `KIND_DOUBLE`: `"%s=%g\n"`
- `KIND_INT`: `"%s=%d\n"`
- `KIND_INT_ENUM`: `"%s=%d  # 0=<label0>, 1=<label1>, ...\n"`
- `KIND_BOOL`: `"%s=0  # 0 or 1\n"`
- `KIND_STRING`: `"%s=%s\n"`
- `KIND_FILE_PATH`: `"%s=%s\n"`

**Build integration:** `CMakeLists.txt` adds a post-build step that runs `./bin/cfg_example_gen` (a new tiny binary) to regenerate the .cfg.example files. Operators always have current examples.

## Step 5 — Reverse drift CI script (~80 LOC Python)

```python
#!/usr/bin/env python3
# tools/cfg_registry_coverage_audit.py
# 
# Verifies every cfg field declared in ControllerConfig.hpp's struct
# has a corresponding row in FOREACH_CFG_FIELD registry.

import re
import sys
from pathlib import Path

CFG_HPP = Path("CoreFrameworks/ControllerConfig.hpp")
REGISTRY_HPP = Path("CoreFrameworks/CfgFieldRegistry.hpp")

# 1. Parse Cfg struct field declarations
def extract_cfg_fields(hpp_path):
    """Returns set of field names declared in ControllerConfig<F> struct."""
    text = hpp_path.read_text()
    # Match: <type> <name>; inside the struct block
    # Skip nested structs, arrays of structs, etc.
    fields = set()
    # ... regex parsing logic ...
    return fields

# 2. Parse FOREACH_CFG_FIELD rows
def extract_registry_fields(registry_path):
    """Returns set of field names in FOREACH_CFG_FIELD macro."""
    text = registry_path.read_text()
    pattern = re.compile(r'X\(\s*\w+\s*,\s*(\w+)\s*,')
    return set(pattern.findall(text))

# 3. Allow-list for boot-only / monitoring fields (not in registry by design)
BOOT_ONLY_FIELDS = {
    "engine_arch",  # actually it's INT_ENUM in registry; example only
    # ... fields that legitimately stay outside registry ...
}

def main():
    struct_fields = extract_cfg_fields(CFG_HPP)
    registry_fields = extract_registry_fields(REGISTRY_HPP)
    
    orphans = struct_fields - registry_fields - BOOT_ONLY_FIELDS
    if orphans:
        print(f"FAIL — {len(orphans)} cfg fields declared in struct but NOT in registry:")
        for f in sorted(orphans):
            print(f"  - {f}")
        sys.exit(1)
    
    # Reverse: registry → struct (must exist in struct)
    dangling = registry_fields - struct_fields
    if dangling:
        print(f"FAIL — {len(dangling)} registry rows reference non-existent struct fields:")
        for f in sorted(dangling):
            print(f"  - {f}")
        sys.exit(1)
    
    print(f"PASS — {len(registry_fields)} registry rows match struct fields ({len(BOOT_ONLY_FIELDS)} allow-listed)")
    sys.exit(0)

if __name__ == "__main__":
    main()
```

**CMake/build integration:** add as a pre-build step or CI hook. Runs in <1 second; catches reverse drift at every build.

**Note:** if `.F.4b` stretch goal (X-macro generates Cfg struct fields) landed, this CI script becomes redundant safety belt — both directions of drift are structurally closed. Keep the script as a defense-in-depth check regardless.

## Anti-patterns to avoid

- **Don't introduce std::string in cfg struct.** Fixed-size `char[N]` arrays only (per coding rules — no malloc on data plane). Heap-allocated strings break the no-malloc invariant.
- **Don't ship file dialog browser.** ImGui's file dialog isn't built-in; embedding `ImGuiFileDialog` adds dependency. Plain `InputText` for FILE_PATH; defer dialog to future polish ship.
- **Don't display secrets in clear text anywhere.** GUI uses ImGuiInputTextFlags_Password; logs redact via Cfg_DumpForLogging; HMAC stamps never include IS_SECRET fields. If you find a log site that prints a secret, fix it in this ship.
- **Don't add new cfg fields during migration.** Migration first; new features after. Adding fields mid-migration = harder bisect if parity breaks.
- **Don't skip the reverse drift CI script.** It's the second-half of the drift class closure. Without it, an engineer adds a struct field without a registry row → silent gap returns.

## If something goes wrong

- **STRING parse truncates correctly but display shows garbage:** verify the cfg struct field is `char[N]` (not `char*`); ensure the buf_len in the descriptor matches the array size. `static_assert(sizeof(ControllerConfig::X) == BUF_LEN)` per field.
- **HIDDEN_BY_DEFAULT field always visible:** the CollapsingHeader's default-closed flag isn't being respected. Verify ImGui flag spelling + treenode state.
- **SAFETY_CRITICAL modal blocks the GUI:** modal isn't dismissing on operator action. Verify `ImGui::CloseCurrentPopup()` is called in all paths (Confirm + Cancel + Esc).
- **Reverse drift CI script flags false positives:** boot-only / monitoring fields legitimately stay out of registry. Add to `BOOT_ONLY_FIELDS` allow-list in the script with rationale comment.
- **cfg.example auto-gen produces unreadable output:** check `tooltip` column values in registry rows — they need to be operator-friendly, not technical jargon.
- **Rollback:** `git reset --hard pre-v5.15.5.F.4d` (anchor at Step 0).
