### B.6 Auto-populate Flow Verification

**At inference (boot/backtest/hot-swap):**
1. `ModelHandle h` loaded from stamp body via `VerifyModelStamp(sr)` → `sr.inference_cfg_*` fields populated
2. `CoreModelZoo_ValidateAgainstCfg` walks FOREACH_CFG_DRIFT_CHECK registry
3. For each entry: compare `h->inference_cfg_<name>` vs `cfg.<expr>`
4. On mismatch: increment counter + conditionally REFUSE (Tier 1 strict) or WARN (Tier 2)

**At training:**
1. `Stamp_AssembleAndEmit(inf, cfg)` expands STAMP_CFG_AUTOPOPULATE(inf, cfg)
2. For each FOREACH_STAMP_BOUND_CFG entry: if emit_when TRUE, set `inf.has_<name> = 1` + `inf.<name> = cfg_expr`
3. Stamp body written with all matching `inference_cfg_*` fields populated
4. Field names match exactly: `inference_cfg_ml_tp_pct`, etc.

**Critical requirement:** FOREACH_STAMP_BOUND_CFG entry name MUST match the FOREACH_CFG_DRIFT_CHECK stamp_field expression name. Mismatch → silent parity gap.
