## Execution approach (first-value-fast — the anti-overwhelm)

- **Working v1 in DAYS, not after full conversion.** The moment {CI validator + the plugin's one `tagadapter.install{}` call + a handful of pilot files} exist, the system is LIVE in the editor. Full codebase conversion happens AFTER, incrementally — never a blocking cliff.
- **FULL focused conversion (tool-assisted) — NOT as-we-go** *(corrected 2026-07-05, operator)*. For load-bearing, tool-consumed tags, PARTIAL is unreliable (a half-tagged code-map/DAG/tag-query can't be trusted) and "as we go" never completes = itself a rot vector. **Completeness is a correctness property here.** So convert EVERY file in a focused sprint. Mixed-state stays graceful DURING the sprint (parser degrades to prose), but the sprint's job is 100%.
- **The generator does the bulk** — scaffolds every file + auto-fills `[DERIVED]` (`facts.lua`: size/deps/consumers/simd) + **migrates existing comments into `[COMMENT]`**. The human pass = **rot-check** (migrated comment still matches code?) + gap-fill, NOT hand-typing blocks. The **`[SCHEMA]` migrator** applies a future new-tag/section across every relevant unit (scripted transform) → schema evolution stays painless *because* the baseline is complete.
- **Division of labor:** operator builds the plugin adapter (their session); orchestrator builds the CI validator + drives the mechanical audit bulk (dated-doc find · consolidation candidates · rot-flag · per-file scaffolding) → operator reviews + writes judgment-prose at boundaries (offloads the focus-scarce part). Meet at the grammar contract.
- **Keep-in-ratio guardrail (operator's own, ROADMAP):** get to working-v1, then RETURN to the engine + convert opportunistically. The toolchain serves *building the engine* — don't let it become the mission.
- **Timeline:** tooling in DAYS (working-v1 = tooling + adapter + pilot); the FULL conversion is a focused push (~1–2 weeks, size-dependent, tool-assisted) → **COMPLETE**. Completeness is the goal (correctness for tool-consumed tags); then maintenance is trivial + CI-gated.
