## Lessons worth keeping (from this 48 hours)

1. **Trust empirical observations over diff inspection.** When she says it's broken, look at logs first.
2. **The single-source-of-truth pattern works only if every site uses it.** Adding new label kinds revealed that 6 metric sites silently assumed binary.
3. **Multi-file label correctness is a real bug class.** Pointer + count APIs that look like accumulation but aren't.
4. **GUI render threads should never iterate worker-thread buffers directly.** Snapshot pattern is the right shape.
5. **Calibrated metrics matter more than precise ones.** "0.2% accuracy" looking like "some signal" is worse than reading no metric.
6. **Architecture-solved beats runtime-checked.** Position limits via per-core capital allocation > per-tick limit gates.
