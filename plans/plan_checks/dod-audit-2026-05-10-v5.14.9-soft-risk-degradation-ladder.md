This is a **correct simplification** — the pattern's applicability rule is "use when some consumers need a SUBSET (partial-mirror)". Degradation curves have no partial-mirror; basic X-macro suffices. ✓

- enabled_bitmap: FOREACH_FEATURE enabled_bitmap is cfg-level (boot-only write; runtime-read); no cross-thread hazard
- partner_pending_bitmap: per-core; written by event loop; read by scheduler; no atomicity constraint (same thread pattern as current bools)

**Verdict:** CLEAN (plan correctly identifies no new concurrency hazards).
