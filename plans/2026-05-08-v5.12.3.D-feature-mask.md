## Theme

Cfg field `feature_mask_per_core[16]` (uint64_t bitmap; bit i =
FEATURE_<i> enabled). `Features_PackAll` checks mask before each
`FOREACH_FEATURE` compute fn — masked-off features pack as 0.0
sentinel (CLEAN: model trained with that mask sees same input
distribution as inference). Stamp body extension `feature_mask` +
3-tier strict-mode load-time check.

## Phase B — Pack-time mask gate (`v5.12.3.D.2`)

**Goal:** `Features_PackAll` checks the mask before each compute fn.
Masked-off features pack as 0.0.

**Step 0:** Modify `Features_PackAll` (in `ML_Headers/FeatureRegistry.hpp`
adjacent to FOREACH_FEATURE expansion). The current expansion
generates one compute call per row; modify to mask-test:

```cpp
// ML_Headers/FeatureRegistry.hpp Features_PackAll body
// v5.12.3.D: per-core feature mask. Each FOREACH_FEATURE row gets
// its bit-test before compute.
#define X(ID, name, version, enabled, compute_fn, desc)                 \
    {                                                                    \
        uint64_t bit = 1ULL << FEATURE_##ID;                             \
        if (cfg.feature_mask_per_core[ctx.core_id] & bit) {              \
            float v = compute_fn(ctx);                                   \
            if (!FPN_IsValidFinite(v) || std::isnan(v) || std::isinf(v)) {\
                return -1;  /* existing v5.9.0+ NaN-free guard */        \
            }                                                            \
            out[FEATURE_##ID] = v;                                       \
        } else {                                                         \
            out[FEATURE_##ID] = 0.0f;  /* masked-off sentinel */         \
        }                                                                \
    }
FOREACH_FEATURE(X)
#undef X
```

**Critical note:** the NaN-free guard from v5.9.0 (CLAUDE.md item 14)
must apply ONLY to the active (mask-on) features. Masked-off
features bypass the guard since their value is the sentinel 0.0.

**Tests** (+3):
1. Default mask (all on) → pack output bytewise identical to
   v5.11.65 baseline
2. Single feature masked off → that feature's slot = 0.0, others
   bytewise unchanged
3. Mask=0 (all features off) → all 34 slots = 0.0; no compute fn
   called

**Tag:** `v5.12.3.D.2`.

## Phase C — Stamp body extension (Surface G) (`v5.12.3.D.3`)

**Goal:** Stamp body records the feature_mask under which the model
was trained. Surface G `has_feature_mask` flag preserves backward
compat with legacy stamps.

```cpp
// ModelStamp body (in ML_Headers/ModelInference.hpp stamp_write_for_model
// / verify_model_stamp helpers around :1086+)
int      has_feature_mask;     // 0 in legacy stamps
uint64_t feature_mask;          // mask the model was trained under
```

Stamp write site: when model is trained, stamp captures the
operator's `cfg.feature_mask_per_core[core_id]` (or per-model mask
if trainer config differs).

Stamp read site: when loading, parse the new fields if present;
defaults `has_feature_mask=0; feature_mask=UINT64_MAX` for legacy.

**Tests** (+2): stamp round-trip preserves new fields; legacy stamp
loads with default `feature_mask=UINT64_MAX` (no change).

## Phase D — 3-tier strict-mode load-time check (`v5.12.3.D.4`)

**Goal:** Cfg-controlled strictness on stamp.feature_mask vs
cfg.feature_mask_per_core mismatch.

**Cfg field:**
```cpp
// CoreFrameworks/ControllerConfig.hpp
// v5.12.3.D: 3-tier feature_mask check at model load time.
//   0 = off (no check; legacy / experiment mode)
//   1 = warn (mismatch logs Health_Log(WARN); engine continues)
//   2 = strict (mismatch REFUSES load — engine fails to start)
int strict_feature_mask_check;  // default 2 (strict; safest default)
```

**Load-time check site:** `Model_Load` at
`ML_Headers/ModelInference.hpp:380` (or the verify_model_stamp
helper called from it). After stamp parsing:

```cpp
// v5.12.3.D: 3-tier feature_mask check
if (m->stamp.has_feature_mask) {
    uint64_t engine_mask = cfg.feature_mask_per_core[core_id];
    if (m->stamp.feature_mask != engine_mask) {
        if (cfg.strict_feature_mask_check == 2) {
            Health_Log(ERROR, "feature_mask mismatch: stamp=0x%llx, "
                              "engine=0x%llx (strict mode)",
                       (unsigned long long)m->stamp.feature_mask,
                       (unsigned long long)engine_mask);
            return -1;  // REFUSE load
        } else if (cfg.strict_feature_mask_check == 1) {
            Health_Log(WARN, "feature_mask mismatch: stamp=0x%llx, "
                             "engine=0x%llx (warn mode)",
                       (unsigned long long)m->stamp.feature_mask,
                       (unsigned long long)engine_mask);
        }
        // strict_feature_mask_check == 0: silent
    }
} else if (cfg.strict_feature_mask_check == 1) {
    // legacy stamp + warn mode → log reminder
    Health_Log(WARN, "model has no feature_mask in stamp body "
                     "(legacy stamp); treating as no-constraint");
}
```

**Tests** (+5):
1. Stamp has feature_mask + cfg matches + strict=2 → load OK
2. Stamp has feature_mask + cfg mismatches + strict=2 → REFUSE load
3. Stamp has feature_mask + cfg mismatches + strict=1 → WARN, continue
4. Stamp has feature_mask + cfg mismatches + strict=0 → silent
5. Legacy stamp (no `has_feature_mask`) + strict=2 → load OK (no
   constraint to check); + strict=1 → WARN reminder; + strict=0 → silent

**Tag:** `v5.12.3.D.4`.
