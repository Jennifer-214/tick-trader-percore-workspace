## Theme

Operator-observability ship. Per-core latency panel exists but no
top-level "WS health" or "ticks/sec" indicator at-a-glance. Operator
can't tell from the dashboard if the engine is currently receiving
ticks. Header bar shows "WS: <ticks_last_5s>/s, last tick <X>ms ago"
with color coding (green <100ms, yellow <1s, red >5s). Reads
`last_ws_tick_us` from v5.12.1.A; computes ticks-per-5s rolling.

Not load-bearing for safety (v5.12.1.A's flatten covers actual risk);
this surfaces the symptom faster for human eyes.

### Step 1: TUISnapshot population

`TUISnapshot_Build` site (around `:1719` adjacent to existing
`per_core[i].sp_last_tick_us` population):

```cpp
// v5.12.1.C: snapshot WS freshness for header render
snap->ws_last_tick_us = state->last_ws_tick_us.load(std::memory_order_acquire);
snap->ws_ticks_per_5s = state->ws_ticks_per_5s.load(std::memory_order_relaxed);
```

`state->ws_ticks_per_5s` is a NEW field on `EventLoopState` (atomic
uint64_t, single-writer = producer thread). Producer increments it in
fan_out using a circular ring of 5 1-second buckets:

```cpp
// CoreFrameworks/EngineSharded.hpp fan_out body, adjacent to v5.12.1.A's
// last_ws_tick_us publish:
// v5.12.1.C: rolling ticks-per-5s window. 5 second-buckets; current
// bucket = (now_us / 1000000) % 5; reset bucket on second-rollover.
uint64_t now_sec = now_us / 1000000ULL;
int bucket = (int)(now_sec % 5);
if (state.ws_bucket_last_sec[bucket] != now_sec) {
    state.ws_bucket_last_sec[bucket] = now_sec;
    state.ws_bucket_count[bucket] = 0;
}
state.ws_bucket_count[bucket]++;
uint64_t total = 0;
for (int i = 0; i < 5; i++) {
    if (state.ws_bucket_last_sec[i] >= now_sec - 4) {
        total += state.ws_bucket_count[i];
    }
}
state.ws_ticks_per_5s.store(total, std::memory_order_relaxed);
```

### Step 2: Renderers

**ImGui (header bar):** `GUI/EngineHeaderPanel.hpp:37` —
`EngineHeader_Render` already takes `const TUISnapshot* snap`. Add a
new line:

```cpp
// v5.12.1.C: WS health indicator
if (snap && snap->ws_last_tick_us > 0) {
    uint64_t now_us = (uint64_t)time(NULL) * 1000000ULL;  // approximate
    uint64_t gap_ms = (now_us - snap->ws_last_tick_us) / 1000ULL;
    ImVec4 color = (gap_ms < 100)  ? ImVec4(0.0f, 1.0f, 0.0f, 1.0f)   // green
                 : (gap_ms < 1000) ? ImVec4(1.0f, 1.0f, 0.0f, 1.0f)   // yellow
                                   : ImVec4(1.0f, 0.0f, 0.0f, 1.0f);  // red
    ImGui::TextColored(color, "WS: %llu/s, last %llums ago",
                       (unsigned long long)snap->ws_ticks_per_5s / 5ULL,
                       (unsigned long long)gap_ms);
}
```

**ANSI (`DataStream/TUIAnsi.hpp` header section):** identical math,
ANSI escape codes for color (`\033[32m` green, `\033[33m` yellow,
`\033[31m` red). One added row in the header section.
