# Ship A — 16B binary-core storage flip

## What shipped
`FPN<64>` compacted **24B sign-magnitude** (`uint64_t w[2]` + `int32_t sign` + pad) → **16B two's-complement** (bare `__int128 v`), **value-equivalent** (NOT byte-identical — bytes change by design under 16B; D-139). The tag is the **STOP-before-money boundary** (D-130): a complete 16B binary core, no money yet (decimal money is Ship B). Mechanism = `FPN<64>` is a full-specialization of `FPN<F>` (layout-identical to `FixedPoint<2,64>`; sizeof 24→16, 4 per cache line); the ~2,144 FPN sites ride the **alias-not-rename** (D-143) unchanged. Disjoint traits `is_fp_binary_v`/`is_fp_decimal_v` (B6). 16B ops native+branchless, reusing the `.E.0.1`-certified FP64 reduce via the C1 hoist. Hot `OrderGates` compares branchless `a.v>=b.v` (net latency reduction, D-133).

This ship absorbed the Session-9 op-port (5 commits `6f50864`..`c53e182`; the 16B op surface built additive) + this session's storage flip + acceptance + sanitizer close-out, under one tag.

## Acceptance — every Ship-A gate verified
- `controller_test` **3246/0 with binary VALUE assertions preserved** (passing ⇒ 16B produces identical values — the value-equivalence half of the P1 gate) + op-slice 423/0 + asan 3246/0 + **UBSan UB-clean** + gui green.
- **R1** layout asserts re-derived → 16B (`sizeof==16` self-proof). **R2** max-magnitude probe confirms saturate-not-wrap at the 2⁶³ boundary (63-bit bound feature-domain-safe; money decimal unaffected). **R3** snapshot VERSIONS bumped current+1 (CONTROLLER 12→13, SHARDED 8→9, PORTFOLIO 5→6; D-144, H21 append-only). **B1** UBSan signed-overflow lane + INT_MIN guard (branchless saturate-to-MAX in unsigned space, D-147). **B6** disjoint traits.
- Run-to-run + cross-opt (-O3×2, -O3-vs-O0) determinism **IDENTICAL**.

## The one deliberate deviation — golden refreeze deferred (D-157)
Acceptance criterion 316 (part 2) asks for a fresh 16B golden re-cert. **Deferred, operator-steered:** the core changes bytes *again* at Ship B, so refreezing now is premature churn. The determinism *property* is verified; only committing a new frozen golden file + un-bypassing pre-commit Check F is deferred until the numeric core stabilizes (post-Ship-B). Until then Check F runs bypassed-with-rationale (`SKIP_DETERMINISM_CHECK`) on flip commits. This is the **two-foundations** discipline (D-82): reproducibility (the net) and exact-values (the golden) are orthogonal; freezing an intermediate you'll re-freeze is waste.

## Meta-harvest — patterns + lessons (the "what did we learn / learn NOT to do")

**Patterns proven (codification candidates — Stage 1-2; full DESIGN_SPEC at ≥2 applications per the lifecycle):**
1. **Value-equivalent storage flip methodology** — reuse determinism-certified op cores (the C1 hoist), prove value-equivalence at the OP level (slice) + end-to-end via *preserved* test value-assertions, gate the bound (R2 63-bit), tag a STOP-before-money boundary. → candidate refactor-pattern (first canonical = this ship).
2. **Branchless overflow guard via safe-compute-in-unsigned-space** — `(v^s)-s` abs + `of_mask` saturate instead of a branch on `INT_MIN` (UB-free, branchless, H7/H20-aligned). → candidate branchless-discipline extension.
3. **Sanitizer-aware test thresholds via a build flag** (`FOXML_SANITIZER_BUILD`) — instrumented -O1 perturbs timing; the flag lets timing tests relax their floor only under sanitizers. → candidate test-discipline note.
4. **`no_sanitize("address")` on *verified-correct* AVX-512 masked kernels** — asan cannot model `_mm512_mask_*` masked load/store; the buffers are correctly sized, so the suppression is correct (not a papering-over). → LANDMINES + sanitizer-discipline note.

**Meta-process lesson (candidate for the meta-anti-pattern index):**
- **A first-ever sanitizer run surfaces a BATCH of pre-existing bugs — close them as their own cohort, do NOT conflate with the change under test (D-155).** Conflating them would either block the ship on unrelated debt or hide a real regression in the noise. The discriminator: does the finding reproduce on the *pre-change* code? All five did → pre-existing.

**Learned-NOT-to-do (C++ gotchas; cost build cycles this session):**
- **`namespace { using namespace tt; … }` LEAKS `tt` globally.** A using-directive inside an anonymous namespace propagates transitively (the anon namespace's implicit `using` carries it to the enclosing scope) → broke unrelated `MASK_*` lookups across the whole file. Qualify explicitly (`tt::`) for scoped resolution; never wrap a block in an anon-namespace using-directive.
- **Symlinked test files + `../`-relative includes break** when the symlink resolves to a different root (LANDMINE 7). Fix = root-relative includes + a build-system include anchor, not `../`.
- **Over-aligned structs (`alignas(64)`) allocated via bare `malloc` (16-byte alignment) = misaligned UB.** Use `aligned_alloc`/C++17-aligned-new/arena. Now structurally guarded (Check K).
