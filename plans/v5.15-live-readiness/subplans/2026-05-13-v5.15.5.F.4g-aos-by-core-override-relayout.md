## Goal

Re-layout per-core override storage from current SoA (`core_<field>[16]` + `core_<field>_override_set[16]` per field) to AoS-by-core (single `per_core_overrides[16]` array where each entry is one struct containing all override values for that core, plus a single bitmap mask for set/unset).

**Estimated savings:** ~3-5 cache miss savings per resolution × 16 cores × 100 cycles/sec = **600-1000 μs/sec slow-path budget recovered.** Per `DESIGN_SPECS/slow-path-cfg-resolution-cache-pattern.md` § "Per-core override storage layout — AoS-by-core."

## Key changes

1. **Define `PerCoreOverrides<F>` struct** in `CoreFrameworks/ControllerConfig.hpp`:
   ```cpp
   template <unsigned F>
   struct alignas(64) PerCoreOverrides {
       // All FPN<F> per-core override values for this core
       FPN<F> bandit_blend_ratio;
       FPN<F> ml_buy_threshold;
       FPN<F> ml_tp_pct;
       FPN<F> confidence_hard_block_threshold;
       FPN<F> ... (13 total per cohort audit)
       
       // All INT per-core override values
       uint32_t lazy_rebuild_force_period_us;
       uint32_t recovery_delay_secs;
       uint32_t param_max_age_ticks;
       int32_t  bandit_algorithm;
       int32_t  risk_degradation_curve;
       int32_t  barrier_blend_mode;
       
       // Override-set bitmap (1 bit per field; 64 fields max → uint64_t)
       uint64_t override_set_mask;
       
       /* pad to cache-line multiple */
   };
   ```
2. **Replace per-field arrays** in `Cfg`:
   - DELETE: `core_bandit_blend_ratio[16]`, `core_bandit_blend_ratio_override_set[16]`, ... (~26+ arrays)
   - ADD: `PerCoreOverrides<F> per_core_overrides[16];`
3. **Migrate parser** to write to `per_core_overrides[i].X`:
   - The `core_N_X` matching logic resolves N + field name → emit `per_core_overrides[N].X = parsed_val; per_core_overrides[N].override_set_mask |= (1ULL << FIELD_BIT_X);`
   - Use the FOREACH_CFG_FIELD registry's PER_CORE_OK metadata to auto-generate the field bit map.
4. **Migrate save** similarly (registry-driven).
5. **Migrate `Cfg_GetEffective_<field>(cfg, core_idx)` accessors:**
   ```cpp
   inline FPN<F> Cfg_GetEffective_bandit_blend_ratio(const Cfg* cfg, int core_idx) {
       const auto& ov = cfg->per_core_overrides[core_idx];
       return (ov.override_set_mask >> FIELD_BIT_BANDIT_BLEND_RATIO) & 1
              ? ov.bandit_blend_ratio
              : cfg->bandit_blend_ratio;
   }
   ```
6. **Migrate `ResolveCoreCfg`** to use `per_core_overrides[core_idx]` directly (1 cache miss instead of N).
7. **Verify backtest byte-identical:**
   ```bash
   cmp paper_runs/backtest_run.bin baseline_aos_pre.bin
   ```
8. **Measure cache-miss delta via `perf stat`:**

## Key concerns / pitfalls

- **Cfg struct size budget.** Adding `PerCoreOverrides<F>[16]` ≈ 16 × 256 bytes = 4 KB. Total Cfg size: currently ~12-15 KB; post-migration ~17-20 KB. Still well under L1 budget (32 KB typical). Verify Cfg fits in L1 if hot reads happen (it shouldn't — Cfg is slow-path or boot only).
- **Snapshot wire format.** If `Cfg` is part of `SHARDED_SNAPSHOT` body, the struct layout change BREAKS the wire format. **Check:** `rg "fwrite.*cfg" CoreFrameworks/` — if cfg is persisted, bump snapshot version + add migration. If cfg is NOT persisted (loaded from cfg.cfg on boot), no wire format concern.
- **Parser per-core override matching.** Current parser scans for `core_N_<field>` prefix; needs minor refactor to write to AoS struct. Verify regex/string match still works for fields with underscores in their name (`core_0_momentum_min_tp_margin_pct` etc.).
- **GUI per-core tabs.** SettingsPanel renders per-core overrides via per-core tabs. The tabs currently read from `core_X[i]` arrays; need to update to `per_core_overrides[i].X`. Likely minimal change since the descriptors abstract away storage.
- **Backward-compatibility for cfg files.** Existing `engine.cfg` files have `core_0_X=Y` lines. AoS migration MUST preserve the parser's text-format support (operator's existing cfg.cfg files still work).
- **Default values:** `override_set_mask = 0` at init means "no overrides set" — verify `PerCoreOverrides<F>` default constructor zero-initializes the mask + all FPN/int fields. C++ default initialization for POD union types can be UB if not careful.
