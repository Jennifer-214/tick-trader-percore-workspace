## Thread A Charters (8-14) — Framework consolidation (was `.F.4d` original charter)

### Charter 8 — Cfg-derived inference fields lack structural source-of-truth (Class 21 at derived-filter surface)

"Cfg field is in stamp body for inference parity" today encoded across THREE registries that must stay in sync:

| Registry | File:line | Purpose |
|---|---|---|
| Source row | `CoreFrameworks/CfgFieldRegistry.hpp` (`FOREACH_PER_CORE_CFG_FIELD` / `FOREACH_GLOBAL_CFG_FIELD`) | Cfg field definition (with `STAMP_BOUND` metadata bit) |
| Manual emission row | `ML_Headers/StampBoundCfgRegistry.hpp` (`FOREACH_STAMP_BOUND_CFG`) | Stamp body emit |
| Drift-check row | `ML_Headers/CfgDriftCheckRegistry.hpp` | Load-time drift compare |

Adding a new field requires touching all three; forgetting one = Class 18 mirror-incomplete drift. Class 21 anti-pattern (parallel descriptors) at derived-filter surface.

**Closure mechanism (Th-A.1 + Th-A.2):** Add `STAMP_BOUND_CFG_DERIVED` metadata bit to `CfgFieldDescriptor::MetadataFlag` enum. `DERIVED_FILTER_DECLARE_WIRE_FORMAT_TWO_SOURCE` framework macro walks source registries filtering by metadata bit; auto-generates downstream rows (POST_CFG mirror + CfgDerivedInferenceCfgRegistry + CfgDriftCheckRegistry) per flagged source row. Per Stage 1 audit, downstream registry generation is implicitly scope-gated — per-core source rows get all three downstream entries; global source rows get POST_CFG mirror + drift-check only (no inference-cfg-mirror because per-core IS the inference-cfg surface). Future additions = 1-row mechanical at source registry. **Closes Class 21 structurally for derived-filter surface.** First canonical applications: bandit/thompson cohort + Ridge cohort + Composite confidence cohort + Soft-risk degradation cohort + Winsor cohort + Always-emit cohort (ml_buy_threshold + trading_mode + gap_acceptable_threshold) — 22 source rows flagged this ship.

```cpp
// In CoreFrameworks/Order.hpp — sister to MASK_ORDER_PRE_RESOLVED canonical
// Order::flags_packed (uint32_t at .F.4c.3) bit allocation:
//   Bits 0-15:  original 16-bit flags (state, OrderType, etc.)
//   Bit 16:     MASK_ORDER_PRE_RESOLVED (.F.4c.3 canonical)
//   Bits 17-19: bandit_active_state (NEW; 3 bits for 5 states)
//   Bits 20-22: bandit_regime       (NEW; 3 bits for 5 regimes)
//   Bits 23-25: bandit_chosen_arm   (NEW; 3 bits for 8 arms)
//   Bits 26-31: 6 bits free headroom for future Order metadata
constexpr int SHIFT_ORDER_BANDIT_ACTIVE_STATE = 17;
constexpr int SHIFT_ORDER_BANDIT_REGIME       = 20;
constexpr int SHIFT_ORDER_BANDIT_CHOSEN_ARM   = 23;
constexpr uint32_t MASK_ORDER_BANDIT_3BIT     = 0x7;

// Static_assert that 5 bandit states + 5 regimes + 8 arms all fit in 3 bits each:
static_assert(FOREACH_BANDIT_ALGORITHM_COUNT <= 8, "bandit_active_state must fit in 3 bits");
static_assert(NUM_REGIMES <= 8, "bandit_regime must fit in 3 bits");
static_assert(ENSEMBLE_HORIZON_MAX <= 8, "bandit_chosen_arm must fit in 3 bits");

// MBS_* accessors per H14 manual-bit-packing-discipline (sister to BITMAP_* macros):
template <unsigned F>
inline int MBS_OrderBanditActiveState(const Order<F>& o) {
    return (o.flags_packed >> SHIFT_ORDER_BANDIT_ACTIVE_STATE) & MASK_ORDER_BANDIT_3BIT;
}
template <unsigned F>
inline int MBS_OrderBanditRegime(const Order<F>& o) {
    return (o.flags_packed >> SHIFT_ORDER_BANDIT_REGIME) & MASK_ORDER_BANDIT_3BIT;
}
template <unsigned F>
inline int MBS_OrderBanditChosenArm(const Order<F>& o) {
    return (o.flags_packed >> SHIFT_ORDER_BANDIT_CHOSEN_ARM) & MASK_ORDER_BANDIT_3BIT;
}
template <unsigned F>
inline void MBS_OrderSetBanditContext(Order<F>* o, int state, int regime, int arm) {
    // Clear existing bandit bits then OR in new values; sister shape to BITMAP_SET
    constexpr uint32_t BANDIT_CLEAR_MASK = ~(
        (MASK_ORDER_BANDIT_3BIT << SHIFT_ORDER_BANDIT_ACTIVE_STATE) |
        (MASK_ORDER_BANDIT_3BIT << SHIFT_ORDER_BANDIT_REGIME) |
        (MASK_ORDER_BANDIT_3BIT << SHIFT_ORDER_BANDIT_CHOSEN_ARM));
    o->flags_packed = (o->flags_packed & BANDIT_CLEAR_MASK) |
        ((uint32_t)(state  & MASK_ORDER_BANDIT_3BIT) << SHIFT_ORDER_BANDIT_ACTIVE_STATE) |
        ((uint32_t)(regime & MASK_ORDER_BANDIT_3BIT) << SHIFT_ORDER_BANDIT_REGIME) |
        ((uint32_t)(arm    & MASK_ORDER_BANDIT_3BIT) << SHIFT_ORDER_BANDIT_CHOSEN_ARM);
}
```
