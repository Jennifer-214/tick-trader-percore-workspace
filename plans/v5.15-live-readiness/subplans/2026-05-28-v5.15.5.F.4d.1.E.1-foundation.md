## TL;DR (executive summary)

This is the FOUNDATION ship for the full `.E` sub-sprint. Lands the substrate that subsequent ships `.E.2-.E.8` + standalone `.E.X` build upon. Substantial scope by design — getting the foundation right makes the downstream work clean; rushing it makes everything pay technical debt forever.

**Seven major axes land at this ship:**

1. **Core → Node hard rename** throughout codebase (Option α per D-27). All `state.cores[i]` → `state.nodes[i]`, `MAX_CORES` → `MAX_NODES`, `CoreContext` → `NodeContext`, `FOREACH_PER_CORE_CFG_FIELD` → `FOREACH_PER_NODE_CFG_FIELD`, per-core dirs → per-node dirs. ~100+ files touched mechanically.

2. **Per-node slow-path absorbs drainer responsibilities.** Central drainer thread (`Run.hpp:1455` lambda) goes away. Per-node slow-path owns: OMS submit, fill consumption, post-fill bookkeeping, manual close. Class 26 surface eliminated structurally (no cross-node iteration possible).
   - **↳ Folded from `.E.0.10` (A3 — FlattenAll half-flatten; TECH_DEBT-170; 2026-06-11):** the submit-path rework MUST (a) **preserve the honest-count contract** — `EventLoop_FlattenAll` returns legs ACTUALLY queued, not attempted (landed `.E.0.10` in `ControllerEventLoop.hpp`; a topology-independent contract this ship carries forward); (b) **define the RETRY for dropped emergency-flatten legs** — under the current finite per-core SPSC `submit_queue`, a full queue drops leg B → half-flatten (leg left OPEN + dirty `partner_pending_bitmap` → next-trade W/L mis-bucket); the per-node absorption + `conc-5` single-producer is where the retry / back-pressure model gets defined; (c) **CHARACTERIZE the failure path HERE, not at `.E.0.10`** — it was deliberately NOT pinned there per two-foundations (freezing a behavior THIS ship reworks = a worthless golden that breaks at the rework); `.E.0.10`'s net pins only the STABLE happy-path (N legs → N submits when the queue has room). Register: `plan_checks/E.0.10-finding-disposition-register.md` § bug-hunt A3.

3. **Multi-exchange registry framework substrate.** `FOREACH_EXCHANGE` meta-registry + `FOREACH_SUBACCOUNT` per-exchange meta-registry. Binance wired as first canonical row; framework ready for Alpaca + IBKR additions at `.E.6/.E.7`. Aligns with H15 (every X-macro registry enrolled in meta-registry) + H19 (topology discipline).

4. **Cluster/Node/Deployment hierarchy data layout.** Per-cluster shared resources (producer + adapter + WS); per-node trading flow with own sub-account binding. Global aggregator (1 thread; **event-driven O(1) push model per D-54**; integrity-verification cycle only).

5. **Per-node mode flag + dev vs production thread topology.** 4-state mode enum (`backtest | paper | live | shadow`) per-node. Dev mode topology (OS-scheduled threads; laptop functional) vs production (strict isolcpus + nohz_full).

6. **Event-sourced O(1) aggregator (per D-54).** Each per-node fill triggers atomic_fetch_add on global aggregator's running aggregate (push model; replaces pull-model cycle-based scan). Aggregator state always-exact; kill-switch latency floor drops from ~100ms to ~50μs. Multi-writer atomic; lock-free; contention bounded by fill rate.

7. **Portfolio/Position SoA + AVX-512 layout (per D-55).** Struct-of-Arrays for Portfolio + Position (bundled with NodeState refactor; incremental cost). ~100× speedup for portfolio walks via SIMD even at small N=8-32; cache-locality wins + memory bandwidth reduction compound. H10 SIMD discipline extends.

**Structural impact:**
- Class 26 (Global consumer reading per-core field with wrong index): **CLOSED structurally** — no cross-node iteration in per-node code
- Class 27 (Single-value cache flattens per-instance): **CLOSED structurally** — drainer-state cfg-mirrors move into per-node slow_state seqlock-published
- **Cross-thread torn-read CLASS** (NOT just the 1 known KS race — `.E.0.10` adversarial 3-agent sweep found it SYSTEMIC: **9 sites, 3 LIVE capital-control** — the **reconciler that corrects live capital off a torn `balance` read** [Knight-shaped], the global + per-core MTM kill switches, a GUI drag-TP/SL write-hazard): **CLOSED structurally by the aggregator** (single-writer + seqlock-published snapshot = exactly the reader-side fix, `concurrency-patterns/cross-thread-multiword-read-consistency-discipline.md`). **LOAD-BEARING FOR CAPITAL SAFETY — reframes F-2's "free bonus": `.E.1` is now a HARD LIVE-ENABLE GATE (live trading BLOCKED until this + `conc-5` land).** Scope = the torn-read class ONLY; `persist-8` (stale-flag, fixed `d0a6bb1`) + `conc-5` (SPSC-ring race) are DISTINCT roots, not closed by the aggregator.

**12 NEW DESIGN_SPECS land at Stage 3 first canonical** (full list in §10 DESIGN_SPECs).

**Hot path TOUCHED.** Drainer relocated; per-node slow-path absorbs. HOT_PATH_CHANGELOG entry mandatory. Verification: `tools/calls_graph_diff.sh` confirms no NEW hot path branches; per-node hot path remains branchless (H7); latency baseline measurement.

**Cluster** = per-exchange shared resource pool. Owns: producer (market-data WS) + adapter (REST/WS-API submit + HMAC sign) + user-data WS (fills) + sub-account credentials pool + rate-limit budget + connection topology.

**Node** = per-sub-account trading unit. Owns: hot thread (branchless H7) + slow thread (rebuild + submit + bookkeeping) + sub-account binding + symbol + strategy + capital + mode flag.

**Deployment** = engine instance. Owns: producer fan-out (per-cluster) + aggregator (global) + GUI/TUI publication + audit log.

**CPU core count for production mode:**
- N clusters × (producer + adapter + WS = 3 threads) + N clusters × M nodes × 2 threads (hot + slow) + 1 aggregator + 1 kernel
- For 2 clusters × 4 nodes each: 2×3 + 2×4×2 + 1 + 1 = **24 CPU cores**

**CPU core count for dev mode:**
- All threads OS-scheduled; no strict pinning; functional + correctness work on any core count ≥ 4
- Laptop with 8 cores comfortably runs 1 cluster × 2 nodes (functional + tests work; perf benchmarks unreliable)

struct alignas(64) NodeState {
    // === HOT cluster (HOT THREAD reads; SLOW THREAD writes) ===
    alignas(64) struct {

        FPN<F> open_notional;                           // current open positions value

        uint64_t wins_count;
        uint64_t losses_count;
        uint8_t _padding1[24];                          // pad to 64 boundary
    } slow_account;

    // === DRAINER ABSORB cluster (SLOW THREAD owns; was drainer state) ===
    alignas(64) struct {
        SPSCRing<TradeEvent, RING_SIZE> hot_to_slow_ring;     // hot path emits; slow path consumes
        SPSCRing<FillEvent, RING_SIZE> cluster_fill_ring;     // cluster WS routes; node slow consumes
        SPSCRing<ManualClose, RING_SIZE> gui_close_ring;      // GUI close requests for this node
        OrderTable<MAX_ORDERS_PER_NODE> orders;               // per-node order table
        BITMAP_TYPE(MAX_ORDERS_PER_NODE) order_bitmap;
        uint32_t next_order_id;                               // per-node monotonic
        // post-fill bookkeeping state (was CoreContext fields)
        FPN<F> core_realized;
        FPN<F> core_open_notional;
        FPN<F> core_fees;
    } drainer_state;

    // === SUB-ACCOUNT BINDING (boot-time; immutable post-boot) ===
    alignas(64) struct {
        uint32_t cluster_id;                            // FOREACH_EXCHANGE index
        uint32_t subaccount_id;                         // FOREACH_SUBACCOUNT index within cluster
        char client_order_id_prefix[16];                // encoded as "C<cluster><sub><node>"
    } binding;

    // === KILL SWITCH (atomic flags; multi-writer; lock-free) ===
    alignas(64) struct {
        std::atomic<uint8_t> per_node_kill;             // aggregator or operator sets
        std::atomic<uint8_t> per_cluster_kill_mirror;   // mirrored from cluster atomic for fast read
        std::atomic<uint8_t> global_kill_mirror;        // mirrored from global atomic for fast read
    } kill_flags;
};

static_assert(sizeof(NodeState) % 64 == 0, "NodeState size must be multiple of cache line");
static_assert(offsetof(NodeState, hot) % 64 == 0);
static_assert(offsetof(NodeState, slow_account) % 64 == 0);
static_assert(offsetof(NodeState, drainer_state) % 64 == 0);
static_assert(offsetof(NodeState, binding) % 64 == 0);
static_assert(offsetof(NodeState, kill_flags) % 64 == 0);
```

**Cache-line discipline:** 5 clusters of fields aligned to 64-byte boundaries. Cross-thread fields (seqlock-published; atomic kill flags) get dedicated cache lines. Per-thread state stays in own cluster.

**No false sharing:** hot thread reads `hot` cluster; slow thread writes `hot` + reads `slow_account`/`drainer_state`; aggregator reads `slow_account` via seqlock; kill flags atomic on dedicated cache line. Each axis has its own cache line ownership.

### Global aggregator + hierarchical kill switches (event-driven O(1) push model per D-54)

**Architectural shift from pull to push (per D-54 + F-11):** Aggregator does NOT iterate N nodes every cycle to compute totals. Each per-node fill TRIGGERS an atomic update of aggregator's running aggregate. Aggregator's periodic cycle (every 100ms, cfg-overridable) is INTEGRITY VERIFICATION only — recomputes totals from per-node state via seqlock + compares to running aggregate; warns on drift.

Drops kill-switch evaluation from "cycle-bounded 100ms" to "fill-arrival 50μs". Closes race window between fill arrival and aggregator pickup. Aggregator state always-exact (bit-precise; no aggregation drift).

```cpp
// CoreFrameworks/Aggregator.hpp (NEW; event-driven O(1) per D-54)

struct alignas(64) AggregatorState {
    // === GLOBAL RUNNING AGGREGATE (push-model; updated atomically per fill) ===
    alignas(64) struct {
        // FPN<F=64> is 24 bytes (not natively atomic); split into running aggregate via per-node delta accumulators
        // Each node has own atomic delta slot; global = sum of slots (computed on read by aggregator OR ad-hoc by GUI)
        // OR use 128-bit __int128 atomic on x86_64 for native atomic 96-bit FPN
        // (At v5.X: split-slot approach; revisit __int128 atomic at v5.16+)

        // For now: each per-node has own atomic slot for its contribution
        // Global total = sum of all per-node slots (lazy compute on read; cached)
        FPN<F> cached_total_realized_pnl;            // cached value; refreshed lazily on read
        FPN<F> cached_total_open_notional;
        FPN<F> cached_total_capital_allocated;
        FPN<F> cached_total_drawdown_current;
        std::atomic<uint64_t> cached_version;        // monotonic; bumped on update
        std::atomic<uint64_t> total_fills;
        uint8_t _padding[8];
    } global;

    // === PER-CLUSTER RUNNING AGGREGATE (same shape per cluster) ===
    alignas(64) struct ClusterRunning {
        FPN<F> cached_realized_pnl;
        FPN<F> cached_open_notional;
        FPN<F> cached_drawdown_current;
        std::atomic<uint64_t> cached_version;
        std::atomic<uint64_t> fills;
    };
    ClusterRunning per_cluster[NUM_EXCHANGES];

    // === KILL FLAGS (aggregator OWNS write; nodes mirror via atomic read) ===
    // These are EVENT-DRIVEN: aggregator updates immediately after fill if threshold breached
    alignas(64) std::atomic<uint8_t> global_kill_flag;
    std::atomic<uint8_t> per_cluster_kill[NUM_EXCHANGES];

    // === KILL THRESHOLDS (operator-configurable) ===
    FPN<F> global_kill_drawdown_threshold;
    FPN<F> per_cluster_kill_drawdown_threshold[NUM_EXCHANGES];

    // === INTEGRITY-VERIFICATION CYCLE STATE ===
    // Aggregator cycle (every 100ms) recomputes totals via seqlock walk;
    // compares to cached running aggregate; warns on drift (should always match)
    uint64_t integrity_cycle_count;
    uint64_t last_integrity_drift_count;       // expected: 0 always
    uint64_t last_cycle_duration_ns;
};

// Per-node fill event triggers IMMEDIATE atomic update of aggregator
void Aggregator_OnFill(AggregatorState& agg, NodeState<F>& node, const FillEvent<F>& fill) {
    if (node.hot.mode == NODE_MODE_LIVE || node.hot.mode == NODE_MODE_SHADOW) {
        // ATOMIC delta apply (lock-free; bit-exact)
        // FPN<F=64> is 24 bytes; not native atomic
        // Approach: per-node delta accumulator (each node atomic-write own slot; aggregator sums on read)
        // OR per-cluster delta accumulator (cluster atomic adds in delta; aggregator sums clusters)

        FPN<F> delta_realized = fill.net_pnl;       // can be negative for losses
        FPN<F> delta_notional = FPN_Sub(fill.qty_traded, fill.qty_remaining);  // sign depending on close vs open

        // Atomic increment cluster's running totals (multi-writer atomic; aligned)
        uint32_t cluster_id = node.binding.cluster_id;
        ClusterRunning& cluster = agg.per_cluster[cluster_id];

        // FPN atomic-add helper: implemented via __int128 atomic OR split FPN-low/FPN-high atomics
        FPN_AtomicAdd(&cluster.cached_realized_pnl, delta_realized);
        FPN_AtomicAdd(&cluster.cached_open_notional, delta_notional);
        cluster.cached_version.fetch_add(1, std::memory_order_release);
        cluster.fills.fetch_add(1, std::memory_order_relaxed);

        // Same for global running totals
        FPN_AtomicAdd(&agg.global.cached_total_realized_pnl, delta_realized);
        FPN_AtomicAdd(&agg.global.cached_total_open_notional, delta_notional);
        agg.global.cached_version.fetch_add(1, std::memory_order_release);
        agg.global.total_fills.fetch_add(1, std::memory_order_relaxed);

        // EVENT-DRIVEN kill check (no cycle wait):
        FPN<F> cluster_drawdown = FPN_Max(cluster.cached_drawdown_current, ComputeDrawdown(cluster));
        if (FPN_GreaterEq(cluster_drawdown, agg.per_cluster_kill_drawdown_threshold[cluster_id])) {
            agg.per_cluster_kill[cluster_id].store(1, std::memory_order_release);
            // Mirror to all nodes in cluster (atomic; nodes pick up on slow-path entry)
            ClusterMirrorKillFlag(cluster_id);
        }

        FPN<F> global_drawdown = FPN_Max(agg.global.cached_total_drawdown_current, ComputeDrawdown(agg.global));
        if (FPN_GreaterEq(global_drawdown, agg.global_kill_drawdown_threshold)) {
            agg.global_kill_flag.store(1, std::memory_order_release);
            // Mirror to all nodes (atomic)
            GlobalMirrorKillFlag();
        }
    }
}

// Aggregator's periodic cycle = INTEGRITY VERIFICATION only (no compute; just verify)
void Aggregator_IntegrityCycle(EngineState<F>& state) {
    AggregatorState& agg = state.aggregator;

    // Walk all nodes via seqlock; recompute totals; compare to cached running aggregate
    FPN<F> verify_realized = FPN<F>::zero();
    for (uint32_t c = 0; c < state.cluster_count; ++c) {
        ClusterState<...>& cluster = state.clusters[c];
        for (uint32_t n = 0; n < cluster.node_count; ++n) {
            NodeState<F>& node = *cluster.nodes[n];
            // seqlock read
            FPN<F> realized;
            uint64_t seq1, seq2;
            do {
                seq1 = node.slow_account.account_state_seqlock.load(std::memory_order_acquire);
                realized = node.slow_account.realized_pnl;
                seq2 = node.slow_account.account_state_seqlock.load(std::memory_order_acquire);
            } while (seq1 != seq2 || (seq1 & 1) != 0);

            if (node.hot.mode == NODE_MODE_LIVE || node.hot.mode == NODE_MODE_SHADOW) {
                verify_realized = FPN_Add(verify_realized, realized);
            }
        }
    }

    // Compare to cached running aggregate
    FPN<F> cached_realized = FPN_AtomicLoad(&agg.global.cached_total_realized_pnl);
    if (!FPN_Equal(verify_realized, cached_realized)) {
        agg.last_integrity_drift_count++;
        // LOG ERROR: integrity drift detected; running aggregate doesn't match seqlock-walk
        // Possible causes: atomic-add ordering bug; mode-flag race; calculation bug
        // Operator alert via webhook
    }
    agg.integrity_cycle_count++;
}

// Aggregator main loop
void Aggregator_Cycle(EngineState<F>& state) {
    AggregatorState& agg = state.aggregator;

    // 1. Read all node state via seqlock (lock-free)
    FPN<F> global_realized = FPN<F>::zero();
    FPN<F> global_notional = FPN<F>::zero();
    FPN<F> global_drawdown = FPN<F>::zero();

    for (uint32_t c = 0; c < state.cluster_count; ++c) {
        ClusterState<...>& cluster = state.clusters[c];
        FPN<F> cluster_realized = FPN<F>::zero();
        FPN<F> cluster_notional = FPN<F>::zero();
        FPN<F> cluster_drawdown = FPN<F>::zero();

        for (uint32_t n = 0; n < cluster.node_count; ++n) {
            NodeState<F>& node = *cluster.nodes[n];
            // seqlock read (lock-free; multi-version)
            FPN<F> realized, notional, drawdown;
            do {
                uint64_t seq1 = node.slow_account.account_state_seqlock.load(std::memory_order_acquire);
                realized = node.slow_account.realized_pnl;
                notional = node.slow_account.open_notional;
                drawdown = node.slow_account.drawdown_current;
                uint64_t seq2 = node.slow_account.account_state_seqlock.load(std::memory_order_acquire);
                if (seq1 == seq2 && (seq1 & 1) == 0) break;  // consistent read
                // else retry
            } while (true);

            // Skip paper-mode in real totals
            if (node.hot.mode == NODE_MODE_LIVE || node.hot.mode == NODE_MODE_SHADOW) {
                cluster_realized = FPN_Add(cluster_realized, realized);
                cluster_notional = FPN_Add(cluster_notional, notional);
                cluster_drawdown = FPN_Max(cluster_drawdown, drawdown);
            }
            // paper-mode: tagged separately (out of scope for kill switch)
        }

        agg.per_cluster[cluster.exchange_id].realized_pnl = cluster_realized;
        agg.per_cluster[cluster.exchange_id].open_notional = cluster_notional;
        agg.per_cluster[cluster.exchange_id].drawdown_current = cluster_drawdown;

        // Per-cluster kill check
        uint8_t cluster_kill = FPN_GreaterEq(cluster_drawdown,
                                              agg.per_cluster_kill_drawdown_threshold[cluster.exchange_id]) ? 1 : 0;
        agg.per_cluster_kill[cluster.exchange_id].store(cluster_kill, std::memory_order_release);

        global_realized = FPN_Add(global_realized, cluster_realized);
        global_notional = FPN_Add(global_notional, cluster_notional);
        global_drawdown = FPN_Max(global_drawdown, cluster_drawdown);
    }

    agg.global.total_realized_pnl = global_realized;
    agg.global.total_open_notional = global_notional;
    agg.global.total_drawdown_current = global_drawdown;

    // Global kill check
    uint8_t global_kill = FPN_GreaterEq(global_drawdown, agg.global_kill_drawdown_threshold) ? 1 : 0;
    agg.global_kill_flag.store(global_kill, std::memory_order_release);

    // Nodes will mirror these flags on next slow-path cycle entry (atomic read; cheap)
}
