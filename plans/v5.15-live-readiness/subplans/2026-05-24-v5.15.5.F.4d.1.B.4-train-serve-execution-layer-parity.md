## Ship end goal

**Close the train-serve execution-layer Class 18 mirror structurally** by extracting **5 shared helpers** in NEW `CoreFrameworks/EngineCommon.hpp` (v1.3 EXPANDED from 4):

1. `EngineCommon_ApplyBnbDiscount(ControllerConfig<F>& cfg)` — **NON-CONST cfg; ONE-SHOT mutator** (BNB fee discount applied to `cfg.cores[c].fee_rate_*` once). The ONLY non-const-cfg helper. Sister to existing `Sharded_ValidatePartialExitCfg`. Called once before BootGlobal.
2. `EngineCommon_BootGlobal(const ControllerConfig<F>& cfg, EventLoopState<F>& state, OrderManagerState<F>& oms)` — **CONST cfg** post-BNB-mutation; one-shot global boot work (kill_switch + DepthRecorder + Notify worker spawn references + trade_log open + engine-wide singletons). Called once per boot after ApplyBnbDiscount.
3. `EngineCommon_BootPerCore(const ControllerConfig<F>& cfg, int c, EventLoopState<F>& state, OrderManagerState<F>& oms)` — per-core boot (ConfidenceScorer + RollingTurnover + Strategy_InitPerCore + per-core OMS state + per-core model load). Called N times per boot.
4. `EngineCommon_SlowPathCycleOneCore(const ControllerConfig<F>& cfg, int c, EventLoopState<F>& state, OrderManagerState<F>& oms, FPN<F> price, uint64_t ts_us)` — per-core slow-path-cycle body (UpdateRollingStateOneCore + RebuildOneCore + TimeExitOneCore + TrailingSLRatchetOneCore + ML exit-prediction submit + per-core regime + `EventLoop_BreakevenOnProfit` per PARITY-032). Atomic per-core unit.
5. `EngineCommon_SlowPathCycleAllCores(const ControllerConfig<F>& cfg, EventLoopState<F>& state, OrderManagerState<F>& oms, FPN<F> price, uint64_t ts_us)` — thin wrapper (~10 LOC for-loop) calling OneCore N times per tick. Per Option D future-orientation for v6.0 viewer decoupling boundary.

Plus 1 named constant: `constexpr int BACKTEST_REGIME_SAMPLE_CORE = 0;` (per N1; documented in EngineCommon.hpp).

Both `EngineSharded_Run` (live) + `BacktestSharded_Run` (backtest) call same helpers; per-call-site differences handled via **cfg flag branches at boot time** + reference args (no nullable args per Decision H).
