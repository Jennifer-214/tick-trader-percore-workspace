## Design — registry-driven (future-thinking)

The skill MUST NOT hardcode the class list. Instead:

1. Read `DOCS/RECURRING_BUG_PATTERNS.md`
2. Walk every `## Class N` section
3. For each class, parse:
   - `**Surface:**` tag (lifecycle/area)
   - `**Detection:**` content (either executable grep OR delegation)
4. Run executable Detection blocks; report per-class:
   - CLEAN (no instances found)
   - KNOWN-N (N instances, all already in `**Known instances:**` list)
   - NEW-N (N instances NOT in known list — operator triage candidates)
5. For delegated Detection blocks, emit one-liner: `[delegated to
   /SISTER_SKILL — run separately]`

**Why registry-driven matters:**

When future Class 19, 20, ... are added to RECURRING_BUG_PATTERNS.md,
/bug-check picks them up automatically. No skill spec edit needed.
Same lesson as v5.14.5.B.0 universalization (CLAUDE.local.md
structural-fix rule): don't patch the visible class; design the
system so the next instance is impossible to miss.

## Implementation plan

### Sub-tag v5.14.6.A — Skill spec

File: `.claude/skills/bug-check/SKILL.md` (NEW; auto-symlinked
from workspace `claude-skills/bug-check/SKILL.md`)

Spec covers:

- **Purpose:** scan codebase for instances of known bug patterns
  catalogued in `DOCS/RECURRING_BUG_PATTERNS.md`. Reports CLEAN /
  KNOWN-N / NEW-N per class.
- **Distinct from sister skills:** see overlap table above.
- **Registry-driven design:** spec describes the parse + dispatch
  algorithm; never hardcodes class list.
- **Format-invariant validation:** first thing skill does is
  verify every class in the doc has both `**Surface:**` and
  `**Detection:**`. If not → CRITICAL doc-debt finding before
  any audits run.
- **Invocations:**
  - `/bug-check` — full scan (all non-delegated classes)
  - `/bug-check class_N` — focused single-class scan
  - `/bug-check surface_<tag>` — filter by Surface (live, ml,
    training, gui, drainer, boot, plan-time, audited-clean)
- **Procedure:** spawn Explore subagent that:
  1. Reads RECURRING_BUG_PATTERNS.md
  2. Validates format (every class has Surface + Detection)
  3. For each non-delegated class, executes Detection grep
  4. Cross-references Detection hits against `**Known instances:**`
     list to classify CLEAN / KNOWN-N / NEW-N
  5. Saves report to `plans/plan_checks/bug-check-<YYYY-MM-DD>.md`
     + prints to stdout
- **Output format:** per-class verdict + summary table + new-instance
  triage section.
