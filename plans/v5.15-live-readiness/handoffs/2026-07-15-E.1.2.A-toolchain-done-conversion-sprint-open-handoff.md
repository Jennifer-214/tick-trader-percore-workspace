## THE CONVERSION RECIPE (the sprint's per-file procedure — proven on ExecutionCore.hpp, D-353)

Fresh session per batch (a few files each — this is a long-horizon mechanical sprint; ~191 engine source files remain of 193). Per file:

1. **Read the WHOLE file.** Inventory units + existing comment shapes. **Rot-check** each comment vs the code (a stale comment relocated is worse than none).
2. **Convert** (copy-source: `DOCS/CODE_TAG_TEMPLATES.hpp`; grammar SSoT: `in-code-documentation-schema.md`):
   - `[FILE]` block at top (block-form `[CONTAINS]`) — this opts the file into standing CI.
   - Per-unit blocks; **code byte-verbatim inside `[CODE]`** — the `[CODE]` body is only ever *wrapped*, never rewritten.
   - Unit-WHY banner comments → below-code `[COMMENT]` **verbatim** (preserve-voice; operator EDIT comments stay IN PLACE). Step/field comments STAY inline (D-326).
   - Band/`=== X ===` in-body headers → bar-wrapped `[SECTION]_[<same text>]` (D-329).
   - **Refinement A:** stale DERIVED-class facts (byte-maps/sizes/offsets claiming the PRESENT) are **DROPPED, enumerated in the commit message** — historical narratives ("pre-vX had…") KEEP.
   - `[TAG]` values from `doc-tag-vocabulary.md` — **reuse-renames:** `[BITMAP_PACKED]`/`[PERSISTENCE]`/`[OMS_DRAINER]`/`[DETERMINISM]`; **NEVER `[WIRE_FORMAT]`/`[REGISTRY]` as TAG values** (fence-category collisions — the v1.1 alias candidates, D-347/D-348; express via `[REFERENCE]_[INVARIANT]_[H9]` / `[CFG_FLOW]`).
   - `[REFERENCE]` ids must RESOLVE (the validator checks). Struct `[DERIVED]` = the 4 lines `[SIZE]/[ALIGN]/[CACHE_LINES]/[STRADDLE]` as `pending-fix` placeholders. `[REGION]`/`[THREAD]`/`[SYNC]` sit ABOVE `[DIAGRAM]` (its freeform body swallows what follows).
   - Prose/preamble lines must not BEGIN with a bracket token (they parse as tag lines).
3. **Verify (the chain — every step, every file):**
   ```bash
   # (a) LOSSLESS — code byte-identical vs HEAD (comment-stripped diff MUST be 0):
   python3 - <<'EOF'
   import subprocess, difflib
   F = "CoreFrameworks/<FILE>.hpp"
   orig = subprocess.run(["git","show",f"HEAD:{F}"],capture_output=True,text=True).stdout
   new = open(F).read()
   cl = lambda t:[l.split("//")[0].rstrip() for l in t.split("\n") if l.split("//")[0].strip()]
   d = [x for x in difflib.unified_diff(cl(orig),cl(new),lineterm="",n=0) if x[0] in "+-" and x[:3] not in ("+++","---")]
   print("LOSSLESS:", "PASS" if not d else f"FAIL {len(d)}"); [print(" ",x[:140]) for x in d[:10]]
   EOF
   python3 tools/check_code_tag_blocks.py --paths <FILE>          # (b) validator green
   python3 tools/check_cache_layout.py --paths <FILE> --fix       # (c) structs: REAL DERIVED
   python3 tools/check_cache_layout.py --paths <FILE>             #     then the gate green
   ./build.sh test                                                # (d) suite 3697/0
   python3 tools/check_code_tag_blocks.py                         # (e) full tree = 2 accept-known ONLY
   ```
