## Theme

Per-handle normalizer maps any output (regression, binary, 3-class)
to `[0, 1]` buy-probability space. Bandit blend operates on
normalized values across heterogeneous ensemble members.

| Label kind | Normalizer | Maps from | Maps to |
|---|---|---|---|
| BINARY_BUY_SIGNAL | NORM_IDENTITY | [0, 1] | [0, 1] |
| REGRESSION_BUY_SIGNAL | NORM_REGRESSION | [-tp_pct, +tp_pct] | [0, 1] |
| PEAK_VALLEY_STABLE_3CLASS | NORM_BARRIER_CLASS_1 | out_result[1] | [0, 1] |
| (future kinds) | NORM_COMPOSITE | composite_signal output | [0, 1] |

```cpp
// ML_Headers/ModelInference.hpp around the ModelHandle struct (:223)
// v5.12.3.B: prediction normalizer maps heterogeneous outputs to
// [0,1] for ensemble blend.
enum prediction_normalizer_t {
    NORM_IDENTITY        = 0,    // binary/probability — passthrough (default)
    NORM_REGRESSION      = 1,    // [-tp_pct, +tp_pct] → [0, 1]
    NORM_BARRIER_CLASS_1 = 2,    // 3-class barrier — extract out_result[1]
    NORM_COMPOSITE       = 3,    // uses Phase 3.A target_classes/class_weights
};
```

**ModelHandle fields** (adjacent to Phase 3.A's

**New function** adjacent to `Model_Predict` at `:507`:

```cpp
// ML_Headers/ModelInference.hpp adjacent to Model_Predict
// v5.12.3.B: normalize predict output to [0, 1] buy-probability
// space. Used by bandit blend for heterogeneous ensembles.
template <unsigned F>
inline float Model_Predict_Normalized(ModelHandle<F>* m,
                                       const float* features,
                                       int num_features) {
    float raw = Model_Predict(m, features, num_features);
    switch (m->normalizer) {
        case NORM_IDENTITY:
            return raw;
        case NORM_REGRESSION: {
            float tp = m->normalizer_param;
            if (tp <= 0.0f) return 0.5f;  // defensive
            float v = 0.5f + raw / (2.0f * tp);
            return (v < 0.0f) ? 0.0f : (v > 1.0f ? 1.0f : v);
        }
        case NORM_BARRIER_CLASS_1: {
            // Note: Model_Predict already returns out_result[buy_class_idx]
            // For barrier with class_1 = peak, buy_class_idx is set to 1
            // at load time (v5.11.62 alias). NORM_BARRIER_CLASS_1 is for
            // models where the loader didn't set buy_class_idx but the
            // user wants explicit class-1 extraction.
            return raw;
        }
        case NORM_COMPOSITE:
            // Phase 3.A's composite extraction already ran inside
            // Model_Predict. The result is ALREADY composed; this
            // normalizer just clamps to [0,1] if needed.
            return (raw < 0.0f) ? 0.0f : (raw > 1.0f ? 1.0f : raw);
    }
    return raw;
}
```

**Loader sets normalizer** based on stamp body's `label_kind` (or

Mapping table from theme section maps directly.

**Tests** (+6):
1. NORM_IDENTITY (default) → raw value passes through unchanged
2. NORM_REGRESSION (pred=+0.025 at tp_pct=0.05) →
   clamp(0.5 + 0.025/0.10, 0, 1) = 0.75
3. NORM_BARRIER_CLASS_1 → out_result[1] equivalent
4. NORM_COMPOSITE clamps to [0, 1] when input out-of-range
5. Ensemble blend with mixed types: one binary (0.7) + one regression
   (clamp(0.5 + 0.025/0.10, 0, 1) = 0.75) = bandit weights apply
   without scale collision
6. Legacy stamp without `has_normalizer` flag → loader sets default
   NORM_IDENTITY, runtime preserved
