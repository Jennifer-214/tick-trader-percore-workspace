## Implementation plan

### Step 1 — Write skill spec

File: `.claude/skills/bug-check/SKILL.md` (NEW; auto-symlinked
from workspace claude-skills/bug-check/SKILL.md)

Spec covers:
- Purpose: read RECURRING_BUG_PATTERNS.md + run each Class's
  Detection grep against current codebase + report any new
  instances of known bug classes
- Distinct from /readiness Check 19 (audits a planned change)
  vs /bug-check (audits the EXISTING codebase for instances of
  known patterns)
- Run cadence: every sprint kickoff + on-demand when operator
  suspects a regression
- Invocations:
  - `/bug-check` — full audit (all classes)
  - `/bug-check class_13` — focused single-class scan
  - `/bug-check live` — Surface=live tagged classes only
  - `/bug-check ml` — Surface=ml/training tagged classes only
- Procedure: spawn Explore subagent that:
  1. Reads RECURRING_BUG_PATTERNS.md
  2. For each class with Detection block, executes the grep/awk
  3. Skips Known instances (file:line already in doc)
  4. Reports New instances matching signature → candidate bugs
  5. Saves to plans/plan_checks/bug-check-<YYYY-MM-DD>.md +
     prints to stdout

### Step 2 — Normalize Detection scripts in RECURRING_BUG_PATTERNS.md

For the 12 existing classes (Class 1-12), some have prose-style
Detection sections. Normalize all to executable grep/awk per the
Class 13 shape so the skill can run them mechanically.

Changes needed (audit during code time):
- Class 1 strategy lifecycle orphans: has tools/calls_graph_diff.sh
  reference — already executable
- Classes 2-12: review each Detection section; convert prose to
  grep/awk where possible; mark `[manual review only]` for ones
  that can't be mechanized
- Add `**Surface:**` line per class for filtering
  (live / ml / training / gui / drainer / boot)

### Step 3 — Skill spec test (single class invocation)

After skill ships, manual test:
- `/bug-check class_13` on current HEAD → should report ZERO new
  instances (v5.13.5.B fix was the only known instance; both
  flavors documented as Known; no new ones)
- `/bug-check` full → reports per-class CLEAN or NEW INSTANCE
  with file:line
