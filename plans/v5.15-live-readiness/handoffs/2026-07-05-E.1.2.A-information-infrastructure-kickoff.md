- **Docs ≠ code structure** (same vocab, different shape): docs = frontmatter + inline tags; do NOT wrap `.md` in `[FUNCTION]` blocks.
- **Mixed-state graceful** — parser degrades to prose; a half-converted tree always works.

- **Parallel-agent cohesion:** operator's plugin session + this session share the SCHEMA as the stable contract; changes TO the contract gate on a `[SCHEMA]_[vN]` bump.
