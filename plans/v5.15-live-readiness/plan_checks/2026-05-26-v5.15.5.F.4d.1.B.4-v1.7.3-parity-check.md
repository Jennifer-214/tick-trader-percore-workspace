### RE-FIRE-1 — CRITICAL — Step C.4 BACKTEST caller code block contains 3 fabricated/incorrect symbol references

**Location:** Plan body lines 970-981 (Step C.4 BACKTEST caller pre-helper resolution code block).

**Plan body cites:**
```cpp
BookSnapshot<BACKTEST_FP> depth = BookSnapshot_Init<BACKTEST_FP>();
if (drv && drv->depth_enabled) {                         // ← FABRICATED: depth_enabled not on drv
    depth.imbalance = drv->current_book_imbalance;       // ← STALE-NAME: drv->book_imbalance

    depth.mid_price = drv->current_mid_price;            // ← TYPE-MISMATCH: drv->current_mid_price is FPN<F>*
}
```

**Verified against actual code:**

1. **`drv->depth_enabled` does not exist.** Searched ShardedBacktestDriver struct definition (`CoreFrameworks/ShardedBacktestDriver.hpp`); no `depth_enabled` member. Actual `depth_enabled` is a CALLER-LOCAL variable at `Backtest/BacktestSharded.hpp:492`: `int depth_enabled = (int)BITMAP_IS_SET(cfg.gate_cfg_flags, MASK_GATE_CFG_DEPTH_ENABLED);`. Driver fields use the same conditional pattern at :509: `drv.book_imbalance = depth_enabled ? &book_imbalance_holder : nullptr;`. Inside the runtick callback, the check would be `drv->book_imbalance != nullptr` (nullness pattern), not `drv->depth_enabled`.

2. **`drv->current_book_imbalance` does not exist.** Searched `ShardedBacktestDriver` struct (lines 95-120). Actual field name is `drv->book_imbalance` (declared at `ShardedBacktestDriver.hpp:102`: `const FPN<F>* book_imbalance;`). The `current_` prefix is not part of the field name.

3. **`drv->current_spread` + `drv->current_mid_price` are `const FPN<F>*` POINTERS**, not values. Confirmed at `ShardedBacktestDriver.hpp:119-120`: `const FPN<F>* current_spread; const FPN<F>* current_mid_price;`. The plan body code `depth.spread = drv->current_spread;` is a type mismatch — assigning `const FPN<F>*` to `FPN<F>`. Would need dereferencing: `depth.spread = drv->current_spread ? *drv->current_spread : FPN_Zero<F>();`.

**Symptom if not caught:** Step C.4 BACKTEST caller code would COMPILE FAIL at Phase C implementation:
- `drv->depth_enabled`: error: 'class ShardedBacktestDriver<...>' has no member named 'depth_enabled'
- `drv->current_book_imbalance`: error: 'class ShardedBacktestDriver<...>' has no member named 'current_book_imbalance'; did you mean 'book_imbalance'?
- `depth.spread = drv->current_spread`: error: cannot convert 'const FPN<8>* const' to 'FPN<8>' in assignment

**Root cause class:** Body-content fabrication — the exact class of issue that v1.7.3 N-6 + M6 META-discipline `feedback_enumerate_helper_signature_args_before_extract` is supposed to catch at plan-time. **This is a fresh sister-instance of the recurrence v1.7.3 codifies.**
