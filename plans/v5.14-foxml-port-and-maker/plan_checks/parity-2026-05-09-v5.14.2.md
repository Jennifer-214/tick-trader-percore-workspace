## Recommended fix (CRITICAL — see also CLAUDE.md item 16)

**Extract `EnsembleModelZoo_PostLoadSetup<F>(ezoo, cfg, core_id, base_dir)` helper** containing the canonical post-load 7-step sequence:

```cpp
template <unsigned F>
inline int EnsembleModelZoo_PostLoadSetup(
    EnsembleModelZoo<F>* ezoo,
    const ControllerConfig<F>& cfg,
    int core_id,
    const char* base_run_path) {
    EnsembleModelZoo_InitBandits(ezoo,
        cfg.ensemble_bandit_eta,
        cfg.ensemble_min_warmup_predictions);
    EnsembleModelZoo_InitExitBandits(ezoo,
        cfg.exit_bandit_lr,
        cfg.ensemble_min_warmup_predictions);
    const char* mode = cfg.core_ensemble_blend_mode[core_id][0]
        ? cfg.core_ensemble_blend_mode[core_id]
        : cfg.ensemble_blend_mode;
    strncpy(ezoo->blend_mode, mode, sizeof(ezoo->blend_mode) - 1);
    ezoo->blend_mode[sizeof(ezoo->blend_mode) - 1] = '\0';
    EnsembleModelZoo_SetDisabledHorizons(ezoo,
        cfg.core_disabled_horizons[core_id]);
    EnsembleModelZoo_LoadBanditState(ezoo, base_run_path);
    EnsembleModelZoo_SetBanditSaveInterval(ezoo,
        cfg.ensemble_bandit_save_interval);
    EnsembleModelZoo_LoadExitBanditState(ezoo, base_run_path);
    return 1;
}
```

Then:
- **Boot** (`EngineSharded.hpp:~1173-1201`): replace 7-step block with `EnsembleModelZoo_PostLoadSetup(&ezoo, cfg, i, cfg.core_model_dir[i])`
- **Backtest** (`BacktestSharded.hpp:~330-359`): same call → closes PARITY-010 (.InitExitBandits + .LoadExitBanditState backfilled)
- **Hot-swap** (`EnsembleHotSwap.hpp:~104-114`): replace 4-step block with the same call → closes PARITY-009.C + .D + .E

**Sub-gaps .A + .B** (held_out_stamp_secret + gap_threshold hardcoded
in hot-swap LoadFromCfg call): fixed inline in HotSwapEnsemble (2-line
patch) since LoadFromCfg signature isn't part of PostLoadSetup.

**Sub-gap .F** (ValidateAgainstCfg call missing in hot-swap):
add 1 call to `CoreModelZoo_ValidateAgainstCfg<F>(nullptr, swap_ezoo, cfg, core_id, ...)` after PostLoadSetup. Same call boot uses (lines 1229-1234) but with `zoo=nullptr` since hot-swap is ensemble-only.
