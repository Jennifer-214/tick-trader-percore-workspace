## Step 0.5 — Implement `tt::cfg_render_field<T>` (third sister of parse/save; ~50 LOC; 30 min)

`tt::cfg_render_field<T>` is the third sister of the canonical `tt::` dispatch trio. Lives in `GUI/SettingsPanel.hpp` namespace `tt` (separate from `CfgFieldDispatch.hpp` to keep ImGui dependency out of parser-path code — see design comment at `CfgFieldDispatch.hpp:143`).

Per `DESIGN_SPECS/type-trait-dispatch-via-tt-namespace.md` 3-barrier discipline:
- **Barrier 1:** destination-by-reference; NO `void*+offset` overload
- **Barrier 2:** X-macro extractor passes cfg field reference (`tt::cfg_render_field(cfg.name, desc)`); never `&((char*)cfg)[offset]`
- **Barrier 3:** compile-time type-family `static_assert`

```cpp
// GUI/SettingsPanel.hpp — namespace tt
namespace tt {
    template <typename T>
    inline bool cfg_render_field(T& field, const CfgFieldDescriptor& desc) {
        // BARRIER 3: compile-time type-family guard.
        static_assert(is_FPN_v<T>
                   || std::is_floating_point_v<T>
                   || std::is_integral_v<T>
                   || std::is_array_v<T>,
                      "cfg field type not in recognized family — "
                      "extend tt::cfg_render_field<T> with a new branch.");
        bool changed = false;

        if constexpr (is_FPN_v<T>) {
            double v = FPN_ToDouble(field);
            if (desc.kind == CfgFieldDescriptor::KIND_DOUBLE_PCT) v *= 100.0;
            float vf = static_cast<float>(v);
            float lo = static_cast<float>(desc.payload.as_double.clamp_min);
            float hi = static_cast<float>(desc.payload.as_double.clamp_max);
            const char* fmt = (desc.kind == CfgFieldDescriptor::KIND_DOUBLE_PCT) ? "%.2f%%" : "%.4f";
            changed = ImGui::SliderFloat(desc.label, &vf, lo, hi, fmt);
            if (changed) {
                if (desc.kind == CfgFieldDescriptor::KIND_DOUBLE_PCT) vf /= 100.0f;
                field = FPN_FromDouble<T::F>(static_cast<double>(vf));
            }
        } else if constexpr (std::is_floating_point_v<T>) {
            // ... similar to FPN minus the FPN_ToDouble/_FromDouble round-trip
        } else if constexpr (std::is_array_v<T>) {
            changed = ImGui::InputText(desc.label, field, std::extent_v<T>);
        } else if constexpr (std::is_integral_v<T>) {
            // Sub-dispatch on Kind for INT_ENUM / BOOL / general INT cases:
            if (desc.kind == CfgFieldDescriptor::KIND_INT_ENUM) {
                int v = static_cast<int>(field);
                changed = ImGui::Combo(desc.label, &v,
                                        desc.payload.as_int_enum.labels,
                                        desc.payload.as_int_enum.count);
                if (changed) field = static_cast<T>(v);
            } else if (desc.kind == CfgFieldDescriptor::KIND_BOOL) {
                bool b = (field != 0);
                changed = ImGui::Checkbox(desc.label, &b);
                if (changed) field = static_cast<T>(b ? 1 : 0);
            } else {
                // KIND_INT_I32 / _I64 / _U32 / _U64 — render as SliderInt with int intermediate
                int v = static_cast<int>(field);
                int lo = static_cast<int>(desc.payload.as_int.clamp_min);
                int hi = static_cast<int>(desc.payload.as_int.clamp_max);
                changed = ImGui::SliderInt(desc.label, &v, lo, hi);
                if (changed) field = static_cast<T>(v);
            }
        }
        if (desc.tooltip && ImGui::IsItemHovered()) ImGui::SetTooltip("%s", desc.tooltip);
        return changed;
    }
}
```

} else if constexpr (std::is_unsigned_v<T> || std::is_integral_v<T>) {

// tests/controller_test.cpp — new test_v5_15_5_F4c_tooltip_byte_identity

constexpr uint64_t TOOLTIP_SNAPSHOT_HASH_V5_15_5_F4c = 0xCAFEBABE12345678ull; // recompute at ship time

void test_v5_15_5_F4c_tooltip_byte_identity() {
    printf("\n[v5.15.5.F.4c tooltip byte-identity discipline]\n");

    static char concat[131072] = {0};   // ~213 fields × ~600 bytes avg ≈ 128KB max
    int pos = 0;
    for (size_t i = 0; i < FIELD_IDX_END; i++) {
        const char* t = g_cfg_field_descriptors[i].tooltip;
        if (t) {
            pos += snprintf(concat + pos, sizeof(concat) - pos,
                             "%s|%s\n", g_cfg_field_descriptors[i].cfg_field_name, t);
        }
    }
    uint64_t hash = fnv1a_64(concat, pos);
    check("v5.15.5.F.4c: tooltip snapshot hash matches locked (operator-UX preservation)",
          hash == TOOLTIP_SNAPSHOT_HASH_V5_15_5_F4c);

    if (hash != TOOLTIP_SNAPSHOT_HASH_V5_15_5_F4c) {
        printf("    [DEBUG] tooltip snapshot hash drift: actual=0x%lx; expected=0x%lx\n",
               hash, TOOLTIP_SNAPSHOT_HASH_V5_15_5_F4c);
        printf("    [DEBUG] Either a tooltip changed (verify intentional + update LOCKED const), "
               "or migration drifted from byte-identity (HIGH-6 discipline violation).\n");

## Anti-patterns to avoid

- **Don't migrate STAMP_BOUND fields here.** They move at `.F.4d` via the derived filter framework. Use `metadata_flags & STAMP_BOUND` as the inclusion filter.
- **Don't migrate bitmap-resident bool fields.** The 5 `FOREACH_*_CFG_FLAG` bitmap registries handle their own bool fields (single source of truth at the bitmap layer).
- **Don't add INT_ENUM labels inline in the X-macro.** Use X_GEN_LABEL extern reuse from existing registries (BanditAlgorithmRegistry / DegradationCurveRegistry / BarrierBlendModeRegistry / etc.).
- **Don't reintroduce Class 23 anti-shape.** Per H13: type-erased `reinterpret_cast` through char*+offset is FORBIDDEN. Use `tt::<verb>_field<T>` with T deduced via X-macro extractor.
- **`model_verify_strict` tri-state vs INT_ENUM clamp:** classify as `KIND_INT_I8` (signed integral, clamp `[-1, 1]`), NOT `KIND_INT_ENUM`. Document tri-state semantics in tooltip.
- **INT storage-width:** registry rows must use the correct Kind sub-token (`KIND_INT_I32` / `_I64` / `_U32` / `_U64`) matching the destination cfg field's declared type.
- **Tooltip drift:** any tooltip text change MUST be intentional. Use raw string literals `R"(...)"` to preserve byte-identity during migration. Update `LOCKED_TOOLTIP_SNAPSHOT_HASH_V5_15_5_F4c` only on explicit operator-UX decision.

## If something goes wrong

- **Build fails on `tt::cfg_render_field<T>` instantiation:** verify all type-trait branches compile via dummy invocation at Step 0.5 entry; ensure no syntactic errors in `is_FPN_v` / `is_array_v` / `is_integral_v` / `is_unsigned_v` branches.
- **INT_ENUM dropdown shows wrong labels:** the extern reuse may point to wrong array. Verify `ENGINE_ARCH_LABELS` / `DEGRADATION_CURVE_LABELS` / etc. extern declarations match the source X-macro registry definitions (especially counts + label order).
- **Tooltip snapshot hash test fails:** an intentional tooltip change occurred or migration drifted from byte-identity. Recompute hash; update `LOCKED` constant; document in CHANGELOG. **Don't blindly update without verifying the change is intentional.**
- **INT_ENUM string-token regression:** operator's `engine_arch=per_core_slow` parses as 0. Verify Step 1.5's labels[] reverse-lookup branch is wired correctly + uses `strcasecmp` (or equivalent case-insensitive compare).
- **Backtest determinism breaks:** unlikely (no semantic changes), but possible if INT clamp ranges differ from manual parser. Audit each migrated INT field's clamp values vs original manual parse code.
- **Rollback:** `git reset --hard pre-v5.15.5.F.4c` (anchor at Step 0).
