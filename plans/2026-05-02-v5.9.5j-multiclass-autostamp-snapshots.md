### #6 — Train Model auto-stamp (1-2h, with #17 locked to Option A)

**Design decision #17 LOCKED:** Train Model auto-stamps using
**WF mean accuracy only** (no held-out). Operators wanting full
validation use Run Full Validation button (existing path). Engine
treats Train-Model-stamped models as warn-only (no refuse) since gap
can't be computed without held-out.

**Wiring:**

1. Read auto-stamp request from worker args (parallel to Full
   Validation's flow at `BacktestPanels.hpp:1730+`):
   ```cpp
   char auto_stamp_secret[128];
   char auto_stamp_path[400];
   int  auto_stamp_format_version;
   ```

2. In `train_model_worker_fn` post-Persist (BacktestPanels.hpp:1944+):
   ```cpp
   if (state->tm_auto_stamp_enabled && scaler_persisted &&
       state->tm_auto_stamp_secret[0]) {
       StampInferenceCfgInputs inf = {};
       // ... build inf from data->config_used + label_type +
       // hyperparams (same as v5.9.5h's RFV path)
       inf.has_inference_cfg = 1;
       // ... 9 cfg fields ...
       inf.has_xgb_hyperparams = 1;
       // ... 8 hyperparam fields (after v5.9.5h) ...
       inf.has_scaler = 1;
       inf.feature_scaler_present = 1;
       inf.scaler_sha256_hex = scaler_sha256_hex;

       StampWriteResult sr = stamp_write_for_model(
           state->tm_auto_stamp_path,
           state->tm_auto_stamp_secret,
           MODEL_FORMAT_VERSION,
           today,
           state->train_accuracy * 0.01,  // WF mean accuracy as wf_mean_val
           0.0,                             // sentinel: no held-out
           0.0,                             // sentinel: no gap_threshold
           /*force=*/0,
           FEATURE_REGISTRY_HASH(),
           ENGINE_VERSION_STRING,
           &inf);
       state->tm_auto_stamp_attempted = 1;
       state->tm_auto_stamp_ok = sr.ok;
       /* ... copy result ... */
   }
   ```

3. Engine load (`CoreModelZoo._TryLoadRole`): when stamp's
   `gap_threshold == 0.0`, skip the gap-acceptable check (treat as
   "training-only stamp; warn but don't refuse").

4. Training panel UI: HMAC secret input field + "Auto-stamp on
   completion" checkbox. Persists to cfg via `cfg_write_field`.

5. Display: after worker completes, show "Stamp written: <path>" or
   "Stamp REFUSED: <reason>" below status_msg (parallel to Full
   Validation's display at line 3088-3119).

**Files:**
