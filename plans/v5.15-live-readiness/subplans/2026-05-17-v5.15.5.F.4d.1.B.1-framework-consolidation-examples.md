## § Step 1 — `MemHeaders/CfgGateRegistry.hpp` (NEW)

```cpp
#pragma once

// CfgGateRegistry.hpp — Canonical sparse sidecar for cfg-derived consumer gate_when expressions.
//
// Pattern: sidecar-override-pattern-for-registry-auto-flows.md Stage 3 ACTIVE
//   (FIRST CANONICAL of gate-type sidecar; sister to FOREACH_DRIFT_OVERRIDE planned at .C
//   which is severity-type sidecar)
// Framework: cfg-derived-consumer-framework.md Stage 3 first reference at .B.1
//
// Encodes: per-row gate_when_expr for fields flagged with STAMP_BOUND_CFG_DERIVED metadata bit.
// Consumers (INFERENCE_CFG_POPULATE_FROM_DERIVED / STAMP_CFG_POPULATE_FROM_DERIVED /
// DRIFT_CHECK_AUTOPOPULATE) walk the master cfg field registry filtered by STAMP_BOUND_CFG_DERIVED;
// per-row, look up gate via this sidecar (default = STAMP_HAS(*h, inference_cfg) for drift /
// `1` for populate when sidecar entry absent).
//
// Initially empty at .B.1; populated at .B.2 as cohort fields flag STAMP_BOUND_CFG_DERIVED.
//
// Adding a new gate-required row:
//   1. Add X(<field_name>, <gate_when_expr>) below
//   2. Confirm field name appears in FOREACH_PER_CORE_CFG_FIELD or FOREACH_GLOBAL_CFG_FIELD
//      with STAMP_BOUND_CFG_DERIVED bit set
//   3. CI verifies: every FOREACH_CFG_GATE row references a flagged source row

#include "../CoreFrameworks/CfgFieldRegistry.hpp"

#define FOREACH_CFG_GATE(X) \
    /* Populated at .B.2 as cohort fields flag STAMP_BOUND_CFG_DERIVED. Sample shape: */ \
    /* X(bandit_algorithm,                  BITMAP_IS_SET(cfg.ml_cfg_flags, MASK_ML_CFG_BANDIT_ENABLED)) \ */ \
    /* X(thompson_mu_prior,                 BITMAP_IS_SET(cfg.ml_cfg_flags, MASK_ML_CFG_BANDIT_ENABLED)) \ */ \
    /* X(ridge_lambda,                      BITMAP_ANY(cfg.ml_cfg_flags, MASK_ML_CFG_RIDGE_WITHIN_HORIZON | MASK_ML_CFG_RIDGE_ACROSS_HORIZONS)) \ */ \
    /* X(confidence_freshness_tau_secs,     BITMAP_IS_SET(cfg.ml_cfg_flags, MASK_ML_CFG_CONFIDENCE_COMPOSITE_ENABLED)) \ */ \

// cfg_gate_lookup — sparse sidecar lookup with default. Returns gate_when_expr value for row idx.
//
// At .B.1 the registry is empty → all calls return default. At .B.2 populated rows return their
// specific gate_when_expr; absent rows continue returning default.
//
// Branchless: linear scan over FOREACH_CFG_GATE sparse entries; row indices known at compile time;
// optimizer generates equivalent jump-table / branchless lookup. Sparse arity is small (≤24 rows
// projected) so scan cost is negligible at slow-path / stamp-emit cadence.

template <unsigned F>
inline bool cfg_gate_lookup_default_drift(const ModelStampResult* handle) {
    return STAMP_HAS(*handle, inference_cfg);
}

template <unsigned F>
inline bool cfg_gate_lookup_default_populate() {
    return true;  // always populate (always-emit canonical Q3.G)
}

// Sparse array entry (per-row entry; compile-time-known indices):
// Per-row entry: F is the FPN fractional-bits template parameter (matches ControllerConfig<F>).
// Dispatch shape (fn pointer table vs inline X-macro paste) finalized at coding time per H20 matrix.
template <unsigned F>
struct CfgGateEntry {
    size_t row_idx;
    bool   (*gate_fn)(const ControllerConfig<F>&);
};

// FOREACH_CFG_GATE expansion → sparse array initializer (filled at .B.2; empty at .B.1)
// See cfg-derived-consumer-framework.md for full dispatch shape.
```

## § Step 2 — 3 consumer macros

```cpp
// MemHeaders/CfgGateRegistry.hpp (continued; or split into CfgDerivedConsumerMacros.hpp)
//
// Consumer macros walk master cfg field registry filtered by STAMP_BOUND_CFG_DERIVED bit
// + per-row gate via FOREACH_CFG_GATE sparse sidecar lookup.
//
// At .B.1: STAMP_BOUND_CFG_DERIVED bit flagged on 0 source rows → walker iterates 0 rows → vacuous behavior.
// At .B.2: 24-row cohort flags the bit → walker iterates 24 rows.

// === INFERENCE_CFG_POPULATE_FROM_DERIVED ===
// Replaces existing INFERENCE_CFG_AUTOPOPULATE at consumers; produces same inf.* field population
// for the equivalent cohort.
#define INFERENCE_CFG_POPULATE_FROM_DERIVED(inf, cfg) \
    do { \
        CFG_FIELD_FOR_EACH_SET_BIT(g_per_core_cfg_stamp_bound_cfg_derived_mask.words, _idx, { \
            const CfgFieldDescriptor& _d = g_per_core_cfg_field_descriptors[_idx]; \
            bool _gate = cfg_gate_lookup_populate(_idx, /*per_core*/true, (cfg)); \
            tt::cfg_populate_inf_field<F>(_d, (inf), (cfg), _gate); \
        }); \
        CFG_FIELD_FOR_EACH_SET_BIT(g_global_cfg_stamp_bound_cfg_derived_mask.words, _idx, { \
            const CfgFieldDescriptor& _d = g_global_cfg_field_descriptors[_idx]; \
            bool _gate = cfg_gate_lookup_populate(_idx, /*per_core*/false, (cfg)); \
            tt::cfg_populate_inf_field<F>(_d, (inf), (cfg), _gate); \
        }); \
    } while (0)

// === STAMP_CFG_POPULATE_FROM_DERIVED ===
// NEW production stamp populate (PARITY-020 closure direction; sister to legacy STAMP_CFG_AUTOPOPULATE).
// Same walker structure; different consumer behavior (writes to stamp body buf vs inf struct).
#define STAMP_CFG_POPULATE_FROM_DERIVED(buf, cap, cfg) \
    do { \
        size_t _written = 0; \
        CFG_FIELD_FOR_EACH_SET_BIT(g_per_core_cfg_stamp_bound_cfg_derived_mask.words, _idx, { \
            const CfgFieldDescriptor& _d = g_per_core_cfg_field_descriptors[_idx]; \
            _written += tt::cfg_emit_field<F>(_d, (cfg), (buf) + _written, (cap) - _written); \
        }); \
        CFG_FIELD_FOR_EACH_SET_BIT(g_global_cfg_stamp_bound_cfg_derived_mask.words, _idx, { \
            const CfgFieldDescriptor& _d = g_global_cfg_field_descriptors[_idx]; \
            _written += tt::cfg_emit_field<F>(_d, (cfg), (buf) + _written, (cap) - _written); \
        }); \
    } while (0)

// === DRIFT_CHECK_FROM_DERIVED ===
// Renamed from DRIFT_CHECK_AUTOPOPULATE for naming consistency (FROM_DERIVED suffix across all 3 consumers).
// Replaces β4 sparse-sidecar dispatch with same shape as sister macros.
// Walker invokes per-row drift compare via tt:: dispatch with sidecar-gate.
// H20 BRANCHLESS via mask-select (no nested if; gate & drifted compose into trigger via AND;
// AND result drives bitmap-set via multiplication mask + drift counter increment via cast).
#define DRIFT_CHECK_FROM_DERIVED(failure_flags, handle, cfg, drift_count_ref) \
    do { \
        CFG_FIELD_FOR_EACH_SET_BIT(g_per_core_cfg_stamp_bound_cfg_derived_mask.words, _idx, { \
            const CfgFieldDescriptor& _d = g_per_core_cfg_field_descriptors[_idx]; \
            bool _gate = cfg_gate_lookup_drift(_idx, /*per_core*/true, (cfg), (handle)); \
            bool _drifted = tt::cfg_drift_compare<F>(_d, *(handle), (cfg)); \
            bool _trigger = _gate & _drifted; \
            (failure_flags) |= ((uint64_t)_trigger * FAILURE_MASK_cfg_inference_drift); \
            (drift_count_ref) += (int)_trigger; \
        }); \
        CFG_FIELD_FOR_EACH_SET_BIT(g_global_cfg_stamp_bound_cfg_derived_mask.words, _idx, { \
            const CfgFieldDescriptor& _d = g_global_cfg_field_descriptors[_idx]; \
            bool _gate = cfg_gate_lookup_drift(_idx, /*per_core*/false, (cfg), (handle)); \
            bool _drifted = tt::cfg_drift_compare<F>(_d, *(handle), (cfg)); \
            bool _trigger = _gate & _drifted; \
            (failure_flags) |= ((uint64_t)_trigger * FAILURE_MASK_cfg_inference_drift); \
            (drift_count_ref) += (int)_trigger; \
        }); \
    } while (0)
```

### Optional: extract `CFG_WALK_DERIVED` helper macro to eliminate per-core/global walker body duplication

Each of 3 consumer macros currently has parallel per-core + global walker bodies (= 6 nearly-identical loop bodies; Class 18 mirror echo). Coding-time decision per H20 matrix:

```cpp
// Generic walker macro (parameterized by bit_lname + body):
#define CFG_WALK_DERIVED(bit_lname, body) \
    do { \
        CFG_FIELD_FOR_EACH_SET_BIT(g_per_core_cfg_##bit_lname##_mask.words, _idx, { \
            const CfgFieldDescriptor& _d = g_per_core_cfg_field_descriptors[_idx]; \
            const bool _is_per_core = true; \
            body; \
        }); \
        CFG_FIELD_FOR_EACH_SET_BIT(g_global_cfg_##bit_lname##_mask.words, _idx, { \
            const CfgFieldDescriptor& _d = g_global_cfg_field_descriptors[_idx]; \
            const bool _is_per_core = false; \
            body; \
        }); \
    } while (0)

// Consumer macros reduce to:
#define INFERENCE_CFG_POPULATE_FROM_DERIVED(inf, cfg) \
    CFG_WALK_DERIVED(stamp_bound_cfg_derived, { \
        bool _gate = cfg_gate_lookup_populate(_idx, _is_per_core, (cfg)); \
        tt::cfg_populate_inf_field<F>(_d, (inf), (cfg), _gate); \
    })
```

Coding-time decision: deploy CFG_WALK_DERIVED IF the per-core/global symmetry holds across all 3 consumers (it does); skip if a consumer has divergent behavior (none do at `.B.1`).
