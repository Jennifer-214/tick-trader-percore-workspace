## Coding-time discoveries from prior session(s)

Pulled from `.B.6` ship close postmortem. Session-real findings; assume they shape what you'll hit next.

### D-1: Forward-decl namespace shadow anti-pattern (Class 34)
- **Catalyst:** Phase B.3 SlowPath.hpp build break — `namespace tt { struct TUISharedState; }` inside namespace created shadow type; ~20 sites failed with "invalid sizeof on incomplete type"
- **Resolution:** Moved forward-decl to GLOBAL scope (outside namespace tt); build cleared. NEW Class 34 codified.
- **Lesson:** When introducing forward-decls during hoisting, place at GLOBAL scope unless the type genuinely lives inside the namespace.

### D-2: Block-scope statics inaccessible from hoisted header (Class 35)
- **Catalyst:** Phase B.2 Async.hpp fan_out hoist — 6 block-scope statics (tick_rings, cores, g_tick_rec, g_depth_shared, g_shared, g_candle_acc) referenced from lambda body couldn't be accessed from header-scope function.
- **Resolution:** Passed as explicit args via wrapper lambda (25-arg signature). NEW Class 35 codified.
- **Lesson:** Before hoisting a lambda from block-scope to header-scope, enumerate ALL block-scope-static refs in the body. They need explicit args, not implicit capture.

### D-3: Code-LOC vs total-LOC counting methodology gap
- **Catalyst:** B.4.1 over-engineering episode — Run.hpp at 2,436 LOC looked "62% over 1,500 threshold" via `wc -l`; operator asked "are we counting comments in the LOC count?"; actual code-LOC was 1,406 (UNDER threshold).
- **Resolution:** Reverted B.4.1 commit (5 Run/* sub-sub-files deleted). Codified code-LOC counting methodology at `file-size-split-discipline.md` v1.3.
- **Lesson:** File-size threshold reads must use code-LOC (exclude comments + blanks), NOT total-LOC. 4-pillar self-audit pillar 4 (novel-alternative consideration) should have surfaced this methodology question BEFORE triggering work.

### D-4: SSoT discipline LIVE+NO-OP merge (Decision H)
- **Catalyst:** SlowPath.hpp had two variants of `drain_post_fill` / `drain_manual_closes` — LIVE branch + NO-OP branch under cfg gate.
- **Resolution:** MERGED both into single function with `#ifdef` inside body. NEW DESIGN_SPEC `single-source-of-truth-discipline.md` codified.
- **Lesson:** When LIVE + NO-OP variants of same function exist, prefer single function with internal #ifdef over two functions selected at call sites.

### D-5: ShardedSnapshot_Save<F> two-phase lookup miss
- **Catalyst:** Async.hpp:428 emitted `-Wc++20-extensions` warning for template call without prior declaration.
- **Resolution:** Added `#include "../ShardedSnapshotPersist.hpp"` in Async.hpp.
- **Lesson:** Template calls in C++17 need explicit prior declaration (two-phase lookup); include the header before the call site.
