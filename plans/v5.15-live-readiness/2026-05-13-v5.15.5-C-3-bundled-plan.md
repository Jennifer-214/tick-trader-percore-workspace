## Phase 3 — Canonical `FOREACH_OMS_FIELD` + 3 derived views + AUTOPOPULATE

**Step 0:** Refactor `MemHeaders/OmsPersistFieldRegistry.hpp` into canonical `MemHeaders/OmsFieldRegistry.hpp`.

**Design specs applied:**
- `registry-tuple-as-single-source-of-truth.md` (THE foundational pattern)
- `heterogeneous-registry-pattern.md` (multi-attribute tuple; per-kind dispatch)
- `autopopulate-pattern-for-production-caller-class.md` (AUTOPOPULATE at INIT + RESET + PERSIST sites)
- `pre-post-cfg-registry-split-for-emit-order-preservation.md` (derived-view pattern precedent)
- `bitmap-flag-api.md` (BIT-kind persist for kill_switch_tripped)
- `x-macro-registry-with-presence-dispatch.md` (SKIP_PERSIST kind dispatch)

**Canonical registry tuple shape:**
```cpp
X(name, type, init_value, reset_value, persist_kind, persist_mask)
```

Where:
- `name` — field name on OrderManagerState
- `type` — wire type (FPN<F>, int, uint32_t, uint64_t)
- `init_value` — value at OrderManager_Init (may reference template/constructor params via context)
- `reset_value` — value at paper-reset (often == init_value for accumulators)
- `persist_kind` — `DIRECT` (read field directly) | `BIT` (extract bit from oms_state_flags) | `SKIP_PERSIST` (observability counter; don't serialize)
- `persist_mask` — for BIT kind: the mask constant; for DIRECT/SKIP_PERSIST: 0

**Per-slot registry tuple (separate; per-slot scope):**
```cpp
X(name, type, init_value, reset_value)
```

Walks `last_fill[i].*`, `last_realized_return[i]`, `last_exit_predicted_p[i]`, `last_exit_predicted_meta[i]` (via OMS_META_CLEAR).

**Projection macros (derived views):**
```cpp
#define OMS_PROJECT_INIT(name, type, init, reset, kind, mask)    /* emit init assignment */
#define OMS_PROJECT_RESET(name, type, init, reset, kind, mask)   /* emit reset assignment */
#define OMS_PROJECT_PERSIST_SAVE(name, type, init, reset, kind, mask)  /* dispatch on kind */
#define OMS_PROJECT_PERSIST_LOAD(name, type, init, reset, kind, mask)  /* dispatch on kind */
#define OMS_PROJECT_PERSIST_DECLARE(name, type, init, reset, kind, mask) /* tmp_<name> decl */
```

**AUTOPOPULATE companions:**
```cpp
#define OMS_INIT_AUTOPOPULATE(oms_var, F_template_param, ...) \
    FOREACH_OMS_FIELD(OMS_PROJECT_INIT) \
    /* per-slot loop expansion */ \
    /* Layer 2 helper-init calls: Portfolio_Init, OrderEventLog_Init */ \
    /* Layer 3 atomic stores: flatten_pending, recovery_until_us, total_* */ \
    /* Layer 4 conditional event_log_mode block */

#define OMS_RESET_AUTOPOPULATE(state_var, ...) \
    FOREACH_OMS_FIELD(OMS_PROJECT_RESET) \
    /* per-slot reset loop */
```

**Static asserts:**
- `static_assert(FOREACH_OMS_FIELD_COUNT > 0, "registry non-empty")`
- Per-kind invariant: each BIT-kind row must have a non-zero mask
- Existing offset-lock static_asserts retained

**Loop fusion:** the canonical per-slot registry walk in OMS_INIT_AUTOPOPULATE merges the previously-separate `last_realized_return[i]` loop (line 680) + `last_fill[i].*` loop (line 688) into a single pass over MAX_PORTFOLIO_POSITIONS.

**Migration of consumer sites:**

- Paper-reset block at `EngineSharded.hpp:2004-2022` collapses to `OMS_RESET_AUTOPOPULATE(state)` + non-registry items (Portfolio_Init)

**DOD/bitmap gate:**
- ✅ Registry-driven: adding a new OMS field = 1 row in canonical

- ✅ Structural fix preferred: 3 derived views from 1 source; drift impossible

## Phase 6 — Paper-reset archive flow

**Step 0:** Create `data/paper_resets/` directory at boot (mkdir idempotent).

**Design specs applied:**
- `shadow-load-state-transition-pattern.md` (atomic capture + validate + publish — applied to archive write before reset)
- Reuses `ShardedSnapshot_Save` (existing) for snapshot.dat
- Reuses ShardedTradeLog rotation pattern (extended per Phase 5 for per-core)

**Archive directory layout:**
```
data/paper_resets/{start_iso}_to_{end_iso}.paper/
  ├── snapshot.dat              ← FOREACH_OMS_FIELD persist projection
  ├── trades/
  │   ├── core_0.csv            ← per-core trade log rotated in
  │   ├── core_1.csv
  │   ├── ...
  │   └── core_15.csv
  ├── summary.json              ← global + per_core + per_strategy + per_regime sections
  └── cfg_at_reset.txt          ← optional cfg snapshot (if cfg-changed-mid-session detection added)
```

**Filename format:**
- `start_iso` = ISO 8601 date from `paper_session_start_us` (e.g., `2026-04-15`)
- `end_iso` = ISO 8601 date from `now()` at reset time (e.g., `2026-05-01`)

**Reset flow (replaces EngineSharded.hpp:1998-2050 block):**
```
1. Capture end_us = now_us()
2. format dirname = format_iso(start_us) + "_to_" + format_iso(end_us) + ".paper"
3. mkdir -p data/paper_resets/<dirname>/trades/
4. ShardedSnapshot_Save(&state, "data/paper_resets/<dirname>/snapshot.dat", partial_on)
5. ShardedTradeLog_RotateAll(state.oms->trade_log, "data/paper_resets/<dirname>/trades/")
6. Summary_WriteJson(&state, "data/paper_resets/<dirname>/summary.json")
7. OMS_RESET_AUTOPOPULATE(state) — resets all 12 fields + per-slot via canonical registry
8. state.oms->paper_session_start_us = end_us  // start of next session
```

**DOD/bitmap gate:**
- ✅ Cache-friendly archive write (sequential I/O; atomic rename for safety)
- ✅ Reuses existing patterns (ShardedSnapshot_Save format, ShardedTradeLog rotation extended)
- ✅ Structural fix preferred: archive-then-reset eliminates Class 5 silent-counter-loss recurrence
