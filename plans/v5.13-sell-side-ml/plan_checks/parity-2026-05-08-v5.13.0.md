## Cross-cutting verification

**`buy_class_idx` aliasing correctness:** Critical fix closes
silent semantic inversion. Without aliasing,
`exit_predictor.buy_class_idx` defaults to 0 (VALLEY). 3-class
outputs are `[P(stable), P(peak), P(valley)]`.
`Model_Predict_Normalized` would read `output[0]=P(stable)`
instead of `output[1]=P(peak)`. For exit timing, peak detection is
correct semantics (exit when reversing). Aliasing ensures
class=1 reading. Caught by /readiness Check 19 pre-coding.

**Scaler sharing assumption:** Reuse correct. `Features_PackAll`
populated once. Scaler per-handle (not per-path). All roles in
ensemble trained same feature matrix → same scaler. Sibling check
validates consistency.

**Partial-exit tracking:** `my_mask` loop correctly computes
per-core slot ownership (legs A+B under PARTIALS mode). Per-slot
marking (`oms.last_exit_was_predicted[pidx]`) before
`OMS_PushSubmit` ensures visibility to calibration log for v5.13.4
counterfactual attribution.
