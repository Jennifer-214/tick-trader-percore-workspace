## Why this subplan exists

Three concerns share the same surface (boot path + cfg parser +
operator-facing safety):

1. **Live-readiness boot gate.** The `./engine` boot log review
   2026-05-11 surfaced that the engine boots with multiple silent
   safety failures (empty stamp secret, mlockall failed, hardcoded
   strategy fallback) — under live conditions these would risk capital.
   Need a checklist gate that REFUSES boot when `trading_mode=live` and
   any pre-flight item fails.

2. **`trading_mode` cfg field.** No top-level discriminator exists today
   between paper and live operation. Need a new cfg field (NOT
   `engine_mode` — that name is already taken for `sharded` vs
   `single_core` architecture choice). The field is stamp-bound so
   every model carries its training-time mode for audit trail.

3. **TECH_DEBT-024 breakeven_on_profit wire-up.** Dormant cfg field
   defined + parsed + zero read sites; sister `breakeven_on_partial` is
   wired at `PortfolioController.hpp:670`. Wire-up the missing read
   site so operators get the feature they configured. Surface area
   overlap with the boot gate (LifecycleCfgFlagRegistry is referenced
   in both contexts).

4. **TECH_DEBT-033 /readiness wider-build check.** Workflow skill
   missing the wider-build verification step that would have caught
   v5.14.post1's `train_model_worker_fn` migration gap. Add the check.

Bundling all four into v5.15.2 absorbs cohort overlap; separating would
require touching cfg parser + boot path twice.

**HMAC chain implication:** legacy stamps lack `trading_mode` line; v5.15.2+
parser leaves `has_trading_mode=0` (default zero-init); v5.15.2+ engine
treats `has_trading_mode=0` as "stamp predates v5.15.2 → effective PAPER
via legacy default → no drift check fired." Surface G `has_*` flag
preserves forward-compat per CLAUDE.md item 15. **No
MODEL_FORMAT_VERSION bump.**

**Wire format byte preservation:** the new line `trading_mode=0\n`
(or `=1\n`, `=2\n`) appears at the canonical position dictated by
FOREACH_STAMP_BOUND_CFG row order — APPENDED at end-of-cfg-section
because we added it as the last row before the macro close. Per
`wire-format-byte-preservation-discipline.md`, appending at end of
registry preserves byte positions of ALL existing rows. SHA-256 lock
test for representative pre-v5.15.2 stamp body will produce IDENTICAL
hash post-v5.15.2 when the stamp lacks trading_mode (legacy load); will
produce DIFFERENT hash for new-emit stamps (because they include the
extra line). Both behaviors are intentional + documented in CHANGELOG.

### Step 1: pre-flight checklist via FOREACH_LIVE_READINESS_CHECK X-macro

Per /merge-scan MEDIUM-2 + Caramel's "don't defer" P3 directive, build
the checklist as an X-macro registry from the start (rather than a
plain static constexpr array). Pattern: curve-registry-pattern.md
(enum-driven dispatch with function pointers).

```cpp
// In CoreFrameworks/LiveReadinessCheckRegistry.hpp (NEW; X-macro registry).
// Adding a new pre-flight check = 1 row. Registry auto-generates:
//   - enum value (for ordering / per-check identification)
//   - static constexpr LiveReadinessCheck table entry
//   - dispatch fn pointer
//
// Same pattern as FOREACH_DEGRADATION_CURVE (v5.14.9.A precedent) +
// SlowPathGateRegistry.

#define FOREACH_LIVE_READINESS_CHECK(X)                                                       \
    /* X(name_id, fn_ptr, severity, fix_hint) */                                              \
    X(secret_nonempty,           check_secret_nonempty,           S_REFUSE,                   \
      "set held_out_stamp_secret in secrets.cfg")                                             \
    X(mlockall_succeeded,        check_mlockall_succeeded,        S_REFUSE,                   \
      "run engine as root OR set require_mlockall=0 (degraded)")                              \
    X(all_cores_strategy_explicit, check_all_cores_strategy_explicit, S_REFUSE,               \
      "set core_0_strategy ... core_N_strategy in cfg")                                       \
    X(all_ml_cores_have_model,   check_all_ml_cores_have_model,   S_REFUSE,                   \
      "set core_N_model_path or core_N_model_dir for ML cores")                               \
    X(model_max_age_set,         check_model_max_age_set,         S_REFUSE,                   \
      "set model_max_age_hours; retrain stale models")                                        \
    X(no_feature_hash_drift,     check_no_feature_hash_drift,     S_REFUSE,                   \
      "retrain with current FEATURE_REGISTRY_HASH")                                           \
    X(no_label_hash_drift,       check_no_label_hash_drift,       S_REFUSE,                   \
      "retrain with current LABEL_REGISTRY_HASH")                                             \
    X(no_build_flags_drift,      check_no_build_flags_drift,      S_WARN,                     \
      "rebuild engine with same flags as training")                                           \
    X(all_stamps_hmac_verified,  check_all_stamps_hmac_verified,  S_REFUSE,                   \
      "set model_verify_strict=1; reload")

template <int F>
struct LiveReadinessCheck {
    const char *name;
    enum Severity { S_REFUSE, S_WARN } sev;
    bool (*fn)(const ControllerConfig<F>&, const EngineShardedState<F>&);
    const char *fix_hint;
};

template <int F>
static bool check_secret_nonempty(const ControllerConfig<F>& cfg,
                                  const EngineShardedState<F>&) {
    return cfg.held_out_stamp_secret[0] != '\0';
}

template <int F>
static bool check_mlockall_succeeded(const ControllerConfig<F>& cfg,
                                     const EngineShardedState<F>& s) {
    // cfg.require_mlockall + mlockall syscall result captured in state at init
    return (cfg.require_mlockall == 0) || (s.mlockall_succeeded != 0);
}

template <int F>
static bool check_all_cores_strategy_explicit(const ControllerConfig<F>& cfg,
                                              const EngineShardedState<F>&) {
    for (int c = 0; c < cfg.num_cores; ++c) {
        if (!cfg.core_strategy_explicit[c]) return false;
    }
    return true;
}

template <int F>
static bool check_all_ml_cores_have_model(const ControllerConfig<F>& cfg,
                                          const EngineShardedState<F>& s) {
    for (int c = 0; c < cfg.num_cores; ++c) {
        if (cfg.core_strategy[c] == STRATEGY_ML &&
            s.cores[c].model_handle == nullptr) {
            return false;
        }
    }
    return true;
}

template <int F>
static bool check_model_max_age_set(const ControllerConfig<F>& cfg,
                                    const EngineShardedState<F>& s) {
    if (cfg.model_max_age_hours == 0) return false;  // strict requires set
    // Also verify no MODEL_AGE_WARN flags tripped at load
    for (int c = 0; c < cfg.num_cores; ++c) {
        if (BITMAP_IS_SET(s.cores[c].percore_snap.failure_flags,
                          MASK_FAILURE_MODEL_AGE_WARN)) return false;
    }
    return true;
}

template <int F>
static bool check_no_feature_hash_drift(const ControllerConfig<F>&,
                                        const EngineShardedState<F>& s) {
    for (int c = 0; c < cfg.num_cores; ++c) {
        if (BITMAP_IS_SET(s.cores[c].percore_snap.failure_flags,
                          MASK_FAILURE_FEATURE_HASH_DRIFT)) return false;
    }
    return true;
}

// Similar checks for label, build_flags, stamp_hmac_verified.

// Static constexpr table AUTO-GENERATED from FOREACH_LIVE_READINESS_CHECK:
template <int F>
static constexpr LiveReadinessCheck<F> kLiveReadinessChecks[] = {
    #define X(name_id, fn_ptr, severity, fix_hint) \
        { #name_id, LiveReadinessCheck<F>::severity, fn_ptr<F>, fix_hint },
    FOREACH_LIVE_READINESS_CHECK(X)
    #undef X
    { nullptr, /*sentinel*/ LiveReadinessCheck<F>::S_REFUSE, nullptr, nullptr }
};

template <int F>
int LiveReadiness_Verify(const ControllerConfig<F>& cfg,
                        const EngineShardedState<F>& state) {
    // returns 0 on PASS; -1 on REFUSE; 1 on WARN-only
    if (cfg.trading_mode == TRADING_MODE_PAPER ||
        cfg.trading_mode == TRADING_MODE_SHADOW) {
        // Paper/shadow: WARN all failures; never REFUSE
        for (const LiveReadinessCheck<F>* c = kLiveReadinessChecks<F>;
             c->name; ++c) {
            if (!c->fn(cfg, state)) {
                fprintf(stderr,
                    "[live_readiness] paper-mode WARN: %s failed. Fix: %s\n",
                    c->name, c->fix_hint);
            }
        }
        return 0;
    }
    // Live mode: REFUSE on REFUSE-severity failures; WARN on WARN-severity
    int refused = 0;
    int warned = 0;
    for (const LiveReadinessCheck<F>* c = kLiveReadinessChecks<F>;
         c->name; ++c) {
        if (!c->fn(cfg, state)) {
            if (c->sev == LiveReadinessCheck<F>::S_REFUSE) {
                fprintf(stderr,
                    "[live_readiness] LIVE REFUSE: %s failed. Fix: %s\n",
                    c->name, c->fix_hint);
                refused++;
            } else {
                fprintf(stderr,
                    "[live_readiness] live mode WARN: %s failed. Fix: %s\n",
                    c->name, c->fix_hint);
                warned++;
            }
        }
    }
    if (refused) {
        fprintf(stderr,
            "[live_readiness] LIVE REFUSED: %d critical pre-flight item(s) failed; "
            "engine will not start. Fix above and retry.\n", refused);
        return -1;
    }
    if (warned) {
        fprintf(stderr,
            "[live_readiness] live mode: %d WARN(s) — engine starts; review above\n",
            warned);
        return 1;
    }
    return 0;
}
```
