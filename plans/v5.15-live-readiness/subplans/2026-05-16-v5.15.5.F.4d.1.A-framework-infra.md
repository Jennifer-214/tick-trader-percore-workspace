### H16 compile-time static_assert (Step 5b)

Per v1.2 revision (registry-coverage-ci-check-pattern.md compile-time variant). Co-locate at `CoreFrameworks/CfgFieldRegistry.hpp` near the existing bitmap-overflow guard (line 212):

```cpp
// In CfgFieldRegistry.hpp after MetadataFlag enum + FOREACH_DERIVED_FILTER roster:

// Gather covered bits via X-macro reduction over FOREACH_DERIVED_FILTER:
#define X_GATHER_FILTER_BITS(NAME, VARIANT, METADATA_BIT, DOC) \
    | static_cast<uint16_t>(CfgFieldDescriptor::METADATA_BIT)
inline constexpr uint16_t COVERED_DERIVED_FILTER_BITS =
    (0 FOREACH_DERIVED_FILTER(X_GATHER_FILTER_BITS));
#undef X_GATHER_FILTER_BITS

// Consumer-side metadata bits exempt from derived-filter requirement
// (these are consumer-side metadata, not derived-filter sources):
inline constexpr uint16_t EXEMPT_FROM_DERIVED_FILTER =
    CfgFieldDescriptor::RESTART_REQUIRED
  | CfgFieldDescriptor::SAFETY_CRITICAL
  | CfgFieldDescriptor::DEPRECATED
  | CfgFieldDescriptor::HIDDEN_BY_DEFAULT
  | CfgFieldDescriptor::IS_SECRET
  | CfgFieldDescriptor::IS_BOOT_ONLY
  | CfgFieldDescriptor::AFFECTS_STAMP_PARITY
  | CfgFieldDescriptor::LOG_VALUE_FORBIDDEN
  | CfgFieldDescriptor::MANUAL_PARSER
  | CfgFieldDescriptor::WARN_ON_CLAMP
  | CfgFieldDescriptor::NO_FLAT_FIELD
  | CfgFieldDescriptor::STAMP_BOUND;  // legacy bit (transitional; .B migration uses both)

// All metadata bits in use (per static_assert at line 212; ≤ uint16_t):
inline constexpr uint16_t ALL_METADATA_BITS_IN_USE =
    CfgFieldDescriptor::RESTART_REQUIRED
  | CfgFieldDescriptor::SAFETY_CRITICAL
  | CfgFieldDescriptor::DEPRECATED
  | CfgFieldDescriptor::STAMP_BOUND
  | CfgFieldDescriptor::HIDDEN_BY_DEFAULT
  | CfgFieldDescriptor::IS_SECRET
  | CfgFieldDescriptor::IS_BOOT_ONLY
  | CfgFieldDescriptor::AFFECTS_STAMP_PARITY
  | CfgFieldDescriptor::LOG_VALUE_FORBIDDEN
  | CfgFieldDescriptor::MANUAL_PARSER
  | CfgFieldDescriptor::WARN_ON_CLAMP
  | CfgFieldDescriptor::NO_FLAT_FIELD
  | CfgFieldDescriptor::STAMP_BOUND_CFG_DERIVED;

// H16 compile-time enforcement — build fails if any in-use bit lacks coverage:
static_assert(
    (ALL_METADATA_BITS_IN_USE & ~(COVERED_DERIVED_FILTER_BITS | EXEMPT_FROM_DERIVED_FILTER)) == 0,
    "H16 violated: a CfgFieldDescriptor::MetadataFlag bit is in use but lacks "
    "a FOREACH_DERIVED_FILTER row AND isn't in EXEMPT_FROM_DERIVED_FILTER list. "
    "Add row to FOREACH_DERIVED_FILTER (consumer-side derived filter) OR add to "
    "EXEMPT_FROM_DERIVED_FILTER with rationale comment (consumer-side metadata "
    "not requiring a derived filter)."

```

**Why compile-time vs Python CI tool (per registry-coverage-ci-check-pattern.md compile-time variant):**
- Strictly stronger: build-fails (can't skip; Python CI can be bypassed)
- Single file (no separate tools/ script to maintain)
- Aligns with existing codebase discipline (X-macro static_asserts everywhere)
- Error message at static_assert site — easier to debug than parsing Python output
- Source data is X-macro-driven (FOREACH_DERIVED_FILTER + MetadataFlag enum); compile-time enumeration available

Note for `.F.4e` planning: when adding HIDDEN_BY_DEFAULT/RESTART_REQUIRED/SAFETY_CRITICAL/IS_SECRET/DEPRECATED derived filter consumers, MOVE those bits from EXEMPT_FROM_DERIVED_FILTER list to COVERED_DERIVED_FILTER_BITS (via FOREACH_DERIVED_FILTER row addition). H16 static_assert verifies the transition mechanically.

## DOD analysis (Data-Oriented Design per `framework-composition-overview.md`)

### Cluster placement
- `g_*_cfg_field_descriptors[]` — already in cold-init cluster (constexpr arrays; populated at compile time)
- Walker fn-pointer callback signature: `void (*per_row_fn)(size_t idx, const CfgFieldDescriptor& desc, void* ctx)` — 8-byte pointer (cache-line negligible)
- Canonical body emit buffer: stack-allocated `char[8192]` at test-call time (no heap; H1)

### Branchless dispatch
- Per-row metadata-bit check: `if ((descriptors[i].metadata_flags & METADATA_BIT) == 0) continue;` — single-branch per row; predictable pattern (most rows DON'T have the bit; pattern is dense-not-have-bit followed by sparse-have-bit)
- Per `branchless-dispatch-discipline.md` decision matrix: boot-time predicate is exempt from H20 branchless preference. Branch is fine here.

### Cache layout
- Walker accesses descriptor metadata + name fields linearly through array; sequential prefetch friendly
- Descriptor struct size: ~64 bytes (cache-line); 1 descriptor per cache line; 213 fields × 64 bytes = ~14KB total; fits in L1 cache
- Walker cost at boot: ~213 × 1-2ns = ~400ns total per walk; once per filter invocation; negligible

### Bit-packing
- `metadata_flags` is `uint16_t` per H14 manual bit-packing discipline; 13 bits used + 3 bits headroom (per `CfgFieldRegistry.hpp:212` static_assert)
- `STAMP_BOUND_CFG_DERIVED = 1u << 13` is the 13th bit (bit 13); within uint16_t capacity

## Anti-patterns to avoid

### Class 18 (mirror-incomplete) — DON'T duplicate the walker logic
The walker is **registry-driven** — it reads from `g_*_cfg_field_descriptors[]` which is THE source of truth. DON'T copy walker bodies across the 3 macro variants; share via inner helper (`_walk_filtered_rows_impl`).

### DON'T reintroduce LOCKED-constant or fixture-file snapshot mechanism (Option F revision)
The original `.F.4d` draft of `wire-format-byte-preservation-discipline.md` § 5b proposed a LOCKED-constant hash mechanism. Caramel's "magic number" pushback caught the Class 18 mirror at the hash-constant layer. Per the codified rule "**Registries optimize for ADDING; principle + sweep optimizes for ELIMINATING**" (set 2026-05-15), the snapshot-as-lock mechanism is the wrong shape. Use structural invariant tests instead.

### Class 21 (parallel descriptors) — DON'T introduce a `FOREACH_STAMP_BOUND_CFG_DERIVED` literal X-macro
The DERIVED filter is computed at runtime via the walker; there is NO parallel X-macro for it. Adding one would create exactly the Class 21 anti-pattern this framework is structurally closing.

### Class 23 (type-erased reinterpret_cast) — DON'T use void*+offset in framework
Walker callback signature passes `const CfgFieldDescriptor&` (typed reference, NOT void*+offset). Synthetic populate at `.B` will dispatch via `tt::cfg_emit_synthetic_field<T>` (existing `tt::` namespace dispatch per H13).

### Class 14 (plan API drift) — DON'T reference functions/macros that haven't shipped
Pre-coding audit gate (Step 2 of handoff) will catch this. All file:line refs in this plan body are verified at draft time against `545b087` HEAD per `feedback_compaction_degrades_treat_handoffs_as_hints`.

### Wire-format byte preservation (per H9 + `wire-format-byte-preservation-discipline.md`)
Locale pinning is THREAD-LOCAL via `uselocale` (per `ModelInference.hpp:1697` precedent). NOT `setlocale`. `setlocale` is process-wide and thread-unsafe; can corrupt other threads. Invariant I3 verifies the body contains no `,` decimal separator — drift in locale-pin behavior detected via this invariant.
