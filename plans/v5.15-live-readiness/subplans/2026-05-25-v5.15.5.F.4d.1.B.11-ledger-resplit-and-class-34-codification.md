### Decision D — Class 34 codification scope

NEW anti-pattern Class 34: "File-size threshold violations as structural-discipline indicator"

**Codification content** (per `ledger-entry-templates.md` § Bug Class entry):

- **Definition:** Files exceeding `file-size-split-discipline.md` hard threshold without applied split discipline; sub-class: ledger files growing past threshold without sub-split
- **Detection signature:** Per file-type thresholds — `find . -name "*.hpp" -exec wc -l {} \; | awk '$1 > 1500'` (header); `find . -name "*.cpp" -exec wc -l {} \; | awk '$1 > 2000'` (body); `find tests -name "*.cpp" -exec wc -l {} \; | awk '$1 > 5000'` (test); `wc -l DOCS/tech-debt/*.md | awk '$1 > 2000'` (ledger)
- **Why it matters:** Cognitive load when navigating; harder to spot inter-file mirrors; CI checks become bypassable as files grow; smaller files = smaller grep surface = faster diagnostics; per-file responsibility clearer
- **Worked examples (from `.B.5`-`.B.10` closures):** 13 source headers (TECH_DEBT-029) + 1 test file (TECH_DEBT-114) + 1 ledger sub-file (TECH_DEBT-029 sister at THIS ship) — all closed at this umbrella
- **False-positive surface (per M3 discipline):** files monolithic by design (`Limits.hpp`, `Version.hpp`, `MemHeaders/BitmapMacros.hpp`); auto-generated files; single-purpose cohesive units where split would fragment
- **Detection cadence:** `/metadata-audit` quarterly per existing skill spec + at ship close per `/ship` skill discipline; CI tool `check_file_sizes.py` candidate at future ship (NEW TECH_DEBT-NN if proposed at this ship)
- **Resolution mechanism:** Apply `file-size-split-discipline.md` v1.1 — subfolder pattern for headers expected to grow; flat-sibling for simpler 2-3 way splits; per-cohort split for ledgers
- **Related classes:** Class 18 (Mirror state/code) — file-size violations make mirror surface harder to track; Class 21 (Multiple parallel descriptors) — large files often have parallel sections that should be unified or split

**Cross-references at codification:**
- `DESIGN_SPECS/doc-disciplines/file-size-split-discipline.md` v1.1 (the discipline)
- `DESIGN_SPECS/refactor-patterns/canonical-sister-extension-discipline.md` (split patterns mature via cohort applications)
- Memory: `feedback_file_size_split_discipline` + `feedback_dont_measure_structural_work_by_loc`
