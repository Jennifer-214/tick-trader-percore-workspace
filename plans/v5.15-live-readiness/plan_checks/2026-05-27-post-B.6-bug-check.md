## NEW findings (triage candidates)

### NEW-1 — Class 26 HIGH — `CoreFrameworks/EngineSharded/Async.hpp:814`

**Symptom:** `cfg.cores[i].partial_exit_pct` — `i` is the inner ring-pop counter `for (int i = 0; i < MAX_EVENTS_PER_DRAIN_PER_CORE; ++i)` (loop variable at line 768), NOT a per-core index. Should be `cfg.cores[slot].partial_exit_pct` to match the surrounding correct usage at line 812 `cfg.core_overrides[slot]` + the comment "per-core fee_rate cluster" at line 805.

**Context:** Drainer-thread `drain_with_submit` body (hoisted into `EngineSharded_Async_DrainWithSubmit`). The line snippet:

```cpp
const auto& ov_slot = cfg.core_overrides[slot];               // line 812: correct slot
FPN<F> partial_pct = !FPN_IsZero(ov_slot.partial_exit_pct)
    ? ov_slot.partial_exit_pct : cfg.cores[i].partial_exit_pct;  // line 814: WRONG index
```

**Root cause:** Mechanical migration at commit `ea08210` (v5.15.5.F.4c.3 Phase 2 — "18 mechanical migrations"). The migration replaced `cfg.partial_exit_pct` (global) with `cfg.cores[i].partial_exit_pct` (per-core), but the surrounding scope's `i` variable is the inner ring-pop counter, not the outer `slot` counter. Silent value-flatten when partial_exit_pct differs across cores — fall-through to wrong core's per-core value, or possibly out-of-bounds when `i` exceeds num_cores (uses raw `cores[]` array; len = MAX_PORTFOLIO_POSITIONS = 16 so doesn't crash but reads stale init data for high i).

**Severity:** HIGH — silent partial-exit miscalibration; effect masked when (a) all cores use same partial_exit_pct (value-equivalent) OR (b) core_overrides[slot].partial_exit_pct is nonzero (override path taken). Surfaces only when operator sets DIFFERENT per-core partial_exit_pct with NO override.

**Fix shape:** `cfg.cores[i]` → `cfg.cores[slot]` (1-char correction). Sister to `.B.4` Cx-cohort Class 26 closure shape.

**Codebase blast radius:** This Async.hpp file is the producer/drainer asynchronous path; effect is per-fill at entry-construction time; affects all entry orders during partial-on phase.
