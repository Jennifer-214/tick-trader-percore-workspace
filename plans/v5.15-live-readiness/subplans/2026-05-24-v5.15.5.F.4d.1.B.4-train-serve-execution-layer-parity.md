### Decision B — Per-call-site exemption handling

Backtest + live boot/slow-path-cycle aren't 100% identical. Legitimate exemptions need to be handled in the helper signature without forcing artificial uniformity.

| Mechanism | When to use | Example |
|---|---|---|
| **Nullable state args** | Genuinely-absent state on one side | `oms == nullptr` skips OMS-dependent work in backtest variants without OMS |
| **cfg flag branches at boot time** | Runtime-mode branching that's boot-frozen | `cfg.engine_arch == ENGINE_ARCH_PER_CORE_SLOW` vs `CENTRALIZED` |
| **Conditional compile** | Build-flag-driven differences | `#ifdef LATENCY_PROFILING` |
| **External wrapper** | Operator-explicit overrides that don't fit shared shape | `bandit_state_prior_path` override called AFTER `EngineCommon_BootPerCore` returns |

**Anti-pattern to avoid:** Adding cfg flags that DUPLICATE existing cfg semantics just to encode "live vs backtest" — that's a Class 24 capability-cfg surface mismatch. Use cfg flags only when the cfg semantic GENUINELY differs.

## Pre-coding concerns (informational; resolve during Phase A audit gate)

1. **Helper signature stability** — Per-call-site differences may require >3-4 nullable args or cfg flag branches. If signature grows unwieldy, refactor first OR accept some individual patches.
2. **Boot order preservation** — `EngineSharded_Run` boot has subtle ordering (e.g., `Strategy_InitPerCore` AFTER `ConfidenceScorer_Init` AFTER `EventLoopState_Init`). Helper must preserve order; per-call-site exemptions can't reorder.
3. **HMAC byte preservation** — `Stamp_AssembleAndEmit` path is downstream of boot. Helper extract MUST NOT change cfg state read by stamp emit; canonical body byte preservation invariant verified at Phase C.5.
4. **Thread isolation** — EngineSharded boot spawns threads; BacktestSharded doesn't. `EngineCommon_BootPerCore` MUST be thread-safe at the per-core boundary (already is — no shared state writes to global; per-core scoped).
5. **`bandit_state_prior_path` exemption** — per Decision B (d), handled via external wrapper called AFTER helper returns. Not in helper signature.
6. **Per-core regime state per PARITY-031** — `EngineCommon_SlowPathCycleOneCore` populates per-core regime; backtest's `fc_ctx.regime_state` becomes `[MAX_EXECUTION_CORES]` array. ~30 LOC additional in backtest-side wiring (not the helper itself).
7. **CI tool defer** — Compile-time enforcement of `EngineCommon_*` API discipline is preferred over Python tool per `registry-coverage-ci-check-pattern.md`; specific mechanism (static_assert / TT_ASSERT_HELPER_API_STABLE / etc.) decided during Phase D.
