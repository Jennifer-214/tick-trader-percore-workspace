# `.E.0.1` / `.E.0.3` new-function designs — for the design-audit gate

**Path calibration (read first):** every function here is on a **boot / stamp-time / parse path — NOT the 500ns branchless hot path.** So **H11 + DOD apply** (layout, alloc-free, branch-minimal, fast core) but **H7-strict-branchless does NOT** — a canonicalizer and a parser have inherent loops + error branches; forcing them branchless would be cargo-cult. The audit should judge them by DOD/clean/fast, not by hot-path branchlessness.

## D1 — `Fingerprint_CanonicalizeConfig` (`.E.0.1`; F-076 / H12)

Deterministic, padding-free, locale-independent byte image of `ControllerConfig<F>` for SHA-256. Replaces the current raw-struct SHA (`Fingerprint.hpp:180`) that hashes uninitialized padding.

```cpp
// Boot/stamp-time. Field-wise → a packed canonical byte stream (no padding ever enters the hash).
template<int F>
static inline size_t Fingerprint_CanonicalizeConfig(uint8_t* buf, size_t cap,
                                                     const ControllerConfig<F>* c) {
    size_t off = 0;
    auto put = [&](const void* p, size_t n) { /* assert(off+n<=cap); */ memcpy(buf+off, p, n); off += n; };
    auto put_str = [&](const char* s) {                       // char[]: length-prefixed, strnlen-bounded
        uint32_t n = (uint32_t)strnlen(s, MAX_CFG_STR);        //   → trailing garbage after '\0' never enters the hash
        put(&n, sizeof n); put(s, n);
    };
    auto put_fpn = [&](const FPN<F>& v) { put(v.w, sizeof v.w); put(&v.sign, sizeof v.sign); }; // RAW LIMBS, never ToDouble

    // FIXED field order = the canonical SSoT (one writer; self-consistent).
    put(&c->int_field_a, sizeof c->int_field_a);
    put_fpn(c->fee_rate);            // bundle invariant: hash fee_rate (stored), NOT maker/taker (derived) — ControllerConfig.hpp:369-370
    put_str(c->symbol);
    for (int i = 0; i < NUM_CORES; ++i) { /* per-core fields, field-wise, same discipline */ }
    return off;                      // caller: SHA256(buf, off)
}

// COVERAGE SENTINEL — add a field to ControllerConfig<F> → sizeof changes → this fails → forces updating the canonicalizer.
static_assert(sizeof(ControllerConfig<64>) == EXPECTED_CFG_SIZE,
              "ControllerConfig<64> changed: update Fingerprint_CanonicalizeConfig field list + bump EXPECTED_CFG_SIZE");
```

**Design decisions for audit:** (a) explicit field-wise (NOT `FOREACH_CFG_FIELD` — retired `.F.4c.3`, reaches ~55/200+ flat + 0 `cores[]`); (b) `static_assert(sizeof==EXPECTED)` is the only thing forcing field-coverage — is that sufficient, or do we also need a field-COUNT or offset sentinel? (c) length-prefixed strings vs fixed-width — chosen length-prefix to avoid hashing trailing garbage; (d) raw FPN limbs (exact, deterministic) vs ToDouble (lossy) — raw chosen.

## D2 — `tt::` error-detecting parse family (`.E.0.3`; the `*to*`-call solution)

Locale-immune (`from_chars` core) **+ error-exposing** (today's `atof` silently returns 0 on malformed → money corruption). Closes the silent-failure class.

```cpp
struct ParseD { double value; bool ok; };           // DOD: returned by value (register pair) — no out-param aliasing
static inline ParseD parse_double_checked(const char* s, size_t n) {
    double d; auto r = std::from_chars(s, s+n, d);
    bool ok = (r.ec == std::errc{}) && (r.ptr == s+n);
    return { ok ? d : 0.0, ok };
}
template<class T> struct ParseI { T value; bool ok; };
template<class T>                                     // T = int32/int64/uint32/uint64 — signed+range checked by from_chars
static inline ParseI<T> parse_int_checked(const char* s, size_t n) {
    T v; auto r = std::from_chars(s, s+n, v);
    bool ok = (r.ec == std::errc{}) && (r.ptr == s+n);
    return { ok ? v : T{0}, ok };
}
// caller: auto p = tt::parse_double_checked(s,n); if (!p.ok) { /* halt / skip / default — per-site */ } use p.value;
```

**Design decisions for audit:** (a) by-value `ParseD`/`ParseI<T>` struct vs `bool + out-param` — chose by-value (DOD, fits registers, no aliasing); (b) keep the existing fast `parse_double_fast` (no error) for already-validated cursors, OR deprecate it in favor of `_checked`? (c) is `n` (explicit length) the right contract vs NUL-terminated; (d) the `_advance` variant (F-054/55) — does it also need a `_checked_advance`?

## Design-audit refinements (applied 2026-05-30 — `/hft` + `/dod` design gate)

Both auditors CONVERGED: designs SOUND + path **CONFIRMED COLD** (all 4 — H7-strict-branchless correctly does NOT apply; H11+DOD do) + correctly NOT cargo-cult-branchless. Reports: `plan_checks/E.0.1-audit-reports/dod-new-fn-designs-2026-05-30.md` + `hft-new-fn-designs-2026-05-30.md`.

**HIGH — gates D1 implementation (both flagged independently): coverage sentinel insufficient.** `static_assert(sizeof==EXPECTED)` is BLIND to a same-size field reorder/swap → a hand-written field list guarded only by a size-sentinel is **a NEW Class-18 mirror** (ironic: closing H12 with a Class-18). FIX: (a) per-field `offsetof` static_asserts on the load-bearing anchors (`fee_rate` / `symbol` / each FPN field); (b) a `registry-coverage-ci-check-pattern` CI as the structural close, keyed on `file:symbol:line` (NOT bare counts). **Same swap-blindness fix → D4 allowlist** (key on `file:symbol:line` + a monotonic-shrink assertion).

**MED — D1 `cap` bounds check must be REAL** (not the commented `// assert`): stamp-path overrun = corrupted hash + smashed stack. (Boot/stamp-time → asserting is fine; H7 doesn't apply.)

**Confirmed SOUND (no change):** D2 by-value `ParseD`/`ParseI<T>` (register-pair, no aliasing — ABI-confirmed, strictly beats bool+out-param); **keep BOTH** `parse_double_fast` (trusted/validated cursor) + `_checked` (untrusted → silent-0 guard) — distinct contracts, not redundancy; raw FPN limbs (exact, NOT ToDouble); fee_rate bundle invariant preserved (`ControllerConfig.hpp:367-370`); manual field-wise canonicalizer is correct (verified: `FOREACH_GLOBAL_CFG_FIELD`=55 of ~148 flat + 0 `cores[]` → no registry enumerates the hashable set).

**LOW:** `NUM_CORES`→`MAX_EXECUTION_CORES`=16 (`Limits.hpp:19`); define `EXPECTED_CFG_SIZE`/`MAX_CFG_STR`; serialize ALL `MAX_EXECUTION_CORES` slots unconditionally (no `if(active)` break — position-stable bytes, H11); `from_chars` has no `bool` overload (don't route bool through `parse_int_checked`); add `_checked_advance` to the `.E.0.3` family only where an untrusted advancing cursor exists (BanditLearning JSON load).

**Canonical sister:** EXTEND `struct-padding-determinism-pattern.md` (add a canonicalize-to-stream sibling) + `registry-coverage-ci-check-pattern.md` — NOT author-new (>50% overlap). ⚠ one auditor found `struct-padding-determinism-pattern.md` absent → verify the exact spec name at codification (extend vs first-canonical).

**Operator "branchless?" answer (precise):** NO — and correctly so (cargo-cult to force it on a parser/canonicalizer). The branchlessness that matters is the DATA LAYOUT (packed byte-stream + register-pair `ParseD` return), which the designs HAVE. Fast + DOD + cold-budget-safe.
