## Framework genericity audit (the substantive work)

### Audit checklist (verify FOREACH_EXCHANGE is truly generic)

Per `feedback_enumerate_consumers_before_registry_row_deletion` + `feedback_categorical_triggers_over_hardcoded_refs`:

**1. Hardcoded "binance" string references:**
```bash
rg -i 'binance' --type cpp --type hpp | grep -v 'comment' | grep -v 'log'
```
Each hit: classify as legitimate (cfg-driven name; log message) vs leak (framework code hardcoding behavior).

**2. Hardcoded WS endpoints:**
```bash
rg 'wss://' --type cpp --type hpp
```
Should all be in BinanceAdapter; framework should not reference specific WS URLs.

**3. Hardcoded HMAC discipline:**
```bash
rg 'hmac_sha256\|HMAC' --type cpp --type hpp
```
HMAC is Binance auth flavor; should be encapsulated in BinanceAdapter; framework dispatch should not assume HMAC.

**4. Hardcoded rate-limit values:**
```bash
rg '1200\b' --type cpp --type hpp
```
Should be FOREACH_EXCHANGE row metadata column (rate_per_min); not hardcoded constants in framework code.

**5. Hardcoded order field formats:**
```bash
rg 'GTC\|IOC\|FOK\|MARKET\|LIMIT' --type cpp --type hpp
```
Each exchange has different order type vocabulary; should be per-adapter dispatch.

**Expected findings + fixes:**
- 10-30 hits typically; most legitimate (BinanceAdapter encapsulation); 1-3 leaks to refactor

### Market-hours handling

```cpp
// CoreFrameworks/MarketHours.hpp (NEW)

enum MarketHoursKind {
    MARKET_HOURS_ALWAYS    = 0,    // crypto (Binance)
    MARKET_HOURS_US_EQUITIES = 1,  // Alpaca (9:30am-4pm ET; weekdays; holidays-aware)
    MARKET_HOURS_FUTURES    = 2,   // CME (24/5; weekends closed; specific session hours)
    MARKET_HOURS_FOREX      = 3,   // 24/5 (open Sun 5pm ET to Fri 5pm ET)
};

bool MarketHours_IsOpen(MarketHoursKind kind, uint64_t now_us) {
    switch (kind) {
        case MARKET_HOURS_ALWAYS: return true;
        case MARKET_HOURS_US_EQUITIES: return USEquities_IsOpen(now_us);
        case MARKET_HOURS_FUTURES: return Futures_IsOpen(now_us);
        case MARKET_HOURS_FOREX: return Forex_IsOpen(now_us);
    }
    return false;
}

bool USEquities_IsOpen(uint64_t now_us) {
    // Convert to ET timezone
    struct tm et_time;
    UsToEasternTime(now_us, &et_time);

    // Weekend check
    if (et_time.tm_wday == 0 || et_time.tm_wday == 6) return false;

    // Holiday check (TODO: load from cfg or external feed)
    if (USHoliday_IsHoliday(&et_time)) return false;

    // Time-of-day check
    int minutes_into_day = et_time.tm_hour * 60 + et_time.tm_min;
    int market_open = 9 * 60 + 30;            // 9:30 AM ET
    int market_close = 16 * 60;                // 4:00 PM ET

    return minutes_into_day >= market_open && minutes_into_day < market_close;
}
```

### Per-node slow-path market-hours check

```cpp
void NodeSlowPath_Cycle(NodeState<F>& node) {
    // Kill switch check (from .E.1)
    if (KillSwitch_NodeStopped(node)) {
        NodeSlowPath_HandleKilled(node);
        return;
    }

    // NEW at .E.6: market-hours check
    uint32_t cluster_id = node.binding.cluster_id;
    ClusterState<...>& cluster = g_state.clusters[cluster_id];
    if (!MarketHours_IsOpen(cluster.market_hours_kind, NowUs())) {
        // Market closed; skip trading but drain queues for safety
        NodeSlowPath_DrainQueuesOnly(node);
        usleep(60 * 1000 * 1000);  // sleep 1min (cfg-overridable)
        return;
    }

    // Normal slow-path cycle (existing)
    NodeSlowPath_DrainHotToSlow(node);
    NodeSlowPath_DrainFillEvents(node);
    NodeSlowPath_DrainManualCloses(node);
    NodeSlowPath_PostFillBookkeeping(node);
    NodeSlowPath_RebuildStrategy(node);
    NodeSlowPath_TimeExit(node);
    NodeSlowPath_TrailingSLRatchet(node);
}
```

## Honest risks

### R1 — Alpaca API semantics differ from Binance
Different auth (no HMAC); different submit body schema; different fill notification protocol.

**Mitigation:** AlpacaAdapter encapsulates differences; tt:: dispatch handles per-exchange variation; testnet integration test thorough.

### R2 — Holiday handling complexity
US market holidays vary year-to-year; need feed or hardcoded calendar.

**Mitigation:** Static holiday table for current year + next; cfg-overridable for testing; update annually.

### R3 — Time-zone handling
Engine timestamps in UTC; market hours in ET. Conversion error risk.

**Mitigation:** Standard tz library (zoneinfo); thoroughly tested; specific test cases (DST transitions; etc.).

### R4 — Pattern Stage 4 promotion may surface FOREACH_EXCHANGE gaps
Framework didn't anticipate some Alpaca-specific quirks (e.g., trade-stream message types).

**Mitigation:** Sister-cohort-amendment-completeness discipline; amend FOREACH_EXCHANGE metadata if needed; document as sub-shape.
