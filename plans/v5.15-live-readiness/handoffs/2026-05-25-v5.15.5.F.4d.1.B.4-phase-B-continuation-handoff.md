                               int c,

**Option β (recommended):** Add per-core ring + per-core core as reference args:
```cpp
template <int F>
void EngineCommon_BootPerCore(const ControllerConfig<F>& cfg,
                               int c,

                               SPSCRing<Tick<F>, EXECUTION_CORE_TICK_RING_SIZE>& tick_ring,
                               ExecutionCore<F>& core);
```
Caller indexes once: `BootPerCore(cfg, c, state, oms, tick_rings[c], cores[c])`. Type-safe; clear API.

**Option γ:** Helper does ONLY non-static-array calls; caller does SPSCRing_Init + ExecutionCore_Init + EventLoopState_RegisterCore + EventLoopState_SetCoreStrategy inline. BootPerCore handles only :931+ (ML branch) + :1136-1173 (ConfidenceScorer + RollingTurnover + Strategy_InitPerCore + ExecutionCore_SetPermission). Smaller helper but split surface.

**Option δ:** Helper takes pointer to whole arrays: `tick_rings[]` + `cores[]`. Pointer-to-array semantic is awkward; rejected per Decision H (reference args).

My recommendation: **Option β**. Consistent with Decision H + cleanest API + closes Class 18 mirror fully (all per-core calls in shared helper).
