## Step 1 — Add `is_FPN_v` type trait (5 min)

**File:** `FixedPoint/FixedPointN.hpp` (Edit; co-locate with `FPN<F>` primary template at line 31)

```cpp
// Type trait for FPN<F> detection in templated dispatchers.
// Used by tt::cfg_parse_field<T> / tt::cfg_save_field<T> to dispatch
// to FPN-specific branches (FPN_FromDouble + clamp + percent scaling)
// vs. raw double. Critical for closing Class 23 (DOCS/RECURRING_BUG_PATTERNS.md):
// without this trait, registry-driven cfg dispatch can't safely
// distinguish FPN<F> fields from raw double fields, leading to
// type-erased reinterpret_cast corruption.
//
// Precedent: std::is_array_v / std::is_floating_point_v from <type_traits>;
// this trait extends the family to FPN<F> for codebase-specific dispatch.
template <typename T> struct is_FPN : std::false_type {};
template <unsigned F> struct is_FPN<FPN<F>> : std::true_type {};
template <typename T> inline constexpr bool is_FPN_v = is_FPN<T>::value;
```

**Verification at end of Step 1:** trait compiles + `is_FPN_v<FPN<64>>` evaluates to `true`, `is_FPN_v<double>` to `false`. Add to `tests/controller_test.cpp` as a `static_assert`:

```cpp
static_assert(is_FPN_v<FPN<64>>, "is_FPN_v should detect FPN<F>");
static_assert(!is_FPN_v<double>, "is_FPN_v should reject double");
static_assert(!is_FPN_v<int>, "is_FPN_v should reject int");
```

### Descriptor design

```cpp
// CoreFrameworks/CfgFieldRegistry.hpp — NEW
//
// Single source of truth for cfg field declarations.
// All cfg consumers (parser, save/load, panel render, per-core override emission,
// drift check) derive from this registry via tt:: type-trait dispatch + AUTOPOPULATE walks.
//
// Class 23 prevention: this registry pairs with tt::cfg_*_field<T> dispatchers.
// X-macro extractors pass cfg field BY REFERENCE (cfg->name); T is deduced.
// NO void*+offset entry point exists. See DESIGN_SPECS/type-trait-dispatch-via-tt-namespace.md
// + DOCS/RECURRING_BUG_PATTERNS.md Class 23 + CLAUDE.md item 23.

struct CfgFieldDescriptor {
    // ─── Kind enum (uint8_t) — METADATA-ONLY, drives GUI presentation ───
    // NOTE: Kind does NOT drive type dispatch in the parser/save/render
    // helpers. Type dispatch happens via tt::cfg_*_field<T> with T deduced
    // from the destination field. Kind is purely for:
    //   - GUI render hint (slider vs textbox vs dropdown)
    //   - GUI format string (%.4f vs %.17g vs %d)
    //   - Percentage scaling (KIND_DOUBLE_PCT × 100 in display, ÷ 100 in storage)
    //   - Clamp coercion at parse time
    // The actual storage type comes from the cfg field's declaration in
    // ControllerConfig<F>; mismatches between Kind and field type are caught
    // at compile time by tt::cfg_*_field's type-family static_assert.
    enum Kind : uint8_t {
        KIND_DOUBLE       = 0,  // raw double or FPN<F>; clamp_min/max
        KIND_DOUBLE_PCT   = 1,  // double formatted as percent in GUI (×100 + "%" suffix); stored as fraction
        KIND_INT          = 2,  // signed/unsigned int with clamp (.F.4c)
        KIND_INT_ENUM     = 3,  // int with enum labels (radio/dropdown) (.F.4c)
        KIND_BOOL         = 4,  // 0/1; stored as scalar or bitmap bit (.F.4c)
        KIND_STRING       = 5,  // char[N] / std::string (.F.4d)
        KIND_FILE_PATH    = 6,  // string + file picker hint (.F.4d)
        // RESERVED for future:
        // KIND_RANGE_INT    = 7,  // hyperparameter sweep (v5.15.6.C)
        // KIND_RANGE_DOUBLE = 8,  // hyperparameter sweep (v5.15.6.C)
        // KIND_FPN          = 9,  // raw FPN<F> (rare; covered by KIND_DOUBLE today via is_FPN_v branch)
    };

    // ─── Metadata bitmap (uint16_t — 10 bits used; 6 headroom) ───
    enum MetadataFlag : uint16_t {
        PER_CORE_OK           = 1u << 0,   // emit per-core override (.F.4g consumer)
        RESTART_REQUIRED      = 1u << 1,   // GUI badge: "restart needed" (.F.4d render)
        SAFETY_CRITICAL       = 1u << 2,   // GUI warning + confirmation prompt (.F.4d)
        DEPRECATED            = 1u << 3,   // GUI: strikethrough + tooltip (.F.4d)
        STAMP_BOUND           = 1u << 4,   // include in stamp drift check + FOREACH_STAMP_BOUND_CFG_DERIVED filter (.F.4c)
        HIDDEN_BY_DEFAULT     = 1u << 5,   // GUI: collapsed section (.F.4d)
        IS_SECRET             = 1u << 6,   // password-masking in GUI; never logged (v5.15.6.B)
        IS_BOOT_ONLY          = 1u << 7,   // changes after boot are ignored — restart required (.F.4d)
        AFFECTS_STAMP_PARITY  = 1u << 8,   // training-time concern; bound to model stamp (.F.4c)
        LOG_VALUE_FORBIDDEN   = 1u << 9,   // value never appears in logs (privacy/security; v5.15.6.B)
        // ... ~6 bits headroom for future ...
    };

    // Bitmap overflow guard per DESIGN_SPECS/bitmap-overflow-protection-discipline.md
    // (Co-located static_assert in this header, after the enum):
    static_assert(LOG_VALUE_FORBIDDEN < (1u << 16),
                  "MetadataFlag bitmap overflowed uint16_t — upgrade to uint32_t");

    // ─── Storage discriminator — which cfg struct this field lives in ───
    // .F.4b only populates STRUCT_CFG rows; full enum declared for v5.15.6 forward-compat.
    enum LivesInStruct : uint8_t {
        STRUCT_CFG             = 0,  // engine.cfg → ControllerConfig<F>
        STRUCT_BACKTEST_CFG    = 1,  // backtest.cfg → BacktestCfg (.F.4i)
        STRUCT_CONTROLLER_CFG  = 2,  // controller.cfg → ControllerCfg (v5.15.6.A)
        STRUCT_SECRETS_CFG     = 3,  // secrets.cfg → SecretsCfg (v5.15.6.B)
        STRUCT_TRAINING_CFG    = 4,  // training cfg → TrainingCfg (v5.15.6.C)
    };

    // ─── Header (8 bytes) ───
    Kind          kind;             // 1 byte
    uint8_t       lives_in_struct;  // 1 byte (LivesInStruct enum value)
    uint16_t      metadata_flags;   // 2 bytes
    uint16_t      _reserved = 0;    // 2 bytes — future use; default-init to 0 per CLAUDE.md item 27
    uint16_t      field_idx;        // 2 bytes (FIELD_IDX_<name>; for sidecar-table lookup)

    // ─── String pointers (32 bytes) ───
    const char*   cfg_field_name;   // matches Cfg::<name>; used by parser strcmp + save key lookup
    const char*   label;            // GUI label (e.g. "TP %%")
    const char*   section;          // GUI section heading (e.g. "Trading")
    const char*   tooltip;          // GUI tooltip + cfg.example comment (multi-line via R"(...)" allowed)

    // ─── Categorical applicability masks (10 bytes — see categorical-tag-applicability-pattern.md) ───
    // Static-init values; GUI filters by `(applies_to_X & active_X_cats) != 0` per domain.
    // .F.4b initial values: applies_to_strategy_cat populated per-row; op_mode/regime/risk default to _CAT_ALL until v5.16.
    uint32_t      applies_to_strategy_cat;   // STRAT_CAT_* bitmap (32 max categories)
    uint16_t      applies_to_op_mode_cat;    // OP_MODE_CAT_* bitmap (16 max)
    uint16_t      applies_to_regime_cat;     // REGIME_CAT_* bitmap (default = REGIME_CAT_ALL until v5.16)
    uint16_t      applies_to_risk_cat;       // RISK_CAT_* bitmap (default = RISK_CAT_ALL until v5.16)

    // ─── Runtime cfg gating (8 bytes) ───
    const char*   requires_cfg;     // gating expression ("bandit_algorithm == THOMPSON"); null if always applicable

    // ─── Payload union (32 bytes — clamp_min/max inline; no sparse-table indirection) ───
    // Size budget: 24 bytes used by widest variant (as_double or as_int); padded to 32 for alignment.
    union {
        struct { double default_val; double clamp_min; double clamp_max; }                                              as_double;   // KIND_DOUBLE, KIND_DOUBLE_PCT
        struct { int64_t default_val; int64_t clamp_min; int64_t clamp_max; }                                           as_int;      // KIND_INT
        struct { int default_val; const char* const* labels; uint8_t count; uint8_t _pad[3]; uint64_t _pad2[2]; }       as_int_enum; // KIND_INT_ENUM
        struct { uint8_t default_val; uint8_t _pad[7]; uint64_t _pad2[3]; }                                             as_bool;     // KIND_BOOL
        struct { const char* default_val; size_t buf_len; uint64_t _pad[2]; }                                           as_string;   // KIND_STRING, KIND_FILE_PATH
    } payload;

    // ─── End: total = 8 + 32 + 10 + 8 + 32 = 90 bytes used + 38 bytes padding to 128 ───
};

// Cache-line budget assert per latency-vs-cache-decision-framework.md.
// Cfg metadata is read at boot (parser) + 60 Hz (GUI render) — neither is
// latency-critical. 128B (2 cache lines) accepts inline clamp_min/max for
// simpler structure; sparse-table indirection unnecessary at this access cadence.
static_assert(sizeof(CfgFieldDescriptor) <= 128,
              "CfgFieldDescriptor must fit two cache lines (128B). "
              "Cache impact is hygiene-level (GUI render is 60 Hz, cache-warm). "
              "See DESIGN_SPECS/latency-vs-cache-decision-framework.md.");
```

## Step 3 — Create `CfgFieldDispatch.hpp` with tt:: type-trait dispatch (3-barrier structural fix; ~180 LOC)

**File:** `CoreFrameworks/CfgFieldDispatch.hpp` (NEW; sister to CfgFieldRegistry.hpp)

**This step IS the structural fix for Class 23.** Three barriers in concert make the type-erased reinterpret_cast anti-shape unreachable:
- **Barrier 1 (API surface):** ONLY templated overloads with destination-by-reference exist. NO void*+offset variant.
- **Barrier 2 (X-macro extractor chokepoint):** the registry consumer macros call `tt::cfg_*_field(cfg->name, ...)`; T is deduced from the field declaration.
- **Barrier 3 (compile-time type-family guard):** `static_assert` in each tt:: function fails build if T isn't in the recognized family.

```cpp
// CoreFrameworks/CfgFieldDispatch.hpp — NEW
//
// 3-barrier structural fix for Class 23 (type-erased reinterpret_cast dispatch).
// Mirrors the canonical pattern at ML_Headers/StampBoundModelConstRegistry.hpp:101-124
// (tt::stamp_parse_field<T>). Required precedent: CLAUDE.md item 23 + DESIGN_SPECS/type-trait-dispatch-via-tt-namespace.md.

#pragma once
#include "../FixedPoint/FixedPointN.hpp"  // is_FPN_v + FPN_FromDouble + FPN_ToDouble
#include "CfgFieldRegistry.hpp"
#include <cstdlib>     // strtoull, atoi
#include <cstring>     // strncpy, strchr
#include <cstdio>      // snprintf
#include <type_traits> // std::is_floating_point_v, std::is_integral_v, std::is_array_v, std::is_unsigned_v
#include <algorithm>   // std::clamp
#include <locale.h>    // newlocale, uselocale, freelocale (Layer 2 locale pinning)

namespace tt {

    // Forward-declared parse_double_fast (definition lives in ModelInference.hpp's
    // namespace tt; same precedent as StampBoundModelConstRegistry.hpp:97-99).
    inline double parse_double_fast(const char* s);

    //==================================================================
    // PARSE: text → typed cfg field
    //==================================================================
    template <typename T>
    inline void cfg_parse_field(T& dst, const CfgFieldDescriptor& desc, const char* val) {
        // BARRIER 3: compile-time type-family guard. Adding a cfg field of an
        // unrecognized type FAILS THE BUILD here, forcing a deliberate decision
        // (extend tt::cfg_parse_field<T> with a new branch) rather than silent
        // truncation via type-erased reinterpret_cast.
        static_assert(is_FPN_v<T>
                   || std::is_floating_point_v<T>
                   || std::is_integral_v<T>
                   || std::is_array_v<T>,
                      "cfg field type not in recognized family — "
                      "extend tt::cfg_parse_field<T> with a new branch before "
                      "using this T as a cfg field. See "
                      "DESIGN_SPECS/type-trait-dispatch-via-tt-namespace.md.");

        if constexpr (is_FPN_v<T>) {
            // FPN<F>: parse double, apply percent scaling if KIND_DOUBLE_PCT,
            // clamp to descriptor range, convert to FPN<F>.
            double v = parse_double_fast(val);
            if (desc.kind == CfgFieldDescriptor::KIND_DOUBLE_PCT) {
                v /= 100.0;  // operator types "15.0" → stored as 0.15
            }
            v = std::clamp(v, desc.payload.as_double.clamp_min, desc.payload.as_double.clamp_max);
            // Use T::F to instantiate FPN_FromDouble at the right F.
            // Pattern: FPN<F>::FRAC_BITS exposes the template parameter; if
            // FPN doesn't expose this, infer via decltype trickery.
            // T::F is exposed via `static constexpr unsigned F = FRAC_BITS;`
            // added to FPN<F> primary template at Step 1 (FixedPoint/FixedPointN.hpp).
            dst = FPN_FromDouble<T::F>(v);
        } else if constexpr (std::is_floating_point_v<T>) {
            double v = parse_double_fast(val);
            if (desc.kind == CfgFieldDescriptor::KIND_DOUBLE_PCT) v /= 100.0;
            v = std::clamp(v, desc.payload.as_double.clamp_min, desc.payload.as_double.clamp_max);
            dst = static_cast<T>(v);
        } else if constexpr (std::is_array_v<T>) {
            strncpy(dst, val, std::extent_v<T> - 1);
            dst[std::extent_v<T> - 1] = '\0';
        } else if constexpr (std::is_unsigned_v<T>) {
            // Decimal default; .F.4c may extend with hex base detection if needed.
            dst = static_cast<T>(strtoull(val, nullptr, 10));
        } else { // signed integral
            int64_t v = atoi(val);
            v = std::clamp(v, desc.payload.as_int.clamp_min, desc.payload.as_int.clamp_max);
            dst = static_cast<T>(v);
        }
    }

    //==================================================================
    // SAVE: typed cfg field → text buffer (operator-friendly format)
    //==================================================================
    // Returns chars written (snprintf semantics). Caller routes the buffer
    // through cfg_write_field(path, key, buf) for comment-preserving save UX.
    template <typename T>
    inline int cfg_save_field(const T& src, const CfgFieldDescriptor& desc, char* buf, size_t cap) {
        static_assert(is_FPN_v<T>
                   || std::is_floating_point_v<T>
                   || std::is_integral_v<T>
                   || std::is_array_v<T>,
                      "cfg field type not in recognized family — "
                      "extend tt::cfg_save_field<T> with a new branch.");

        // LAYER 2 LOCALE PINNING per wire-format-byte-preservation-discipline.md.
        // Status-quo SettingsPanel save uses raw snprintf which honors LC_NUMERIC;
        // a stamp emitted under de_DE produces "0,55" not "0.55" → HMAC chain
        // breaks. tt:: dispatch pins per-thread to LC_NUMERIC=C; restores before return.
        // Precedent: MemHeaders/RunHistory.hpp:87-89.
        locale_t pinned = newlocale(LC_NUMERIC_MASK, "C", (locale_t)0);
        locale_t prev = (locale_t)0;
        if (pinned) prev = uselocale(pinned);

        int n = 0;
        if constexpr (is_FPN_v<T>) {
            double v = FPN_ToDouble(src);
            if (desc.kind == CfgFieldDescriptor::KIND_DOUBLE_PCT) v *= 100.0;
            // GUI-friendly format per Kind:
            const char* fmt = (desc.kind == CfgFieldDescriptor::KIND_DOUBLE_PCT) ? "%.4f" : "%.6g";
            n = snprintf(buf, cap, fmt, v);
        } else if constexpr (std::is_floating_point_v<T>) {
            double v = static_cast<double>(src);
            if (desc.kind == CfgFieldDescriptor::KIND_DOUBLE_PCT) v *= 100.0;
            const char* fmt = (desc.kind == CfgFieldDescriptor::KIND_DOUBLE_PCT) ? "%.4f" : "%.6g";
            n = snprintf(buf, cap, fmt, v);
        } else if constexpr (std::is_array_v<T>) {
            n = snprintf(buf, cap, "%s", src);
        } else if constexpr (std::is_unsigned_v<T>) {
            n = snprintf(buf, cap, "%llu", (unsigned long long)src);
        } else { // signed integral
            n = snprintf(buf, cap, "%lld", (long long)src);
        }

        if (pinned) {
            uselocale(prev);
            freelocale(pinned);
        }
        return n;
    }

    //==================================================================
    // RENDER: typed cfg field → Dear ImGui widget (returns true if changed)
    //==================================================================
    template <typename T>
    inline bool cfg_render_field(T& field, const CfgFieldDescriptor& desc) {
        static_assert(is_FPN_v<T>
                   || std::is_floating_point_v<T>
                   || std::is_integral_v<T>
                   || std::is_array_v<T>,
                      "cfg field type not in recognized family — "
                      "extend tt::cfg_render_field<T> with a new branch.");

        bool changed = false;
        // Implementation routed via existing CFG_FLOAT/INT/BOOL ImGui::InputText helpers
        // in SettingsPanel.hpp; .F.4b's render path emits the same widgets as the
        // pre-migration code path for byte-identical operator UX. Detailed render
        // body documented at SettingsPanel.hpp; this dispatch just selects type behavior.
        if constexpr (is_FPN_v<T>) {
            double v = FPN_ToDouble(field);
            if (desc.kind == CfgFieldDescriptor::KIND_DOUBLE_PCT) v *= 100.0;
            // ImGui::InputDouble or ::InputFloat with desc.label, format derived from Kind
            // [render impl details — Step 4]
            // changed = (user edit detected); if changed, dst = FPN_FromDouble<T::F>(v / scale)
        } else if constexpr (std::is_floating_point_v<T>) {
            // [render impl details]
        } else if constexpr (std::is_array_v<T>) {
            // ImGui::InputText with std::extent_v<T> as buffer cap
        } else { // integral
            // ImGui::InputInt
        }
        return changed;
    }

}  // namespace tt
```

**Critical implementation notes (per audit synthesis):**

- **NO `offsetof` or `reinterpret_cast` in this file.** The whole point of Barrier 1.
- **NO `KIND` template parameter.** The previous draft used `template <Kind K>` with per-Kind specializations; the rewrite uses `template <typename T>` with T deduced from caller's field reference. This is the canonical pattern from `tt::stamp_parse_field<T>`.
- **`T::F` access:** assumes `FPN<F>` exposes `static constexpr unsigned FRAC_BITS = F;` in its primary template. If not exposed today, add it as a 1-line addition to `FixedPoint/FixedPointN.hpp` next to `is_FPN_v` (Step 1).

- **Don't optimize the descriptor lookup.** A flat array search is fine for ~250 entries; promote to perfect hash only if profiling shows it matters (won't — boot-only path).
- **Don't add CI script yet.** Until ALL fields migrated, parser has both registry + manual paths; CI script would false-flag. Add at .F.4d-or-later when manual paths gone.
- **Don't add new cfg fields during this migration.** Adding fields + migrating same time = harder bisect.
- **Don't lock Layer 5b hash at .F.4b.** Hash will rotate at .F.4c when INT entries land. Defer to .F.4c when full type coverage validates the locked-hash discipline.
- **Don't ship the X-macro-generates-Cfg-struct stretch goal.** Bytewise-incompatible struct layout risk + depends on full type dispatch validation; defer to .F.4d earliest (or drop entirely if not needed after reverse-drift CI script).
- **CRITICAL — Don't use `*reinterpret_cast<T*>((char*)cfg + offset) = v`.** That's the Class 23 anti-shape. The 3-barrier design eliminates it; if you're tempted to bypass, that's the bug class. ## If something goes wrong

- **Build fails on `static_assert(sizeof(CfgFieldDescriptor) <= 128)`:** the union grew too large. Drop the `clamp_min/max` from `as_double` (move to separate sparse table indexed by FIELD_IDX) OR pack categorical masks more aggressively. Likely cause: payload union variant declared with too much padding.
