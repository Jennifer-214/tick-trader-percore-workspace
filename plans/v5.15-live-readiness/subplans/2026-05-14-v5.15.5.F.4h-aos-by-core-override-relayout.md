```cpp
// AoS-by-core: ONE struct per core containing all override values + a single bitmap mask
template <unsigned F>
struct alignas(64) PerCoreOverrides {
    // ─── FPN<F> per-core override values (24B each; aim to fit ~2-3 cache lines) ───
    FPN<F>  bandit_blend_ratio;
    FPN<F>  ml_buy_threshold;
    FPN<F>  ml_tp_pct;
    FPN<F>  ml_sl_pct;
    FPN<F>  confidence_hard_block_threshold;
    FPN<F>  confidence_ic_floor;
    FPN<F>  momentum_min_tp_margin_pct;
    FPN<F>  exit_threshold;
    /* ... up to ~13 FPN<F> fields per .F.4a cohort audit (13 fields graduated to PER_CORE_OK) ... */

    // ─── INT/uint32_t per-core override values ───
    uint32_t lazy_rebuild_force_period_us;
    uint32_t recovery_delay_secs;
    uint32_t param_max_age_ticks;
    int32_t  bandit_algorithm;
    int32_t  risk_degradation_curve;
    int32_t  barrier_blend_mode;
    int32_t  confidence_ic_floor_window;
    /* ... INT/INT_ENUM PER_CORE_OK fields per .F.4a cohort ... */

    // ─── BOOL per-core overrides (packed into bitmap; saves space) ───
    uint8_t  momentum_require_last_win;
    /* ... BOOL PER_CORE_OK fields ... */

    // ─── Override-set bitmap (1 bit per field; uint64_t = 64 fields max) ───
    uint64_t override_set_mask;

    // ─── Padding to cache-line multiple ───
    uint8_t _pad[N];  // adjust to fit alignas(64) requirement
};

// Bit-position constants for override_set_mask (per-field bit assignments):
constexpr uint64_t OVERRIDE_BIT_BANDIT_BLEND_RATIO            = 1ull << 0;
constexpr uint64_t OVERRIDE_BIT_ML_BUY_THRESHOLD              = 1ull << 1;
constexpr uint64_t OVERRIDE_BIT_ML_TP_PCT                     = 1ull << 2;
constexpr uint64_t OVERRIDE_BIT_ML_SL_PCT                     = 1ull << 3;
/* ... one bit per PER_CORE_OK field; up to 64 ... */
constexpr int OVERRIDE_BIT_MAX_USED = 25;  // .F.4h refines based on PER_CORE_OK cohort
static_assert(OVERRIDE_BIT_MAX_USED < 64, "override_set_mask overflow uint64_t — split into two bitmaps");
```

**Cache budget verification:** `sizeof(PerCoreOverrides<64>)` must be a multiple of 64 (single cache line). Run pahole after struct definition to confirm. If ~25 fields × 24-byte FPNs exceeds 3 cache lines, pack INT/BOOL fields more tightly.

## Step 3 — Update `Cfg_GetEffective_<field>` accessors (~50 LOC)

For each PER_CORE_OK field, rewrite the accessor:

```cpp
// Before (SoA):
inline FPN<F> Cfg_GetEffective_bandit_blend_ratio(const Cfg* cfg, int core_idx) {
    return cfg->core_bandit_blend_ratio_override_set[core_idx]
           ? cfg->core_bandit_blend_ratio[core_idx]
           : cfg->bandit_blend_ratio;
}

// After (AoS-by-core):
inline FPN<F> Cfg_GetEffective_bandit_blend_ratio(const Cfg* cfg, int core_idx) {
    const auto& ov = cfg->per_core_overrides[core_idx];
    return (ov.override_set_mask & OVERRIDE_BIT_BANDIT_BLEND_RATIO)
           ? ov.bandit_blend_ratio
           : cfg->bandit_blend_ratio;
}
```

Cache locality win: accessing `cfg->per_core_overrides[core_idx].bandit_blend_ratio` + `.override_set_mask` both hit the SAME cache line (the line for core_idx). Previously each was a SCATTERED read.

```cpp
// Before (writes to scattered arrays):
if (sscanf(key, "core_%d_%s", &core_idx, field_name) == 2) {
    if (strcmp(field_name, "bandit_blend_ratio") == 0) {

        cfg->core_bandit_blend_ratio_override_set[core_idx] = 1;
    }

// After (registry-driven AoS):
if (sscanf(key, "core_%d_%s", &core_idx, field_name) == 2) {
    if (core_idx < 0 || core_idx >= 16) return;  // bounds check
    
    auto& ov = cfg->per_core_overrides[core_idx];
    
    #define EMIT_PER_CORE_PARSE(kind, name, label, section, meta, payload, tooltip, \
                                strat, op_mode, regime, risk, requires_cfg, lives_in) \
        EMIT_PER_CORE_PARSE_DISPATCH_##meta(kind, name, field_name, val, ov)
    
    #define EMIT_PER_CORE_PARSE_DISPATCH_HAS_PER_CORE_OK(kind, name, fn, val, ov_ref) \
        if (strcmp(fn, #name) == 0) { \
            tt::per_core_parse<CfgFieldDescriptor::KIND_##kind>(ov_ref, FIELD_IDX_##name, val); \
            (ov_ref).override_set_mask |= OVERRIDE_BIT_##name; \
            return; \
        }
    
    #define EMIT_PER_CORE_PARSE_DISPATCH_NO_PER_CORE_OK(kind, name, fn, val, ov_ref) \
        /* skip — not per-core eligible */
    
    FOREACH_CFG_FIELD(EMIT_PER_CORE_PARSE)
    #undef EMIT_PER_CORE_PARSE
}
```

## Step 5 — Migrate save (~30 LOC)

Cfg_Save (registry-driven from `.F.4d`) walks every per-core override + emits if set:

```cpp
void Cfg_Save_PerCoreOverrides(const Cfg* cfg, FILE* fp) {
    for (int core_idx = 0; core_idx < 16; core_idx++) {
        const auto& ov = cfg->per_core_overrides[core_idx];
        if (ov.override_set_mask == 0) continue;  // no overrides for this core
        
        #define EMIT_PER_CORE_SAVE(kind, name, label, section, meta, payload, tooltip, \
                                    strat, op_mode, regime, risk, requires_cfg, lives_in) \
            EMIT_PER_CORE_SAVE_DISPATCH_##meta(kind, name, ov, core_idx, fp)
        
        #define EMIT_PER_CORE_SAVE_DISPATCH_HAS_PER_CORE_OK(kind, name, ov_ref, ci, fp_) \
            if ((ov_ref).override_set_mask & OVERRIDE_BIT_##name) { \
                tt::per_core_save<CfgFieldDescriptor::KIND_##kind>(fp_, ov_ref, FIELD_IDX_##name, ci); \
            }
        
        FOREACH_CFG_FIELD(EMIT_PER_CORE_SAVE)
        #undef EMIT_PER_CORE_SAVE
    }
}
```

## Anti-patterns to avoid

- **Don't combine per-core overrides + global cfg fields into one struct.** Keep per-core overrides in PerCoreOverrides<F>[16]; globals in the rest of Cfg. Mixing breaks the cache-locality win + complicates the accessor dispatch.
- **Don't make `override_set_mask` per-field instead of per-core.** Per-core is the right granularity (one mask per cache line; all overrides for a core checked via single mask AND). Per-field returns to SoA-shaped storage.
- **Don't drop the `override_set_mask` semantic** (e.g., "if value > 0, treat as override"). The mask is EXPLICIT presence; the value alone doesn't encode whether the override is set. Operator may want `core_0_ml_buy_threshold=0.0` as an explicit override (vs no override).
- **Don't reorder PerCoreOverrides fields after locking the bit positions.** OVERRIDE_BIT_<NAME> constants depend on field position; reordering = different bit semantics + breaks operator cfg files.
- **Don't widen Cfg without checking total cache budget.** Adding ~5KB of new struct space is fine (Cfg is slow-path/boot only, not hot-path). Verify total Cfg size stays under L1 budget; cfg shouldn't be hot anyway.
- **Don't skip cache-miss baseline measurement.** Without it, we can't validate the win. perf stat is cheap; run it.

## If something goes wrong

- **Backtest determinism breaks (cmp shows divergence):**
  1. Per-core override semantics changed (e.g., explicit zero vs no-override). Audit each override path.
  2. Parser bit position assignment may differ from accessor's bit check. Verify OVERRIDE_BIT_<NAME> matches between parser SET and accessor GET.
  3. Bisect via single-symbol backtest.
- **Existing engine.cfg fails to load:**
  - Per-core key format (`core_<N>_<field>`) must parse identically. Verify Step 4 parser handles all field names from the old format.
  - Add unit test: load each cfg.example variant + verify byte-identical post-load state.
- **Cache-miss delta is NEGATIVE (cache locality worse):**
  - Unlikely but possible if PerCoreOverrides<F> straddles cache lines awkwardly. Verify pahole layout + adjust field order.
  - Check whether per_core_overrides[16] array span exceeds L1 budget (16 × sizeof(PerCoreOverrides<64>)). If yes, defer fields to a secondary array.
- **Snapshot wire format broken:**
  - If Cfg IS part of snapshot body: bump SHARDED_SNAPSHOT_VERSION + add migration path. Loading legacy snapshots: parse old SoA layout into new AoS struct via field-by-field copy.
- **Rollback:** `git reset --hard pre-v5.15.5.F.4g` (anchor at Step 0). Critical — Cfg struct layout is load-bearing across many sites.
