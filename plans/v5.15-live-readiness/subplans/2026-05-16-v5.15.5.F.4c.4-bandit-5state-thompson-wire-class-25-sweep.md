#### A.0 — NEW: Telemetry-preserving ghost-aware apply_fns (HIGH-2 fix)

Pre-ship `BanditAlgo_Both_Apply` (cfg=2 = legacy BOTH) calls `Thompson_Sample(thompson)` for `*chosen_arm_out` telemetry — populates `last_predicted_thompson_arm` snapshot field. Plan must preserve this telemetry side effect when cfg=2 reassigns to ghost-training mode.

```cpp
// cfg=2 = EXP3_OP_THOMPSON_GHOST — Exp3 drives decisions; Thompson sample for telemetry
// chosen_arm = Exp3's argmax (correct reward attribution per Class 24 sister fix)
inline void BanditAlgo_Exp3_Drives_Thompson_Ghost_Apply(
    BanditState* exp3, ThompsonBanditState* thompson,
    int n_arms, double* weights_out, int* chosen_arm_out
) {
    if (!exp3 || !weights_out) { /* uniform fallback */ return; }
    // Exp3 drives ensemble blending — write Exp3 probabilities
    Bandit_GetProbabilities(exp3, weights_out);
    // Thompson sample for telemetry side effect (RNG advances; populates last_predicted_thompson_arm
    // via separate caller-stored slot — see ezoo->last_predicted_thompson_arm assignment in
    // ML_BuildParameters caller scope after Apply returns).
    int thompson_telemetry_arm = thompson ? Thompson_Sample(thompson) : 0;
    (void)thompson_telemetry_arm;  // emitted to telemetry via separate channel; see § O
    // chosen_arm reflects DRIVING algorithm for correct reward attribution
    if (chosen_arm_out) {
        int best = 0;
        double best_w = weights_out[0];
        for (int i = 1; i < n_arms; i++) {
            int win   = weights_out[i] > best_w;       // cmov branchless (Class 28 prevention)
            best      = win ? i : best;
            best_w    = win ? weights_out[i] : best_w;
        }
        *chosen_arm_out = best;
    }
}

// cfg=3 = THOMPSON_OP_EXP3_GHOST — Thompson drives decisions; Exp3 probs computed for telemetry
inline void BanditAlgo_Thompson_Drives_Exp3_Ghost_Apply(
    BanditState* exp3, ThompsonBanditState* thompson,
    int n_arms, double* weights_out, int* chosen_arm_out
) {
    if (!thompson || !weights_out) { /* uniform fallback */ return; }
    // Compute Exp3 probabilities for telemetry side effect (does NOT consume Thompson RNG)
    double exp3_probs[BANDIT_MAX_ARMS];
    if (exp3) Bandit_GetProbabilities(exp3, exp3_probs);
    // Thompson drives — sample for arm selection
    int chosen = Thompson_Sample(thompson);
    // weights_out reflects Thompson's pick (one-hot at chosen)
    for (int i = 0; i < n_arms; i++) weights_out[i] = (i == chosen) ? 1.0 : 0.0;
    if (chosen_arm_out) *chosen_arm_out = chosen;
    // Exp3 telemetry available via exp3_probs[] for calib log (see § N + § O caller scope)
}
```

Caller scope (`ML_BuildParameters`) extracts the telemetry values after Apply returns to populate snapshot fields. Implementation detail in § N + § O.
