### Step 1 — EngineSharded_HotSwapEnsemble helper

File: `CoreFrameworks/EngineSharded.hpp` (new inline function near
existing hot-swap path)

**Important:** must reconstruct `horizon_list` from
`ezoo->horizon_ticks_at_idx[]` BEFORE calling Free (Free zeros the
counts, so we cache the horizons first). Pass all 5 mandatory params
to `LoadFromCfg`.

```cpp
// v5.14.2 — atomic ensemble hot-swap. Replaces v5.10.0c REFUSE
// when ensemble inference is active.
//
// Same-thread (slow-path c is single-reader/writer for its zoo);
// brief window with empty zoo is safe — ML inference also runs
// on this same slow-path thread, can't preempt itself.
//
// Returns 1 on success, 0 on failure (caller logs).
template <unsigned F>
inline int EngineSharded_HotSwapEnsemble(
    EnsembleModelZoo<F>* swap_ezoo,
    const ControllerConfig<F>& cfg,
    int core_id,
    const char* new_base_dir,
    int swap_backend) {

    // 1. Cache horizons BEFORE Free (which zeros barrier_count etc.,
    //    leaving horizon_ticks_at_idx[] dirty but not authoritative).
    //    horizon_ticks_at_idx is only meaningfully populated up to
    //    barrier_count / regime_count / etc.; we walk all slots and
    //    keep the non-zero ones to be conservative.
    int horizons[ENSEMBLE_HORIZON_MAX];
    int h_count = 0;
    for (int i = 0; i < ENSEMBLE_HORIZON_MAX; ++i) {
        if (swap_ezoo->horizon_ticks_at_idx[i] > 0) {
            horizons[h_count++] = swap_ezoo->horizon_ticks_at_idx[i];
        }
    }
    if (h_count == 0) {
        fprintf(stderr,
            "[hot_swap] ensemble core %d FAILED: no cached horizons "
            "to load (boot must have failed)\n", core_id);
        return 0;
    }

    // 2. Tear down old ensemble state (bandits + handles)
    EnsembleModelZoo_Free(swap_ezoo);

    // 3. Re-init zero state (clears v5.14.1.E fields too)
    EnsembleModelZoo_Init(swap_ezoo);

    // 4. Load new ensemble (buy_signal/barrier/regime/exit_predictor)
    int total = EnsembleModelZoo_LoadFromCfg(
        swap_ezoo,
        new_base_dir,
        horizons,                                          // reconstructed
        h_count,                                           // count
        swap_backend,
        /*held_out_stamp_secret=*/nullptr,
        /*gap_threshold=*/0.05,
        /*held_out_gate_strict=*/cfg.held_out_gate_strict,
        /*acknowledge_cross_binary_drift=*/cfg.acknowledge_cross_binary_version_drift);
    if (total == 0) {
        fprintf(stderr,
            "[hot_swap] ensemble core %d FAILED: 0 roles loaded "
            "from %s\n", core_id, new_base_dir);
        return 0;
    }

    // 5. Re-init bandits (buy + exit) with cfg defaults
    EnsembleModelZoo_InitBandits(swap_ezoo,
        cfg.ensemble_bandit_eta,
        cfg.ensemble_min_warmup_predictions);
    EnsembleModelZoo_InitExitBandits(swap_ezoo,
        cfg.exit_bandit_lr,
        cfg.ensemble_min_warmup_predictions);

    // 6. Overlay persisted bandit state if any (graceful skip on
    //    bundle-id mismatch — uniform priors stay)
    EnsembleModelZoo_LoadBanditState(swap_ezoo, new_base_dir);
    EnsembleModelZoo_LoadExitBanditState(swap_ezoo, new_base_dir);

    fprintf(stderr,
        "[hot_swap] ensemble core %d swapped to %s "
        "(%d roles loaded; primary=%s; exit=%d)\n",
        core_id, new_base_dir, total,
        swap_ezoo->primary_role_name[0]
            ? swap_ezoo->primary_role_name : "(none)",
        swap_ezoo->exit_predictor_count);
    return 1;
}
```

### Step 5 — Post-ship completeness patch (low-priority follow-up)

`EnsembleModelZoo_Free` (CoreModelZoo.hpp:1325) does NOT zero the
v5.14.1.E fields (exit_ridge_state / exit_reward_ring /
exit_reward_ring_head / exit_predict_call_count). Init compensates
in the hot-swap path (Free → Init → Load), so this is non-blocking
for v5.14.2 — but Free is semantically incomplete and could leave
stale state if called outside the swap path.

**Patch (v5.14.2.D or follow-on):**

```cpp
inline void EnsembleModelZoo_Free(EnsembleModelZoo<F>* ezoo) {
    for (int i = 0; i < ENSEMBLE_HORIZON_MAX; ++i) {
        Model_Free(&ezoo->barrier[i]);
        Model_Free(&ezoo->regime[i]);
        Model_Free(&ezoo->exit_predictor[i]);
        Model_Free(&ezoo->buy_signal[i]);
    }
    ezoo->barrier_count = 0;
    ezoo->regime_count = 0;
    ezoo->exit_predictor_count = 0;
    ezoo->buy_signal_count = 0;
    ezoo->active = 0;
    // v5.14.2.D — clear v5.14.1.E fields for semantic completeness
    RidgeWeights_Init(&ezoo->exit_ridge_state);
    memset(ezoo->exit_reward_ring, 0, sizeof(ezoo->exit_reward_ring));
    ezoo->exit_reward_ring_head = 0;
    ezoo->exit_predict_call_count = 0;
}
```

Treat as bundled into v5.14.2 if scope budget allows (4 LOC + 1
test); otherwise queue as a v5.14.3 micro-fix.
