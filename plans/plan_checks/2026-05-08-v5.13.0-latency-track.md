## Detailed Findings

### 1. DEFAULT CFG OVERHEAD (5 ns claim) — PASS

**Location:** `EngineSharded.hpp:2917–2920`, slow-path body gate

**Code:**
```cpp
if (cfg.use_exit_model
    && state.cores[c].last_exit_prediction
       > FPN_ToDouble(cfg.exit_threshold)
    && price_d > 0.01)
```

**Cost estimate:**
- `cfg.use_exit_model` (bool load + test): ~0.5 ns
- `last_exit_prediction > FPN_ToDouble(cfg.exit_threshold)`
  (FPN double load + compare): ~1.5 ns
- `price_d > 0.01` (double load + compare): ~1 ns
- **Total: ~3 ns** (estimated ALU cost; compiler may pipeline/fuse)

**Branchless:** No. This is an `if` with data-dependent predicate
on slow path.

**Branch prediction:** With `use_exit_model=0` (default), the first
test fails and the branch is predicted-not-taken. Steady state:
**not taken**, negligible mispredict cost.

**Verdict:** Claim of ~5 ns is conservative + acceptable. Actual
~3 ns ALU cost + predicted-not-taken branch. **PASS.**

### 2. N-MODEL EXIT INFERENCE (3-15 μs claim) — PASS

**Location:** `StrategyParameters.hpp:951–974`, ML_BuildParameters
exit block

**Cost breakdown:**
- Loop overhead (N iterations): ~5 ns per iteration × N
- Model_IsLoaded check (~2 bool load): ~0.5 ns per iteration
- `Model_Predict_Normalized` call:
  **~1-8 μs per call** (XGBoost inference path; C API wraps
  treelite AOT or tree traversal)
  - Per existing benchmarks: ~500-2000 ns per model

**Total:** With 2-4 models loaded: **3-15 μs/cycle** (claim
validated).

**Caveat:** Cost is dominated by `Model_Predict_Normalized`, NOT
the blend logic. Changelog confirms features are reused (no extra
`Features_PackAll` call). Sibling-scaler enforcement verified at
`StrategyParameters.hpp:944-945`.

**Verdict:** Claim is accurate. **PASS.**
