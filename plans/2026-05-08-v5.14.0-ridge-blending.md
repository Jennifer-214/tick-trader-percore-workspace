### Step 1 — RidgeBlender struct + Cholesky kernel

File: `ML_Headers/RidgeBlender.hpp` (NEW)

```cpp
template <unsigned F, int MAX_MODELS>
struct RidgeWeights {
    // Output (boundary type; FPN for snapshot/serialization stability)
    FPN<F> w[MAX_MODELS];        // sum to 1.0; clipped non-negative

    // Internal scratch (double for Cholesky numerical stability;
    // boundary-stable refactor pattern per CLAUDE.local.md)
    double corr_matrix[MAX_MODELS][MAX_MODELS];
    double mu[MAX_MODELS];        // net IC (cost-penalized) per model
    double L[MAX_MODELS][MAX_MODELS];  // Cholesky factor (lower triangular)
    double y[MAX_MODELS];         // forward-substitution intermediate
    double w_internal[MAX_MODELS];

    // Diagnostics
    int    n_models;
    int    fallback_to_uniform;   // 1 if Cholesky failed (singular matrix)
    int    last_compute_us;       // wall-clock for /latency-track
};

// Solve (Σ + λI) w = μ via Cholesky.
// Σ = corr_matrix (input; standardized predictions correlation)
// μ = ic[i] - cost_penalty * cost[i], floored at min_ic
// Returns 0 on success, -1 on Cholesky failure (singular).
template <unsigned F, int MAX_MODELS>
int RidgeBlender_Compute(
    RidgeWeights<F, MAX_MODELS>* out,
    const double ic[],            // per-model IC from RollingIC
    const double cost[],          // per-model cost (fee + slippage est)
    int n_models,
    double ridge_lambda,          // cfg.ridge_lambda
    double cost_penalty,          // cfg.ridge_cost_penalty
    double min_ic                 // cfg.ridge_min_ic_floor
);
```

Cholesky algorithm (standard textbook; ~30 lines):
1. For diagonal: `L[i][i] = sqrt(Σ[i][i] + λ - Σ_{k<i}(L[i][k]^2))`
2. For off-diagonal: `L[i][j] = (Σ[i][j] - Σ_{k<j}(L[i][k]·L[j][k])) / L[j][j]`
3. Forward solve `L y = μ` then back solve `L^T w = y`
4. If any `L[i][i] <= 0` → Cholesky failure → fallback to uniform

Numerical stability: λI added to diagonal protects against near-
singular Σ (the "ridge regularization"). `cfg.ridge_lambda=0.15`
is safe default per FoxML_Core.

### Step 2 — Correlation matrix update from prediction history

File: `ML_Headers/RidgeBlender.hpp`

```cpp
// Build standardized correlation matrix from K recent predictions.
// History from ezoo->reward_ring (PredictionRecord.predictions[]).
// Per-model: mean-center + unit-variance, then pairwise Pearson.
template <unsigned F, int MAX_MODELS>
void RidgeBlender_BuildCorr(
    double corr_out[MAX_MODELS][MAX_MODELS],
    const PredictionRecord history[],  // ezoo->reward_ring
    int n_history,                      // valid entries
    int n_models                        // ezoo->primary_count
);
```

Algorithm:
1. For each model i: compute mean + std over n_history predictions
2. For each pair (i, j): `corr[i][j] = mean((p_i - mean_i) × (p_j - mean_j)) / (std_i × std_j)`
3. Guard `std_i < 1e-9` (constant predictions) → corr = identity row

Cost: O(n_models² × n_history). For n=8, K=64 → ~4000 ops; sub-µs.

### Step 3 — Engine wiring (StrategyParameters.hpp ML dispatch)

```cpp
// v5.14.0 — Ridge blending alternative to bandit weights.
// Default cfg (ridge_within_horizon=0): bandit weights as today.
// cfg.ridge_within_horizon=1: Ridge weights computed per-cycle.
double weights_buf[ENSEMBLE_HORIZON_MAX];

if (cfg->ridge_within_horizon && ezoo->ridge_state.n_models >= 2) {
    // Build correlation from reward_ring history
    RidgeBlender_BuildCorr(
        ezoo->ridge_state.corr_matrix,
        ezoo->reward_ring, ezoo->reward_ring_head,
        ezoo->primary_count);
    // Compute IC + cost per model from existing per-arm IC tracking
    double ic_per_model[ENSEMBLE_HORIZON_MAX];
    double cost_per_model[ENSEMBLE_HORIZON_MAX];
    for (int h = 0; h < ezoo->primary_count; ++h) {
        ic_per_model[h] = (double)ezoo->drift[h].ic_avg;  // existing
        cost_per_model[h] = ...;  // operator-tunable; default 0
    }
    int rc = RidgeBlender_Compute(
        &ezoo->ridge_state,
        ic_per_model, cost_per_model, ezoo->primary_count,
        FPN_ToDouble(cfg->ridge_lambda),
        FPN_ToDouble(cfg->ridge_cost_penalty),
        FPN_ToDouble(cfg->ridge_min_ic_floor));
    if (rc == 0) {
        for (int h = 0; h < ezoo->primary_count; ++h)
            weights_buf[h] = FPN_ToDouble(ezoo->ridge_state.w[h]);
    } else {
        // Cholesky failure → bandit fallback
        Bandit_GetProbabilities(&ezoo->bandits[regime_id], weights_buf);
    }
} else {
    Bandit_GetProbabilities(&ezoo->bandits[regime_id], weights_buf);
}

pred_raw = (double)Model_Predict_Ensemble_Weighted(
    ezoo->primary_handles, ezoo->primary_count,
    features, n,
    weights_buf,
    ezoo->disabled_horizon_mask,
    config->ensemble_min_agreement_pct,
    &dominant_idx,
    per_arm_preds);
```

Reuses existing `Model_Predict_Ensemble_Weighted` — no signature
change. Just swaps weight source.
