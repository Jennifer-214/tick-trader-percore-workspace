## § Step 1 — `tt::cfg_emit_synthetic_field<T>` type-trait dispatch helper

### Full implementation (in `tt::` namespace, sister to `tt::cfg_save_field<T>`)

```cpp
// CoreFrameworks/TtDispatch.hpp (or wherever tt:: namespace lives; verify at .B time)
//
// Sister to tt::cfg_parse_field<T> + tt::cfg_save_field<T> per type-trait-dispatch-via-tt-namespace.md
//
// Per-type emit format (deterministic + Layer 2 locale-pinned by caller):
//   FPN<F>:        snprintf with %.17g (lossless double round-trip)
//   integers:      snprintf with %d / %u / %lu
//   float/double:  snprintf with %.17g
//   bool:          ternary (idx & 1 ? 1 : 0) — H9 byte-equivalence
//   array<T, N>:   per-element deterministic per element index
//
// v5.15.5.F.4d.1.B — NEW (was placeholder stub at .A).

namespace tt {

template <typename T>
inline size_t cfg_emit_synthetic_field(
    const CfgFieldDescriptor& d,
    size_t idx,            // row index for deterministic distinctness
    char* buf,
    size_t cap)
{
    static_assert(
        is_FPN_v<T> ||
        std::is_integral_v<T> ||
        std::is_floating_point_v<T> ||
        std::is_array_v<T>,
        "tt::cfg_emit_synthetic_field: unsupported type"
    );

    if constexpr (is_FPN_v<T>) {
        constexpr unsigned F = T::fractional_bits;
        return (size_t)snprintf(buf, cap, "%s=%.17g\n",
                                 d.cfg_field_name,
                                 FPN_ToDouble(T::from_double(42.0 + (double)idx)));
    } else if constexpr (std::is_same_v<T, bool>) {
        return (size_t)snprintf(buf, cap, "%s=%d\n",
                                 d.cfg_field_name,
                                 (int)((idx & 1u) ? 1 : 0));
    } else if constexpr (std::is_unsigned_v<T>) {
        return (size_t)snprintf(buf, cap, "%s=%llu\n",
                                 d.cfg_field_name,
                                 (unsigned long long)(42u + idx));
    } else if constexpr (std::is_signed_v<T> && std::is_integral_v<T>) {
        return (size_t)snprintf(buf, cap, "%s=%lld\n",
                                 d.cfg_field_name,
                                 (long long)(42 + (int)idx));
    } else if constexpr (std::is_floating_point_v<T>) {
        return (size_t)snprintf(buf, cap, "%s=%.17g\n",
                                 d.cfg_field_name,
                                 42.0 + (double)idx);
    } else if constexpr (std::is_array_v<T>) {
        // Array: emit per-element deterministic; for stamp body purposes
        // arrays are typically string-paths (KIND_FILE_PATH) — emit stub label.
        return (size_t)snprintf(buf, cap, "%s=synthetic_array_idx_%zu\n",
                                 d.cfg_field_name, idx);
    }
}

}  // namespace tt
```

### Design decision: 42 + idx for distinctness
Each row gets a distinct deterministic value. 42 is the offset constant (well-known); idx makes each row distinct. Cross-test determinism: same idx → same value across process restarts.

### Verification expectations
- Compile-time `static_assert` per supported type
- Build verify: existing parser tests still pass (no parser regression)
- Runtime tests at Step 13 verify per-type emit produces deterministic output

## § Step 8 — `CFG_DRIFT_AUTOPOPULATE` companion macro (revised v1.1 for β4 dispatch)

**v1.1 revision (2026-05-16 per β4 sidecar-dispatch approach):** original draft used inline cohort branches in the callback (Option α; Class 19/14/18 latent). Revised to **branchless fn-pointer dispatch table per H20 Pattern 1** using the `FOREACH_DRIFT_GATE` sparse sidecar + `DriftGateKind` enum landed at `.B` (sister to `FOREACH_DRIFT_OVERRIDE` at `.C` per per-concern-separation discipline).

### Full macro definition (β4)

```cpp
// MemHeaders/CfgDriftAutoPopulate.hpp (NEW; sister to StampCfgAutoPopulate.hpp)
//
// Sister to STAMP_CFG_AUTOPOPULATE + INFERENCE_CFG_AUTOPOPULATE (canonical .A.7).
// Walks STAMP_BOUND_CFG derived filter; per-row drift check via:
//   1. Branchless cohort gate dispatch via FOREACH_DRIFT_GATE sidecar + DriftGateKind table (.B β4)
//   2. Per-field drift compare via tt::cfg_drift_compare_descriptor<F> (preserves H13)
//   3. Branchless severity / category override via FOREACH_DRIFT_OVERRIDE sidecar lookup (.C)

#pragma once

#include "../CoreFrameworks/StampBoundDerivedFilter.hpp"
#include "CfgDriftGate.hpp"     // FOREACH_DRIFT_GATE + DriftGateKind + g_drift_gate_table (.B β4)
// #include "../CoreFrameworks/CfgFieldDriftOverride.hpp"  // landed at .C

template <unsigned F>
struct DriftCtx {
    uint64_t* failure_flags;
    const ModelStampResult* handle;
    const ControllerConfig<F>* cfg;
    int* drift_count;  // → sr.inference_cfg_drift_count
};

template <unsigned F>
inline void emit_drift_check_per_row(
    size_t idx,
    const CfgFieldDescriptor& d,
    void* ctxp)
{
    auto* ctx = static_cast<DriftCtx<F>*>(ctxp);

    // β4 branchless cohort gate dispatch (replaces v1.0 inline branches):
    // Lookup cohort tag in sparse sidecar (default = DRIFT_GATE_DEFAULT for unset rows)
    bool is_per_core = (d.lives_in_struct == CfgFieldDescriptor::PER_CORE_CFG);
    DriftGateKind kind = is_per_core
        ? g_drift_gate_lookup_per_core[idx]
        : g_drift_gate_lookup_global[idx];

    // Single array lookup + 1 fn-pointer indirection (per H20 Pattern 1):
    bool gate = g_drift_gate_table<F>[kind](ctx->cfg, ctx->handle);
    if (!gate) return;

    // Per-field drift compare via tt:: dispatch (preserves H13):
    bool drifted = tt::cfg_drift_compare_descriptor<F>(d, *ctx->handle, *ctx->cfg);
    if (drifted) {
        BITMAP_SET(*ctx->failure_flags, FAILURE_MASK_cfg_inference_drift);
        (*ctx->drift_count)++;
    }
}

#define CFG_DRIFT_AUTOPOPULATE(failure_flags, handle, cfg, drift_count_ref) \
    do { \
        DriftCtx<F> _drift_ctx{&(failure_flags), &(handle), &(cfg), &(drift_count_ref)}; \
        STAMP_BOUND_CFG_walk_filtered_rows(g_per_core_cfg_field_descriptors, \
                                            FIELD_IDX_PER_CORE_END, \
                                            &emit_drift_check_per_row<F>, &_drift_ctx); \
        STAMP_BOUND_CFG_walk_filtered_rows(g_global_cfg_field_descriptors, \
                                            FIELD_IDX_GLOBAL_END, \
                                            &emit_drift_check_per_row<F>, &_drift_ctx); \
    } while (0)
```

### β4 dispatch flow

1. Walker invokes `emit_drift_check_per_row` per matching row (STAMP_BOUND_CFG_DERIVED filter)
2. Determine scope: `is_per_core` from `d.lives_in_struct`
3. Sparse sidecar lookup: `g_drift_gate_lookup_{per_core,global}[idx]` → `DriftGateKind`
4. Branchless fn-pointer table dispatch: `g_drift_gate_table<F>[kind](cfg, handle)` → bool gate
5. Per-field drift compare via `tt::` dispatch (typed; preserves H13)
6. On drift: bitmap-set failure flag + increment counter

**Performance**: 1 array lookup (sidecar) + 1 fn-pointer indirection (dispatch table) + 1 typed compare. No sequential branches per row; per H20 Pattern 1.

### Why β4 replaces v1.0 inline-branch approach

Per `.B` plan body v1.1 § Step 11 + Caramel's "structural fix when bug class can recur" call:

| Property | v1.0 inline branches (α) | **v1.1 β4 dispatch table** |
|---|---|---|
| Class 19 latent (hardcoded enum names in callback) | Yes | **None** (data column drives) |
| Class 14 latent (forget callback branch on new cohort) | Yes | **None** (callback is generic) |
| Class 18 latent (parallel logic in callback) | Yes | **None** (registry IS source of truth) |
| Branchless dispatch (H20) | No (6 sequential branches) | **Yes** (1 lookup + 1 indirect call) |
| New cohort cost | edit callback fn body | **1 enum row + 1 gate fn + N row tags** |

    DRIFT_GATE_DEFAULT              = 0,
    DRIFT_GATE_BANDIT_THOMPSON      = 1,
    DRIFT_GATE_RISK_DEGRADATION     = 2,

template <unsigned F>

inline bool gate_risk_degradation(const ControllerConfig<F>* cfg, const ModelStampResult* h)
    { return STAMP_HAS(*h, inference_cfg) && cfg->risk_degradation_curve != 0; }

template <unsigned F>
inline bool gate_ridge_any(const ControllerConfig<F>* cfg, const ModelStampResult* h) {
    return STAMP_HAS(*h, inference_cfg)
        && BITMAP_ANY(cfg->ml_cfg_flags,
                       MASK_ML_CFG_RIDGE_WITHIN_HORIZON | MASK_ML_CFG_RIDGE_ACROSS_HORIZONS);
}

template <unsigned F>
inline bool gate_composite_confidence(const ControllerConfig<F>* cfg, const ModelStampResult* h)
    { return STAMP_HAS(*h, inference_cfg) && BITMAP_IS_SET(cfg->ml_cfg_flags, MASK_ML_CFG_CONFIDENCE_COMPOSITE_ENABLED); }

    [DRIFT_GATE_BANDIT_THOMPSON]      = &gate_bandit_thompson<F>,
    [DRIFT_GATE_RISK_DEGRADATION]     = &gate_risk_degradation<F>,
    [DRIFT_GATE_RIDGE_ANY]            = &gate_ridge_any<F>,
    [DRIFT_GATE_COMPOSITE_CONFIDENCE] = &gate_composite_confidence<F>,
};

// Sparse sidecar registry: per-FIELD_IDX cohort tag for non-Default rows.
// Default cohort (sidecar entry absent / value 0) is implicit for unflagged rows.
#define FOREACH_DRIFT_GATE(X)                                              \
    /* Bandit/Thompson cohort (4 fields) */                                \
    X(bandit_algorithm,                  BANDIT_THOMPSON)                  \
    X(thompson_mu_prior,                 BANDIT_THOMPSON)                  \
    X(thompson_precision_prior,          BANDIT_THOMPSON)                  \
    X(thompson_precision_obs,            BANDIT_THOMPSON)                  \
    /* Soft-risk degradation (3 fields; risk_degradation_curve gates self) */ \
    X(risk_full_size_threshold,          RISK_DEGRADATION)                 \
    X(risk_min_size_threshold,           RISK_DEGRADATION)                 \
    X(risk_min_size_pct,                 RISK_DEGRADATION)                 \
    /* Ridge cohort (3 scalars; ridge_within/across gates themselves) */   \
    X(ridge_lambda,                      RIDGE_ANY)                        \
    X(ridge_cost_penalty,                RIDGE_ANY)                        \
    X(ridge_min_ic_floor,                RIDGE_ANY)                        \
    /* Composite confidence cohort (4 scalars) */                          \
    X(confidence_freshness_tau_secs,     COMPOSITE_CONFIDENCE)             \
    X(confidence_capacity_target_dollars, COMPOSITE_CONFIDENCE)            \
    X(confidence_capacity_kappa,         COMPOSITE_CONFIDENCE)             \
    X(confidence_rmse_baseline,          COMPOSITE_CONFIDENCE)

// Dense sparse-arrays indexed by FIELD_IDX (default 0 = DRIFT_GATE_DEFAULT):
#define EMIT_DRIFT_GATE_INIT(name, kind) \
    [FIELD_IDX_##name] = DRIFT_GATE_##kind,

inline DriftGateKind g_drift_gate_lookup_per_core[FIELD_IDX_PER_CORE_END] = {
