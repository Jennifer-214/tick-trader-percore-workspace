## Why redesign

Original B.3 plan added a 10-parameter `stamp_check_extended_cfg_drift`
helper (caller-side drift check). Caramel asked "is this future proof?"
during B.3.B coding — it isn't:

- 10 primitive params per drift check; **7+ touch sites** per new
  stamp-bound field added (struct field, ModelStampResult field, emit
  body, parser branch, zero-init, helper param, every caller)
- Same shape as v5.9.5b production-caller field-population gap class
  (the abandoned `inference_cfg_drift_count` field is exactly this:
  defined in v5.9.2b but never incremented anywhere, so cfg drift went
  silently undetected for 9 fields across 2 sprints)
- Violates CLAUDE.md item 13: "X-macro registry is the standard
  pattern for multi-site additions (v5.8.0+). Any category where
  adding the next instance requires touching ≥2 code sites must use
  a `FOREACH_<CATEGORY>(X)` registry."

Stamp-bound cfg drift IS the canonical multi-site addition pattern
(5+ sites per field). FOREACH_STAMP_BOUND_CFG(X) is the disciplined
answer, matching the convention established for FOREACH_FEATURE,
FOREACH_TARGET, FOREACH_STRATEGY, FOREACH_SHALT, FOREACH_REGIME, etc.

## Design

### X-macro entry shape

```cpp
// ML_Headers/StampBoundCfgRegistry.hpp (NEW header)
//
// X(stamp_key, type, fmt, default_val, get_cfg)
//
// Where:
//   stamp_key   = canonical body key (also struct field name)
//   type        = C++ type (int, double)
//   fmt         = printf format ("%d", "%.17g")
//   default_val = zero-init value (0, 0.0)
//   get_cfg     = expression to extract value from cfg (e.g.,
//                 "FPN_ToDouble(cfg.ridge_lambda)" or just
//                 "cfg.ridge_within_horizon")

#define FOREACH_STAMP_BOUND_CFG(X)                                       \
    /* v5.14.1.B.3 — Ridge risk-parity blending (PARITY-004) */         \
    X(ridge_within_horizon,    int,    "%d",     0,   cfg.ridge_within_horizon)   \
    X(ridge_across_horizons,   int,    "%d",     0,   cfg.ridge_across_horizons)  \
    X(ridge_lambda,            double, "%.17g",  0.0, FPN_ToDouble(cfg.ridge_lambda))  \
    X(ridge_cost_penalty,      double, "%.17g",  0.0, FPN_ToDouble(cfg.ridge_cost_penalty))  \
    X(ridge_min_ic_floor,      double, "%.17g",  0.0, FPN_ToDouble(cfg.ridge_min_ic_floor))  \
    /* v5.14.1.B.3 — Composite confidence (PARITY-005) */               \
    X(confidence_composite_enabled,        int,    "%d",     0,   cfg.confidence_composite_enabled)  \
    X(confidence_freshness_tau_secs,       double, "%.17g",  0.0, FPN_ToDouble(cfg.confidence_freshness_tau_secs))  \
    X(confidence_capacity_target_dollars,  double, "%.17g",  0.0, FPN_ToDouble(cfg.confidence_capacity_target_dollars))  \
    X(confidence_capacity_kappa,           double, "%.17g",  0.0, FPN_ToDouble(cfg.confidence_capacity_kappa))  \
    X(confidence_rmse_baseline,            double, "%.17g",  0.0, FPN_ToDouble(cfg.confidence_rmse_baseline))
```

### Auto-generated emit (in stamp_write_for_model)

```cpp
// v5.14.1.B.3 — X-macro-driven emit. Each field gated by has_<name>=1
// (Surface G forward-compat: legacy stamps emit nothing when input
// caller passes default has_*=0).
#define X(name, type, fmt, default_val, get_cfg)                       \
    if (inf && inf->has_##name && n > 0 && (size_t)n < sizeof(canonical)) {  \
        int wrote = snprintf(canonical + n, sizeof(canonical) - n,     \
            #name "=" fmt "\n", inf->name);                            \
        if (wrote > 0) n += wrote;                                     \
    }
FOREACH_STAMP_BOUND_CFG(X)
#undef X
```

### Auto-generated zero-init (in verify_model_stamp)

```cpp
// v5.14.1.B.3 — X-macro-driven zero-init. Legacy stamps load with

#define X(name, type, fmt, default_val, get_cfg)  \

FOREACH_STAMP_BOUND_CFG(X)

```

### Auto-generated parser branches

```cpp
// (Inside the existing parser if-else chain in verify_model_stamp)
// v5.14.1.B.3 — X-macro-driven parser. Each entry adds one
// `else if (strcmp(key, "<name>") == 0) { ... }` branch.
#define X(name, type, fmt, default_val, get_cfg)                       \
    else if (strcmp(key, #name) == 0) {                                \
        r.name = (type)(parse_##type(val));                            \
        r.has_##name = 1;                                              \
    }
FOREACH_STAMP_BOUND_CFG(X)
#undef X
// Where parse_int = atoi; parse_double = tt::parse_double_fast.
// Helper macros define these for the X-expansion.
```

### Auto-generated drift check (resurrects inference_cfg_drift_count)

New helper that takes the parsed `ModelStampResult* sr` and a
`ControllerConfig<F>* cfg`. Increments
`sr->inference_cfg_drift_count` per drifted field. Caller's existing
`held_out_gate_strict` path consumes the count.

```cpp
template <unsigned F>
inline void stamp_check_xmacro_drift(ModelStampResult* sr,
                                       const ControllerConfig<F>& cfg) {
    if (!sr) return;
    #define X(name, type, fmt, default_val, get_cfg)                   \
        if (sr->has_##name) {                                          \
            type cfg_val = (type)(get_cfg);                            \
            if (sr->name != cfg_val) {                                 \
                sr->inference_cfg_drift_count++;                       \
                if (sr->valid > 0 && sr->reason[0] == '\0') {          \
                    snprintf(sr->reason, sizeof(sr->reason),           \
                        "%s drift: stamp=" fmt " cfg=" fmt,            \
                        #name, sr->name, cfg_val);                     \
                }                                                       \
            }                                                          \
        }
    FOREACH_STAMP_BOUND_CFG(X)
    #undef X
}
```

Caller (CoreModelZoo) invokes `stamp_check_xmacro_drift(&sr, cfg)`
after `verify_model_stamp` returns. Existing `if (sr.valid <= 0)` +
`held_out_gate_strict==1` path REFUSES load on any drift; warn-only
mode logs + continues. **No new param explosion at the verifier.**

### Bash CLI mirror

`tools/stamp_model.sh` extension: same 10 fields exposed as CLI
flags, gated by `--has-<name>=1`. Bytewise-identical canonical body
to in-process emit.

(For v5.14.1.B.3 minimum scope, bash CLI keeps the manual list. The

### Step 8 — Tests

File: `tests/controller_test.cpp`

Test groups:

1. **X-macro expansion sanity (~5 tests)**
   - Struct has all 10 expected fields (compile-time check via static_assert
     on offsetof or equivalent)
   - All 10 fields zero-initialized post-Init

2. **Round-trip emit + parse (~10 tests; one per field)**
   - Set `has_<name>=1` + value; emit; parse back; verify field +
     has_* flag both round-trip correctly

3. **Forward-compat (~5 tests)**
   - Legacy stamp (no Ridge/composite keys) loads → has_*=0 for all
   - Drift check skips silently when has_*=0

4. **Drift detection (~10 tests; one per field)**
   - Stamp value differs from cfg → `inference_cfg_drift_count` increments
   - First drift sets `r.reason`
   - Multiple drifts: count = sum, reason = first only

5. **3-tier strict mode (~3 tests)**
   - `held_out_gate_strict=0` → drift detected, valid=0, REFUSE-or-WARN
     decided by caller
   - `=1` → drift treated as failure (ATPI: drift_count > 0 → valid = 0)
   - `=-1` → skip (no parser run; no drift check)

6. **bash CLI parity (~1 round-trip test)**
   - Invoke `tools/stamp_model.sh` with all flags; diff canonical body
     vs in-process emit

Total: ~35 new tests (2112 → 2147).
