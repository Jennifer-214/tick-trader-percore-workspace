### Why so few candidates

The wider engine (`CoreFrameworks/` + `Strategies/`) is primarily:
- **Control flow** — cfg-flag dispatch, state machine transitions, error handling, bounds checks (all legitimate per CLAUDE.md item 18 sub-clauses b/c/d)
- **OMS / order lifecycle** — state transitions, not math reductions
- **Strategy dispatch** — function-pointer table calls; no inner math
- **Per-tick math is in `BG_Evaluate` / `SG_Evaluate` (hot path)** — already branchless via mask compute per CLAUDE.md item 1+18 (Portfolio bitmap, hot-path discipline)

The 1464 if-statements identified in initial scope-estimate are predominantly:
- Cfg-flag dispatch (eligible for FOREACH_*_CFG_FLAG bitmap migration if they fit the cohort-audit framework; many already migrated in v5.14.9.F.*)
- Error-path early-exits
- State-machine dispatches
- Bounds checks

None match the "math-kernel inner reduction with variable bound + if-guard" violation pattern documented in `branchless-math-kernel-pattern.md`.

### Where the engine's math kernels actually live
