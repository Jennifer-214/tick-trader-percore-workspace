## Theme

Operator needs to SEE what the ensemble is doing — which horizons
dominate per regime, are weights converging, what was the last
prediction. Without UI, the bandit is a black box.

This sub-ship lands a new "Ensemble (multi-horizon)" section in
`GUI/MLStatusPanel.hpp`, rendered only when `ensemble_zoo.active=1`.

## Items

### #2 — ML Status panel section (~1h)

Add to `GUI/MLStatusPanel.hpp`:

```cpp
// Render only when at least one core has ensemble active
bool any_ensemble = false;
for (int c = 0; c < num_cores; ++c)
    if (snap->cores[c].ensemble_active) { any_ensemble = true; break; }

if (any_ensemble && ImGui::CollapsingHeader("Ensemble (multi-horizon)")) {
    for (int c = 0; c < num_cores; ++c) {
        const auto& cs = snap->cores[c];
        if (!cs.ensemble_active) continue;

        ImGui::Text("Core %d: %d horizons (mode: %s)",
                    c, cs.ensemble_n_horizons, cs.ensemble_blend_mode);
        ImGui::SameLine();
        ImGui::TextColored(FoxmlColors::comment,
                           "(last: regime=%s, horizon=%d ticks)",
                           regime_name(cs.ensemble_last_predicted_regime),
                           cs.ensemble_horizon_ticks[
                               cs.ensemble_last_predicted_horizon_idx]);

        // Heatmap: regimes (rows) × horizons (cols)
        if (ImGui::BeginTable("ensemble_heatmap_c", cs.ensemble_n_horizons + 1,
                               ImGuiTableFlags_Borders | ImGuiTableFlags_RowBg)) {
            ImGui::TableSetupColumn("Regime", ImGuiTableColumnFlags_WidthFixed, 90);
            for (int h = 0; h < cs.ensemble_n_horizons; ++h) {
                char hdr[16]; snprintf(hdr, 16, "h%d", cs.ensemble_horizon_ticks[h]);
                ImGui::TableSetupColumn(hdr, ImGuiTableColumnFlags_WidthFixed, 70);
            }
            ImGui::TableHeadersRow();
            for (int r = 0; r < NUM_REGIMES; ++r) {
                ImGui::TableNextRow();
                ImGui::TableSetColumnIndex(0);
                ImGui::Text("%s (%d updates)", regime_name(r),
                            cs.ensemble_n_updates_per_regime[r]);
                for (int h = 0; h < cs.ensemble_n_horizons; ++h) {
                    ImGui::TableSetColumnIndex(h + 1);
                    double w = cs.ensemble_weights[r][h];
                    ImVec4 col = (w > 0.4) ? FoxmlColors::green
                               : (w > 0.2) ? FoxmlColors::yellow
                                            : FoxmlColors::comment;
                    ImGui::TextColored(col, "%.3f", w);
                }
            }
            ImGui::EndTable();
        }
        ImGui::Separator();
    }

    // "Persist Now" button — triggers immediate bandit_state.json save
    if (ImGui::Button("Persist Bandit State Now")) {
        // Atomic flag → consumed by slow-path next cycle
        snap->control->ensemble_persist_request = 1;
    }
    ImGui::SetItemTooltip(
        "Forces a bandit_state.json save across all active ensembles.\n"
        "Default: auto-saves every <ensemble_bandit_save_interval> updates\n"
        "(cfg) + at clean shutdown. Use this to checkpoint mid-session.");

    // "Reset Weights" — operator escape hatch (cfg-gated)
    if (cfg_allow_manual_reset) {
        ImGui::SameLine();
        if (ImGui::Button("Reset All Weights to Uniform")) {
            // Confirms via popup; on confirm: snap->control->ensemble_reset_request = 1
        }
        ImGui::SetItemTooltip(
            "Re-initializes all bandit weights to uniform. Use when weights\n"
            "diverge unhelpfully (e.g., after market regime change). Requires\n"
            "cfg.ensemble_allow_manual_reset=1.");
    }
}
```

### #3 — Atomic control flags (~15min)

For the "Persist Now" + "Reset" buttons, GUI thread sets a flag
read by slow-path. New fields in `TUISharedState`:

```cpp
volatile int ensemble_persist_request;   // 1 = save bandit state on next slow-path
volatile int ensemble_reset_request;     // 1 = uniform-init all bandits
```

Slow-path consumes flag (loads atomically, processes, clears):
```cpp
if (__atomic_load_n(&shared->ensemble_persist_request, __ATOMIC_ACQUIRE)) {
    for (int c = 0; c < num_cores; ++c) {
        if (ml_ensemble_zoos[c].active) {
            // ... compute path + call Bandit_SaveJSON ...
        }
    }
    __atomic_store_n(&shared->ensemble_persist_request, 0, __ATOMIC_RELEASE);
}
```

## Risk register

| Risk | Mitigation |
|---|---|
| GUI render-thread blocking on weight read | `Bandit_GetWeights` is a small loop (≤8 iterations); no I/O. Already runs at ~60fps. |
| Atomic flag race between buttons + slow-path | Single-writer (slow-path clears); GUI sets via __ATOMIC_RELEASE. Standard pattern from v5.10.0c hot-swap RCU. |
| Heatmap renders 0 for inactive regimes (warmup) | Display "(warming up)" instead of "0.000" when n_updates_per_regime[r] < min_warmup_predictions |
| Reset-weights catastrophic if mis-clicked | Confirmation popup; cfg-gated (`ensemble_allow_manual_reset` default 0) |
