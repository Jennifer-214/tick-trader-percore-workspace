# v5.10.0a.G.7 — Per-regime BanditState integration + weighted blend dispatch

**Date:** drafted 2026-05-04
**Branch:** `feat/v5.10-foundation`
**Predecessor:** v5.10.0a.G.6
**Effort estimate:** ~3h
**Hot path:** UNTOUCHED (slow-path predict + dispatch)

## Theme

Per-regime bandit weights drive multi-horizon blend. Each of the 4
regimes (RANGING / TRENDING / VOLATILE / TRENDING_DOWN / MILD_TREND; NUM_REGIMES=5 per Strategies/StrategyInterface.hpp:181 FOREACH_REGIME X-macro) has its own
BanditState with N arms (=N horizons). At per-tick predict time:
classify regime → select that regime's bandit → weighted blend
across N horizons.

Reuses existing `ML_Headers/BanditLearning.hpp` infrastructure.

### #2 — EnsembleModelZoo_InitBandits (~20min)

After `EnsembleModelZoo_AutoDetectFromDir` populates N arms, call
`_InitBandits` to initialize per-regime bandits:

```cpp
template <unsigned F>
inline void EnsembleModelZoo_InitBandits(EnsembleModelZoo<F>* ezoo,
                                          double bandit_eta,
                                          int min_warmup) {
    int n_arms = ezoo->buy_signal_count;  // assume same N across roles
    for (int r = 0; r < NUM_REGIMES; ++r) {
        Bandit_Init(&ezoo->bandits[r], n_arms, bandit_eta, min_warmup);
        // Set arm names for debug/logging:
        for (int a = 0; a < n_arms; ++a) {
            char name[32];
            snprintf(name, 32, "h%d", ezoo->horizon_ticks_at_idx[a]);
            Bandit_SetArmName(&ezoo->bandits[r], a, name);
        }
    }
}
```

Uniform initial weights (`Bandit_Init` defaults). Per-regime
warmup tracked independently in BanditState.

### #3 — Model_Predict_Ensemble_Weighted helper (~45min)

New helper in `ML_Headers/ModelInference.hpp`. Extends G.4's
`Model_Predict_Ensemble`:

```cpp
template <unsigned F>
inline float Model_Predict_Ensemble_Weighted(
    ModelHandle<F>* models, int count,
    const float* features, int num_features,
    const double* weights,        // [count] from BanditState
    int* out_dominant_idx);       // for display: argmax weight*pred
```

Per call:
1. For each loaded model: `Model_Predict` → predictions[i]
2. NaN/Inf-skip per model (reuse G.4's defensive logic)
3. Weighted blend: `final = Σ weight_i * pred_i / Σ weight_i`
4. Out param `out_dominant_idx`: argmax(weight_i × |pred_i - 0.5|)
   (which arm contributed most to the signal direction)

Determinism: same features + same weights → same blend bytewise.

### #4 — MLStrategy dispatch update (~45min)

Update `MLStrategy_BuySignal` (Strategies/MLStrategy.hpp) to dispatch
based on blend_mode:

```cpp
if (state->ensemble_zoo && state->ensemble_zoo->active &&
    state->ensemble_zoo->buy_signal_count > 0) {
    int regime_id = current_regime;  // from RegimeDetector classification
    if (regime_id < 0 || regime_id >= NUM_REGIMES) regime_id = 0;
    state->ensemble_zoo->last_predicted_regime_id = regime_id;

    if (strcmp(state->ensemble_zoo->blend_mode, "selection") == 0) {
        // G.4 path: argmax confidence
        prediction = Model_Predict_Ensemble(
            state->ensemble_zoo->buy_signal,
            state->ensemble_zoo->buy_signal_count,
            state->feature_buf, n,
            &state->ensemble_zoo->last_predicted_horizon_idx);
    } else {
        // G.7 path: weighted blend per regime's bandit
        double weights[ENSEMBLE_HORIZON_MAX];
        Bandit_GetWeights(&state->ensemble_zoo->bandits[regime_id], weights);
        prediction = Model_Predict_Ensemble_Weighted(
            state->ensemble_zoo->buy_signal,
            state->ensemble_zoo->buy_signal_count,
            state->feature_buf, n,
            weights,
            &state->ensemble_zoo->last_predicted_horizon_idx);
    }
} else {
    prediction = Model_Predict(&state->buy_model, state->feature_buf, n);
}
```

### #6 — Per-horizon prediction caching (~30min, perf optimization #1)

All N models train on identical features → standardize ONCE per slow-
path predict, reuse across all N model predicts. Saves N-1 calls to
`FeatureStandardizer_Apply` + scaler matrix math.

```cpp
// In MLStrategy_BuySignal, BEFORE the predict dispatch:
// (existing code:)
FeatureStandardizer_Apply(&state->buy_model.scaler,
                          state->feature_buf, n);
// state->feature_buf is now standardized; reusable across N models
// because all N share the same scaler from G.3 LoadFromCfg.

// Per-horizon prediction caching invariant: if scaler differs across
// N models (shouldn't happen post-G.3, but defensive), skip cache:
if (ezoo->active && ezoo->buy_signal_count > 1) {
    bool all_scalers_same_sha = true;
    const char* base_sha = ezoo->buy_signal[0].scaler_sha256_hex;
    for (int h = 1; h < ezoo->buy_signal_count; ++h) {
        if (strcmp(ezoo->buy_signal[h].scaler_sha256_hex, base_sha) != 0) {
            all_scalers_same_sha = false;
            break;
        }
    }
    if (!all_scalers_same_sha) {
        // Per-model standardize fallback (matches pre-cache behavior)
        // Predicts will re-standardize per model.
        // Operators rarely hit this — same training run = same scaler.
        // Log once at boot, not per slow-path.
    }
}

// Pass standardized feature_buf to Model_Predict_Ensemble_Weighted.
// Each model's predict skips its own scaler apply since features
// are already standardized.
```

**Win:** at N=8, scaler step is ~5-6× faster (1× vs 8×). Predict step
itself is unaffected (each model still runs its own XGBooster). Net
~25-40% speedup on total ensemble predict at N=8.

### #7 — Bandit weight dampening on regime hysteresis (~30min, perf optimization #5)

Existing `cfg.regime_hysteresis` prevents thrash on regime
classification (cycles before regime switch). Apply same logic to
ensemble blend weights: when regime just changed, blend OLD regime's
weights with NEW regime's weights linearly over hysteresis cycles.

```cpp
// In EnsembleModelZoo (G.7 struct extension):
int    regime_transition_cycles_remaining;  // 0 = stable; >0 = transitioning
int    prev_regime_id;                       // for blend during transition

// In MLStrategy_BuySignal regime check:
if (current_regime != ezoo->last_predicted_regime_id) {
    if (ezoo->regime_transition_cycles_remaining == 0) {
        // Just changed; start hysteresis dampening
        ezoo->prev_regime_id = ezoo->last_predicted_regime_id;
        ezoo->regime_transition_cycles_remaining = cfg.regime_hysteresis;
    }
}

if (ezoo->regime_transition_cycles_remaining > 0) {
    // Blend current + previous regime's weights
    double weights_curr[ENSEMBLE_HORIZON_MAX], weights_prev[ENSEMBLE_HORIZON_MAX];
    Bandit_GetWeights(&ezoo->bandits[current_regime], weights_curr);
    Bandit_GetWeights(&ezoo->bandits[ezoo->prev_regime_id], weights_prev);
    double alpha = (double)(cfg.regime_hysteresis -
                            ezoo->regime_transition_cycles_remaining) /
                   (double)cfg.regime_hysteresis;
    double blended[ENSEMBLE_HORIZON_MAX];
    for (int h = 0; h < n_arms; ++h) {
        blended[h] = alpha * weights_curr[h] +
                     (1.0 - alpha) * weights_prev[h];
    }
    // Use blended instead of bandits[current_regime].weights
    prediction = Model_Predict_Ensemble_Weighted(..., blended, ...);
    ezoo->regime_transition_cycles_remaining--;
} else {
    // Stable: use current regime's weights directly
    prediction = Model_Predict_Ensemble_Weighted(...,
        bandits[current_regime].weights, ...);
}
```

**Win:** smoother weight transitions across regime boundaries; reduces
spurious entries triggered by single-tick weight flips.

## Risk register

| Risk | Mitigation |
|---|---|
| Regime ID drift between predict-time and reward-time | G.8 reward attribution uses last_predicted_regime_id from prediction record (not current); test G.8.4 covers this |
| current_regime field unsafe across threads | Per-core slow-path arch: write + read happen on same thread; no race |
| Sum of weights can be zero (all bandits at zero) | `Bandit_GetWeights` always returns normalized; sum guaranteed = 1 |
| Bandit_Update during predict (concurrent) | Predict is read-only on weights; updates happen post-prediction in G.8 reward path |
