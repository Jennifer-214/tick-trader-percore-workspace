## Lessons learned (from commit body + plan amendment history)

### Mid-session scope expansion when structural fix beckons

The original `.F.4c` plan was small-scope LOW risk. Mid-session discovery that SettingsPanel parallel-array indirection was the structural drift surface (cfg state in 2 places: ControllerConfig + parallel arrays + sync logic) triggered the Option 2 decision. This is a canonical application of CLAUDE.md item 19 (Structural fix preferred when bug class can recur) + CLAUDE.md item 31 (Framework-discipline meta-principle, codified at `.F.4d` planning).

**Principle reinforced:** when mid-session inspection reveals the planned scope would ship-then-rework, expand scope to land the structural fix once. Aligns with `feedback_no_mvp_for_plumbing_only_for_unknown_unknowns`.

### Class 14 5th-recurrence lesson: delete stale samples, don't preserve-with-notice

The 2026-05-14 audit-gate-triggered rewrite of the `.F.4c` plan body DELETED stale code samples that referenced fictional APIs (`Cfg_LoadFromString`, `cfg_field_offset`, `cfg_dispatch_target<KIND>`, etc.). Amendment-notice scaffolding was deemed insufficient because a fresh-context coder reading top-down might copy body samples verbatim before noticing the notice. See `DOCS/RECURRING_BUG_PATTERNS.md` Class 14 5th-recurrence entry + `DESIGN_SPECS/audit-driven-pre-coding-gate.md` § Lessons.

### Bitmap dispatcher framework primitive: ship the foundation early

The bitmap dispatcher framework lands at `.F.4c` even though only ONE canonical application exists at ship time (the GUI walker). The decision to ship the framework primitive separately (vs lazily) is justified by the 5+ downstream consumers planned (`.F.4d` stamp emit + drift check; `.F.4e` CLI subcommands; TECH_DEBT-067 per-core observability). Framework discipline meta-principle says: invest upfront when N >= 2 future applications + bug class can recur. The framework also enables the "GUI <-> engine thread isolation" rule (each subsystem has its own typed cfg mirror; file is canonical channel).
