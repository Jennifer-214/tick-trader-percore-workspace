## Why portfolio turnover

Operator visibility metric. Tracks how stable the ensemble's top-K
arm picks are over time:
- High turnover → unstable model (top picks shifting frequently);
  signals ensemble is thrashing, possibly regime-mismatched
- Low turnover → stable convictions; ensemble is consistently
  weighting the same arms

Useful for:
- Diagnostic during paper-test (is ensemble committing or flipping?)
- Health monitoring (sudden turnover spike could signal regime
  change OR model degradation)
- Regime hysteresis tuning (high turnover = need more hysteresis)

## Design

### Step 1 — RollingTurnover struct

File: `ML_Headers/RollingTurnover.hpp` (NEW; small standalone)

```cpp
// Top-K membership tracker via bit-mask (8 arms fit in uint8_t).
// Symmetric-difference metric between consecutive top-K sets:
// |A ∆ B| / K where ∆ is symmetric set difference.
// 0.0 = identical sets; 1.0 = fully disjoint sets.

#define ROLLING_TURNOVER_MAX_WINDOW 256

struct RollingTurnover {
    uint8_t  topk_mask_ring[ROLLING_TURNOVER_MAX_WINDOW];
    int      head;                  // next write slot
    int      count;                 // total pushes (≤ window)
    int      window;                // active window size (cfg-tunable)
    int      topk;                  // K value (cfg-tunable; ≤8)
    double   last_turnover;         // most recent compute result
};

static inline void RollingTurnover_Init(RollingTurnover *rt,
                                          int window, int topk) {
    memset(rt, 0, sizeof(*rt));
    if (window < 2) window = 2;
    if (window > ROLLING_TURNOVER_MAX_WINDOW) window = ROLLING_TURNOVER_MAX_WINDOW;
    if (topk < 1)  topk = 1;
    if (topk > 8)  topk = 8;  // ENSEMBLE_HORIZON_MAX
    rt->window = window;
    rt->topk   = topk;
}

// Compute top-K bit-mask from weights array (descending sort by weight,
// take top K indices, set bit i for each top-K member).
static inline uint8_t topk_mask_from_weights(const double* weights, int n,
                                                int topk) {
    if (n <= 0 || topk <= 0) return 0;
    if (topk >= n) {
        // All arms are "top"; mask = (1<<n) - 1
        return (uint8_t)((1u << n) - 1u);
    }
    // O(N*K) selection — fine for N=8, K=3 = 24 ops
    int picked[8] = {0};
    uint8_t mask = 0;
    for (int k = 0; k < topk; k++) {
        int best_idx = -1;
        double best_val = -1e30;
        for (int i = 0; i < n; i++) {
            if (picked[i]) continue;
            if (weights[i] > best_val) { best_val = weights[i]; best_idx = i; }
        }
        if (best_idx >= 0) { picked[best_idx] = 1; mask |= (1u << best_idx); }
    }
    return mask;
}

// Push a top-K mask to the ring; compute symmetric-difference vs
// previous mask in same call (so caller doesn't need separate read fn).
// Returns the just-computed turnover ratio for this push.
static inline double RollingTurnover_Push(RollingTurnover *rt, uint8_t mask) {
    double turnover = 0.0;
    if (rt->count > 0) {
        // Compare with previous (head - 1) slot.
        int prev_idx = (rt->head - 1 + rt->window) % rt->window;
        uint8_t prev_mask = rt->topk_mask_ring[prev_idx];
        uint8_t diff = mask ^ prev_mask;  // symmetric difference
        // popcount via builtin (cross-platform; fall back via byte if needed)
        int diff_bits = __builtin_popcount(diff);
        turnover = (double)diff_bits / (double)(rt->topk * 2);
        // ÷(topk*2) because |A∆B| ≤ |A|+|B| = 2K; divides give [0,1] range
    }
    int slot = rt->head % rt->window;
    rt->topk_mask_ring[slot] = mask;
    rt->head = (rt->head + 1) % rt->window;
    if (rt->count < rt->window) rt->count++;
    rt->last_turnover = turnover;
    return turnover;
}

// Compute average turnover across the window
static inline double RollingTurnover_Compute(const RollingTurnover *rt) {
    if (rt->count < 2) return 0.0;
    double sum = 0.0;
    int n = rt->count;
    for (int i = 1; i < n; i++) {
        int curr_idx = (rt->head - n + i + rt->window) % rt->window;
        int prev_idx = (rt->head - n + i - 1 + rt->window) % rt->window;
        uint8_t diff = rt->topk_mask_ring[curr_idx] ^ rt->topk_mask_ring[prev_idx];
        sum += (double)__builtin_popcount(diff) / (double)(rt->topk * 2);
    }
    return sum / (double)(n - 1);
}
```

### Step 6 — Tests

File: `tests/controller_test.cpp`

1. **RollingTurnover math (4 tests)**
   - Stable picks (same top-3 every push) → turnover ≈ 0
   - Random picks (different top-3 each push) → turnover ≈ 1.0
   - K=1 degenerate (single arm) → either 0 (same arm) or 1 (different)
   - Init defaults sane (window=100, topk=3)

2. **Bit-mask correctness (3 tests)**
   - topk_mask_from_weights: descending weights → top-K mask correct
   - K >= N: all-arms mask = (1<<N) - 1

3. **Cfg parser (2 tests)**
   - Defaults: window=100, topk=3
   - Parse non-default values

4. **Compute over window (2 tests)**
   - Insufficient data (count < 2) → returns 0.0

## Latency analysis

**Hot path: UNTOUCHED.** Slow-path only.

**Slow path:**
- `topk_mask_from_weights`: O(N*K) selection sort = 24 ops at N=8, K=3.
  ~30-50 ns per call.
- `RollingTurnover_Push`: 1 popcount (1 cycle) + ring write + comparison.
  ~10-20 ns per call.
- `RollingTurnover_Compute`: O(window) loop with popcount.
  ~window × 5ns = ~500ns at window=100. Called per slow-path cycle for
  TUI snapshot.
- **Total per slow-path cycle:** ~50-100ns push + ~500ns compute = ~600ns
  total. Within 100µs budget; ~0.6% of slow-path budget.

**HOT_PATH_CHANGELOG.md entry:** YES (slow-path additions ≥10ns/cycle
per Check 23). Documented inline at coding time.

**FUTURE OPPORTUNITY:** if compute cost becomes load-bearing, cache the
per-cycle popcount sum incrementally rather than full window walk
(O(1) per push instead of O(window) per compute). Defer until profiler
flags it.
