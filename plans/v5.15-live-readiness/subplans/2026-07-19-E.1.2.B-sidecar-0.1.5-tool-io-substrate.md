## 2. Typing lock (D-380 / D-382 / D-384)

1. **Single-doc plain JSON**; **uniform record-set TABLE** `{schema, rows}`; **schema-as-DATA registry** (language-neutral JSON, both C++ + Python read via foxtag's existing `json_parse`); **comments-only-never-code**.
2. **CRUX (D-382):** `foxtag <cmd> --json` emits a COMPLETE self-describing envelope, frame data-driven off the registry + one def — the `Version.hpp` model (two READERS of one source, not two truths).
3. **`findings/1` (D-384):** `status.findings` is a CROSS-CUTTING envelope field → its schema lives ONCE at the envelope level, governing every kind. Every PAYLOAD kind is uniformly `{tables:{…}}`. A `verdict` = `kind:"verdict"` + empty payload + populated `status.findings`. No per-kind container special-case; `read`/`validate` uniform, zero kind-branch.
4. **`schema_version` single-source-DERIVED (D-384):** the D-346-locked grammar version is read at emit from the ONE schema-doc SSoT line — never hardcoded (a hardcode = a mirror of a locked string).

## 3. Concrete shapes (the build)

### 3a. The envelope — `foxtag grammar --json` (1st canonical, O3 payload)
```json
{ "envelope_version":"1.0", "kind":"grammar", "schema_version":"<derived from schema doc>",
  "payload_schema_version":"grammar/1",
  "producer":{"tool":"foxtag","version":"<TOOLCHAIN_VERSION>","command":"grammar","args":["--json"]},
  "status":{"ok":true,"code":0,"findings":[]},          // findings/1 schema; empty for a pure producer
  "target":{"paths":[],"git_head":"<.git/HEAD read>"},
  "payload":{
    "categories":  {"schema":["name"], "rows":[["CAPITAL_BEARING"],["HOT_PATH"]]},
    "ref_subcats": {"schema":["name"], "rows":[["DECISION"],["POSTMORTEM"]]},
    "concern":     {"schema":["name"], "rows":[["DETERMINISM"],["LATENCY"]]},
    "surface":     {"schema":["name"], "rows":[["HOT_PATH"],["SLOW_PATH"]]},
    "unit_types":  {"schema":["name","closable"], "rows":[["FUNCTION",true],["STRUCT",true],["FILE",false],["ASSERT",false]]}
  } }
```
- **O3** = the 4 fence/vocab sets (real `Grammar` members `foxtag.hpp:220-226`, already parity-counted) + the node-model `unit_types` (from the free fn `foxtag.hpp:234`, already parity-consistent with Python — both 10-incl-`ASSERT`). It's the set the plugin hardcodes → emitting it kills the mirror.

### 3c. One envelope def + emit/read (two readers, one source)
```python

def emit(kind, payload, *, producer, git_head, schema_version, findings=()):
    validate_payload(payload, REG[schema_ver(kind)])   # every payload kind: {tables:{…}} → rows conform, else FAIL LOUD
    validate_findings(findings, REG["findings/1"])      # the ONE cross-cutting findings schema, every kind

def read(env): return env["payload"]                    # uniform over ALL payload kinds (no kind-branch)
```
