## Theme

v5.10.0c (hot model swap) shipped without re-running the v5.9.5i inference cfg drift detection block + xgb_hyperparams WARN block + label registry hash refusal that fire at boot. Result: a hot-swapped model whose stamp differs from runtime cfg silently miscalibrates predictions, with no operator log.

v5.10.0a (multi-horizon ensemble) shipped with a parallel-handle architecture (`EnsembleModelZoo` arrays) that the boot-time drift block doesn't iterate. Result: ensemble-mode operators bypass Tier 1/Tier 2 cfg drift detection entirely.

These two gaps share the same architectural shape: a load/validate function that's only wired to one of the engine's lifecycle entry points, and that doesn't know about the parallel-handle structure of the ensemble.

**Unified fix (audit recommendation):** extract `EventLoop_ValidateLoadedZooAgainstCfg(zoo, ezoo, cfg, core_id, strict)` covering single + ensemble handles. Call from boot loop AND hot swap branch. Closes Findings #3, #7, #10 in one extraction.

**Phase B operator decision:** Finding #4 (hot swap doesn't touch ensemble zoo) needs an explicit choice — refuse hot swap when ensemble is active (Option A, simpler) OR extend swap to also Free+Init+AutoDetect the ensemble zoo (Option B, more complete). Plan defaults to Option A; Option B is a follow-up if operator wants it.

## Phase A — Extract `CoreModelZoo_ValidateAgainstCfg` helper (`v5.10.2.A`)

**Audit:** Findings #3 (CRITICAL — sort of, marked HIGH because hot-swap is rare), #7, #10.

The boot-time validation block at `EngineSharded.hpp:964-1077` (drift detection) + `EngineSharded.hpp:885-960` (training_poll_interval + xgb_hyperparams + build_flags_hash WARN — three v5.9.4/5.9.5h subgroups, ALL three subsumed by extraction) inlines its logic at boot. v5.10.0c hot swap reload at `EngineSharded.hpp:2483-2510` (within the 2435-2513 swap branch) skips ALL blocks. Result: post-swap, drift goes undetected.

Same blocks iterate `&zoo->buy_signal/barrier/regime/exit` (single zoo) only — never the ensemble's parallel arrays at `&ezoo->buy_signal[h]/barrier[h]/...`. Result: ensemble-mode operator bypasses drift detection entirely.

**Helper location:** `ML_Headers/CoreModelZoo.hpp` (matches v5.10.1.B precedent — `EnsembleZoo_VerifyGridMemberConsistency` at CoreModelZoo.hpp:1141 lives next to the EnsembleModelZoo struct it validates). Renamed from initial draft `EventLoop_ValidateLoadedZooAgainstCfg` to `CoreModelZoo_ValidateAgainstCfg` for naming consistency. NOT in `CoreFrameworks/ControllerEventLoop.hpp` (rejected post-readiness — header dependencies stay local in ML_Headers).

**Cross-reference:** v5.10.1.B precedent at `ML_Headers/CoreModelZoo.hpp:1141` for the canonical "extraction with iteration over single + ensemble" shape.

### Step 0: Helper extraction

Create function in `ML_Headers/CoreModelZoo.hpp` (alongside `EnsembleZoo_VerifyGridMemberConsistency` from v5.10.1.B; both are post-load validators):

```cpp
// v5.10.2.A — Extracted from EngineSharded.hpp boot loop body. Subsumes
// THREE existing WARN/REFUSE subgroups uniformly across single zoo + ensemble:
//   1. inference_cfg drift (v5.9.5i; was at EngineSharded.hpp:964-1077)
//   2. xgb_hyperparams + training_poll_interval + build_flags_hash WARN
//      (v5.9.4 + v5.9.5h; was at EngineSharded.hpp:885-960)
//
// Writes cfg_drift_tier1/tier2_count + strict_refused into ctx.
// Returns 0 on accept, -1 on REFUSE in strict mode (Tier 1 mismatch).
//
// Callable from:
//   - EngineSharded boot loop (after CoreModelZoo_LoadFromDir or
//     EnsembleModelZoo_AutoDetectFromDir succeeds)
//   - EngineSharded hot swap branch (after CoreModelZoo_LoadFromDir
//     for the swap)
//
// Acknowledgement-flag handling: helper signature accepts BOTH suppression
// flags. Existing boot blocks gate on `!cfg.acknowledge_inference_cfg_drift`
// (drift block) and `!cfg.acknowledge_cross_binary_version_drift` (xgb block).
// Helper preserves both contracts via params.
//
// In strict mode, Tier 1 REFUSE returns -1 → caller decides:
//   - boot context: fatal (operator misconfig at boot)
//   - hot swap context: log + leave (model_load_failed=1; operator manually
//     reverts via cfg+restart). True rollback deferred — no pre-swap path
//     caching infrastructure exists.
template <unsigned F>
inline int CoreModelZoo_ValidateAgainstCfg(
    CoreModelZoo<F>* zoo,
    EnsembleModelZoo<F>* ezoo,                      // nullptr if not active
    const ControllerConfig<F>& cfg,
    int core_id,
    int strict_mode,                                 // cfg.held_out_gate_strict
    int acknowledge_inference_cfg_drift,             // suppresses drift block
    int acknowledge_cross_binary_version_drift,      // suppresses xgb/poll/build_flags WARN
    CoreContext<F>* ctx                              // for tier1/2 counter writeback
) {
    int tier1_count = 0;
    int tier2_count = 0;
    int tier1_refused = 0;

    // Helper lambda for one ModelHandle's drift check; same logic regardless
    // of whether handle came from single zoo or ensemble.
    auto check_handle = [&](ModelHandle<F>* h, const char *role_name, int h_idx) {
        if (!h || (!h->has_xgb_hyperparams && !h->has_stamp_inference_cfg)) return;
        // Tier 1 (REFUSE in strict): freshness_tau, threshold_scale, barrier_gate_enabled
        //   gated by !acknowledge_inference_cfg_drift
        // ... copy-paste body from EngineSharded.hpp:964-1077 ...
        // Tier 2 (WARN regardless): hard_block, bandit, fees
        //   gated by !acknowledge_inference_cfg_drift
        // ... copy-paste from same block ...
        // xgb_hyperparams + training_poll_interval + build_flags_hash WARN
        //   gated by !acknowledge_cross_binary_version_drift
        // ... copy-paste from EngineSharded.hpp:885-960 ...
        // (Replace per-handle role_name + h_idx in log messages so ensemble
        // entries are distinguishable from single-zoo: "core 0 ensemble[2] role=buy_signal".)
    };

    // 1. Single zoo: 4 roles
    if (zoo) {
        check_handle(&zoo->buy_signal, "buy_signal", -1);
        check_handle(&zoo->barrier,    "barrier",    -1);
        check_handle(&zoo->regime,     "regime",     -1);
        check_handle(&zoo->exit,       "exit",       -1);  // CoreModelZoo struct has `exit` (singular)
    }
    // 2. Ensemble handles (Finding #7 closure): 4 roles × N horizons
    //    EnsembleModelZoo struct uses `exit_predictor` (NOT `exit`) per CoreModelZoo.hpp:616
    if (ezoo && ezoo->active) {
        for (int h = 0; h < ezoo->buy_signal_count; ++h)
            check_handle(&ezoo->buy_signal[h], "buy_signal", h);
        for (int h = 0; h < ezoo->barrier_count; ++h)
            check_handle(&ezoo->barrier[h], "barrier", h);
        for (int h = 0; h < ezoo->regime_count; ++h)
            check_handle(&ezoo->regime[h], "regime", h);
        for (int h = 0; h < ezoo->exit_predictor_count; ++h)
            check_handle(&ezoo->exit_predictor[h], "exit", h);
    }

    // Writeback counters (Finding #10 closure)
    ctx->cfg_drift_tier1_count = (uint8_t)(tier1_count > 255 ? 255 : tier1_count);
    ctx->cfg_drift_tier2_count = (uint8_t)(tier2_count > 255 ? 255 : tier2_count);
    ctx->cfg_drift_strict_refused = (tier1_refused > 0) ? 1 : 0;

    return (strict_mode && tier1_refused > 0) ? -1 : 0;
}
```

### Step 1: Replace inline body at boot loop

`EngineSharded.hpp:964-1077` (drift block) + `EngineSharded.hpp:885-960` (xgb-and-friends block — all 3 subgroups: training_poll_interval, xgb_hyperparams, build_flags_hash) collapse into a single call:
```cpp
int validate_rc = CoreModelZoo_ValidateAgainstCfg(
    &ml_zoos[i],
    state.cores[i].ensemble_handle ? &ml_ensemble_zoos[i] : nullptr,
    cfg,
    i,
    cfg.held_out_gate_strict,
    cfg.acknowledge_inference_cfg_drift,
    cfg.acknowledge_cross_binary_version_drift,
    &state.cores[i]);
if (validate_rc < 0) {
    fprintf(stderr,
        "[boot] FATAL: core %d Tier 1 cfg drift in strict mode; "
        "operator must reconcile cfg vs stamp before booting.\n", i);
    return -1; // engine refuses to boot
}
```

### Step 2: Add validator call to hot swap branch

Operator gets a clear diagnostic + can manually revert via cfg+restart. Document this trade-off in the audit followup.

## Phase B — Hot swap REFUSE when ensemble active (`v5.10.2.B`)

**Audit:** Finding #4 (HIGH) — hot swap reloads single zoo only, never `ml_ensemble_zoos[c]`. When ensemble is active (`state.cores[c].ensemble_handle != nullptr`), the dispatcher reads ensemble first (`Strategies/StrategyParameters.hpp:794`) — so hot-swapping the single zoo is a NO-OP for actual inference.

**Step 0:** In hot swap branch (EngineSharded.hpp ~2483, within the 2435-2513 swap block), guard the swap on `ensemble_handle == nullptr`:

```cpp
// v5.10.2.B — Finding #4 closure: REFUSE hot swap when ensemble active.
// Dispatcher reads ensemble first; swap of single zoo is silently no-op.
// Operator must restart engine to swap horizon set (full ensemble reload
// is Option B — deferred to v5.10.2.X if needed).
if (state.cores[c].ensemble_handle != nullptr) {
    fprintf(stderr,
        "[hot_swap] core %d REFUSED: ensemble inference active; "
        "swap of single-zoo model would not affect actual predictions. "
        "Restart engine with new core_%d_model_dir to swap horizon set.\n",
        c, c);
    __atomic_store_n(&g_shared.swap_model_path_requested[c], 0, __ATOMIC_RELEASE);
    // Do NOT set model_load_failed; the existing ensemble continues to serve.
    return; // or skip-to-next-core depending on outer loop structure
}
// ... existing swap logic continues here ...
```

Place the guard BEFORE the `CoreModelZoo_Free(swap_zoo)` call so a refused swap leaves the existing zoo intact.

**Verification:**

**Risk:** Low. Refusal-path is a guard; doesn't modify existing behavior unless ensemble is active.

**Sub-ship gate:** `./build.sh test` passes (+1 new test). Tag `v5.10.2.B`.

**Deferred (Option B for #4):** Full ensemble swap (Free + Init + AutoDetect + Refresh state.cores[c].ensemble_handle) lives in `v5.10.2.X` follow-up if operator confirms desire. ~2.5h additional work; covers the case where operator wants to hot-swap the entire horizon set without restart.
