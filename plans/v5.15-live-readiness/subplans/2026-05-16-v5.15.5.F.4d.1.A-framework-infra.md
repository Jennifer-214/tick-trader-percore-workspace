## DOD analysis (Path γ shape)

### Cluster placement
- Auto-generated masks (`g_*_cfg_stamp_bound_cfg_derived_mask`): `.rodata`; constexpr; zero runtime init
- Consumer iteration via `CFG_FIELD_FOR_EACH_SET_BIT`: branchless TZCNT; one `desc[idx]` lookup per set bit
- Canonical body emit buffer: stack-allocated `char[8192]` at test-call time (no heap; H1)

### Branchless dispatch
- Mask iteration: `__builtin_ctzll` single TZCNT instruction; no per-row branch
- Per H20 + `branchless-dispatch-discipline.md`: Path γ STRENGTHENS branchless discipline vs Path β's per-row branch walker

### Cache layout
- Masks are small (`CfgMaskArray<N_WORDS>` where N_WORDS = `(FIELD_IDX_END + 63) / 64`; typically 2-4 uint64_t words per registry); fits in L1 trivially
- Descriptor array lookup pattern is identical to existing FOREACH_METADATA_BIT consumers (SettingsPanel.hpp); sequential prefetch friendly

### Bit-packing
- No new bit-packed structs at `.A`. Metadata bits stay in existing `metadata_flags` uint16_t (13 bits used + 3 bits headroom per `:212` static_assert).
