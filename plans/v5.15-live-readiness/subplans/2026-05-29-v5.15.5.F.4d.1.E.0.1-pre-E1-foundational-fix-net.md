## Per-finding fix-designs

### F-056 — deterministic sqrt under native
`FixedPoint/FixedPointN.hpp` (native block, ~line 1254): **delete** the `template<> inline FPN<64> FPN_Sqrt<64>(...)` specialization that forwards to `FP64_Sqrt`. With it gone, `FPN_Sqrt<64>` resolves to the primary template (~line 873, deterministic Newton-Raphson). All other native specializations (AddSat/Sub/Mul/Div/comparisons) stay — they're exact integer ops, deterministic. **Incidentally closes F-078** (the partial-specialization inconsistency — sqrt now matches Exp/Sin/Cos/Log/InvSqrt which were never specialized). Cost: sqrt is slow-path/feature-only (`FlowFeatures` stddev, `FeatureRegistry`, `RidgeBlender`) → zero hot-path latency impact; determinism is load-bearing for ML train-serve parity (M5; `RidgeBlender.hpp:39`).

### F-058 — memcpy, not pointer-pun (atomic with F-056)
`FixedPointN.hpp:1221-1226`: replace
```c++
FP64 r; r.magnitude = *((__uint128_t*)v.w); r.sign = v.sign; return r;   // verbatim fragment (FP64 = FixedPoint64.hpp); not a standalone-compilable spec
```
with
```c++
FP64 r; __uint128_t m; memcpy(&m, v.w, sizeof(m)); r.magnitude = m; r.sign = v.sign; return r;   // verbatim fragment (FP64 = FixedPoint64.hpp); not a standalone-compilable spec
```
(+ symmetric `_from_fp64`). Removes strict-aliasing + alignment UB; `memcpy` is the standard-blessed type-pun, lowers to the same instruction at `-O2+` (zero cost). Byte-preserving on x86 (same little-endian layout) → no behavior change, just UB removal. **Land WITH F-056** — they share the native block + the determinism harness is the joint acceptance test.

### F-057 — tests build the shipped flags
`CMakeLists.txt`: add, after the test-target definitions, `if(USE_NATIVE_128) target_compile_definitions(controller_test PRIVATE USE_NATIVE_128); target_compile_definitions(parity_harness PRIVATE USE_NATIVE_128); endif()` (+ `depth_recorder_test` if it touches FP). Mirror in `build.sh` tsan/asan paths. **Must land WITH F-056** — enabling native in tests *before* the sqrt fix would surface the sqrt divergence as test failures (which is the point — but we fix the cause first).

### F-054 / F-055 — one locale-immune parser (DROP-IN; the audit found a simpler fix)
`Backtest/BacktestEngine.hpp:88-96` + `DataStream/DepthReplayState.hpp:224-227`: replace each `strtod(p, &p)` with **`tt::parse_double_fast_advance(p, &p)`** — `CoreFrameworks/ParseFast.hpp:78` already provides this exact strtod-style "parse + advance the pointer" variant, so it's a **near-1:1 substitution** (NO find-comma restructure needed — the `.E.0.1` audit surfaced this; my first draft over-engineered it). Same locale-immune `std::from_chars` core LIVE uses → closes the backtest↔live asymmetry (single-source-of-truth) AND is faster than `strtod`. **Acceptance via the replay-locale gate.**

### F-076 — fingerprint determinism (Phase-A confirm, then fold-or-route)
Confirm `Fingerprint_Compute` (locate; finding cites raw-byte SHA-256 over an un-zero-init `ControllerConfig`). If it hashes raw struct bytes without zero-init → uninitialized padding enters the hash → non-deterministic lineage (H12/H9). **Fix** (if folded): `memset(&cfg, 0, sizeof cfg)` before populate, OR hash field-by-field (canonical, padding-free). **Fold into this ship IF** Net-1 includes a stamp/fingerprint/lineage characterization (it gates that); else → PRE-PAPER-TEST.

### F-107 — log-emit locale → PRE-PAPER-TEST
calib/trade-log float CSV emit should use the `LC_NUMERIC=C`-pinned canonical emit (`tt::format_double_canonical`, as RunHistory/stamp emit do). **Output-only → NOT net-gating** (logs don't feed the net/replay) → route to PRE-PAPER-TEST (task #4). Listed here only to close the determinism-cluster sweep with an explicit disposition.

### F-059 — golden-master (NOT this ship; Net-1)
Cross-referenced: the real per-fill `tp_pct/sl_pct` exit path gets a golden-master characterization (freeze real `ExecutionCore_Tick` exit output on recorded ticks; diff) — **a CI characterization gate, not a reimplemented oracle.** Retire/scope `LegacyReferenceDriver`. Home = Net-1; depends on F-054/F-055 (deterministic replay) landing here first.

## Honest risks

- **R1 — `FPN_FromDouble<64>`/`FPN_ToDouble<64>` are the NAMED most-likely native/generic divergence after sqrt** (corrected — the original "non-sqrt ops are exact integer = identical" reasoning was WRONG to exclude them). They are ALSO native specializations (`FixedPointN.hpp:1250-1251`) that round-trip `double` — native `FP64_FromDouble` = `floor` + `frac×2⁶⁴`-truncate (`FixedPoint64.hpp:38-41`) vs the generic multi-word construction (`:162+`) → different rounding → they **do** differ on non-exact doubles. And they sit on the **cfg→FPN ingest path** (`CfgFieldDispatch.hpp:80/242/283` — *every* cfg double). **Pre-decided disposition (so Phase B isn't surprised):** the divergence is EXPECTED + **resolved by F-057** (tests build native → tested==shipped; same mechanism as sqrt's test-vs-prod gap) — NOT a separate F-056-style fix, because (a) `FromDouble` inherently touches `double` in BOTH paths (nothing to "delete down to" a double-free version, unlike sqrt → deterministic NR), and (b) native `FromDouble` is IEEE-deterministic (`floor`+`mul`+truncate) + consistently used post-F-057 (no target builds generic `FPN<64>`). **Verify at Phase B:** native `FromDouble`/`ToDouble` are cross-run/cross-binary deterministic (they should be). If a naïve ±native compare flags them, that's the expected algorithm difference, NOT a regression. Severity MED (named + pre-dispositioned; was the unnamed gap your R1-pushback surfaced).
- **R2 — `parse_double_fast` shifts backtest results** vs `strtod` (rounding). *Mitigation:* `from_chars` is correctly-rounded + matches live; any shift corrects prior locale-fragility (not a regression). Regenerate any backtest goldens deliberately (`/test-strength-audit`). Severity LOW.
- **R3 — F-058 memcpy changes bytes on non-x86.** Engine is x86-only (`-march=native`); byte-preserving there. Severity NIL (x86).
- **R4 — F-076 fix changes model fingerprints** (lineage break). Existing fingerprints were non-deterministic anyway; document the break. Severity LOW (only if F-076 folded).
- **R5 — scope creep into the broad 45.** Held: this ship is *only* the net-gating determinism findings; the broad correctness backlog stays PRE-PAPER-TEST (task #4). Severity NIL (bounded by design).
