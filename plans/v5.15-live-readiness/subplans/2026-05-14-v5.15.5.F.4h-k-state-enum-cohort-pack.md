## Step 1 — Define K-state shifts + masks in `ResolvedCoreCfg.hpp` (~30 LOC)

Per `DESIGN_SPECS/refactor-patterns/multi-bit-state-encoding-pattern.md` + `DESIGN_SPECS/refactor-patterns/slow-path-cfg-resolution-cache-pattern.md` § "K-state enum cohort packing":

```cpp
// CoreFrameworks/ResolvedCoreCfg.hpp (extend from .F.4e)

// K-state cohort: 11 bits packed into uint16_t k_state_word (line 0 HOT)
//
// Bit layout (LSB → MSB):
//   bits 0-0:  bandit_algorithm        (1 bit: 0=Exp3-IX, 1=Thompson)
//   bit  1:    engine_arch             (1 bit: 0=Centralized, 1=Per-Core)
//   bits 2-3:  risk_degradation_curve  (2 bits: 0=OFF, 1=LINEAR, 2=EXP, 3=STEP)
//   bits 4-6:  barrier_blend_mode      (3 bits: 0=LEGACY, 1=BLEND, 2=DOMINANT, 3=SHADOW_A, 4=SHADOW_B; 3 reserved)
//   bits 7-8:  regime_state_current    (2 bits: 0=RANGING, 1=TRENDING, 2=VOLATILE, 3=MILD_TREND)
//   bits 9-10: regime_state_proposed   (2 bits: same as current)
//   bits 11-15: reserved for future K-state fields

constexpr uint16_t K_BANDIT_ALGO_SHIFT     = 0;
constexpr uint16_t K_BANDIT_ALGO_MASK      = 0x0001;  // 1 bit (2 states)
constexpr uint16_t K_ENGINE_ARCH_SHIFT     = 1;
constexpr uint16_t K_ENGINE_ARCH_MASK      = 0x0002;  // 1 bit (2 states)
constexpr uint16_t K_RISK_CURVE_SHIFT      = 2;
constexpr uint16_t K_RISK_CURVE_MASK       = 0x000C;  // 2 bits (4 states)
constexpr uint16_t K_BARRIER_BLEND_SHIFT   = 4;
constexpr uint16_t K_BARRIER_BLEND_MASK    = 0x0070;  // 3 bits (5 states; 3 reserved for future)
constexpr uint16_t K_REGIME_CURR_SHIFT     = 7;
constexpr uint16_t K_REGIME_CURR_MASK      = 0x0180;  // 2 bits (4 states)
constexpr uint16_t K_REGIME_PROP_SHIFT     = 9;
constexpr uint16_t K_REGIME_PROP_MASK      = 0x0600;  // 2 bits (4 states)

// Overflow guard (per bitmap-overflow-protection-discipline.md):
static_assert((K_REGIME_PROP_MASK >> K_REGIME_PROP_SHIFT) < (1u << 2),
              "K_REGIME_PROP exceeded 2-bit allocation");
static_assert(K_REGIME_PROP_SHIFT + 2 <= 16,
              "k_state_word overflows uint16_t — split into uint32_t or remove a field");
```

Lock the bit assignments. Reordering = breaking change requiring alias pattern.

## Step 2 — Add MBS_* inference API to `MemHeaders/BitmapMacros.hpp` (~50 LOC)

Per `DESIGN_SPECS/refactor-patterns/multi-bit-state-encoding-pattern.md` § "Branchless inference API":

```cpp
// MemHeaders/BitmapMacros.hpp (extend; sister of BITMAP_* per CLAUDE.md item 20)

// MBS_PACK: pack value into field at shift position
#define MBS_PACK(shift, val)  ((static_cast<uint16_t>(val) << (shift)))

// MBS_GET: extract value from field
#define MBS_GET(field, mask, shift)  (((field) & (mask)) >> (shift))

// MBS_SET: write value (clear bits, then OR new value)
#define MBS_SET(field, mask, shift, val) \
    ((field) = ((field) & ~(mask)) | (((val) << (shift)) & (mask)))

// MBS_EQ: branchless equality check
#define MBS_EQ(field, mask, shift, val) \
    (((field) & (mask)) == ((val) << (shift)))

// MBS_IN_SET: branchless set membership check
// set_mask is a bitmap with bit N set iff value N is in the set
// (E.g., for regime ∈ {RANGING (0), MILD_TREND (3)}: set_mask = (1<<0) | (1<<3) = 0x09)
#define MBS_IN_SET(field, mask, shift, set_mask) \
    (((set_mask) >> MBS_GET(field, mask, shift)) & 1)

// MBS_SELECT_EQ: branchless conditional value selection
#define MBS_SELECT_EQ(field, mask, shift, val, true_val, false_val) \
    (MBS_EQ(field, mask, shift, val) ? (true_val) : (false_val))
```

Add unit tests:
```cpp
// tests/controller_test.cpp (new section):
{
    uint16_t state = 0;
    MBS_SET(state, K_RISK_CURVE_MASK, K_RISK_CURVE_SHIFT, 2);  // EXP
    check("MBS_GET reads back what MBS_SET wrote",
          MBS_GET(state, K_RISK_CURVE_MASK, K_RISK_CURVE_SHIFT) == 2);
    check("MBS_EQ branchless equality",
          MBS_EQ(state, K_RISK_CURVE_MASK, K_RISK_CURVE_SHIFT, 2));
    check("MBS_EQ false for wrong value",
          !MBS_EQ(state, K_RISK_CURVE_MASK, K_RISK_CURVE_SHIFT, 3));
    check("MBS_IN_SET catches membership",
          MBS_IN_SET(state, K_RISK_CURVE_MASK, K_RISK_CURVE_SHIFT, (1<<2) | (1<<3)));  // EXP or STEP
    check("MBS_IN_SET rejects non-membership",
          !MBS_IN_SET(state, K_RISK_CURVE_MASK, K_RISK_CURVE_SHIFT, (1<<0) | (1<<1)));  // OFF or LINEAR
}
```

## Step 3 — Populate `k_state_word` in `ResolveCoreCfg` (~20 LOC)

Update `ResolveCoreCfg` to pack the 6 K-state fields:

```cpp
template <unsigned F>
inline void ResolveCoreCfg(const Cfg* cfg, int core_idx, ResolvedCoreCfg<F>* resolved) {
    // ... existing field resolution from .F.4e ...

    // Pack K-state cohort:
    int bandit_algo    = (int)Cfg_GetEffective_bandit_algorithm(cfg, core_idx);
    int engine_arch    = (int)cfg->engine_arch;  // not per-core
    int risk_curve     = (int)Cfg_GetEffective_risk_degradation_curve(cfg, core_idx);
    int barrier_blend  = (int)Cfg_GetEffective_barrier_blend_mode(cfg, core_idx);
    int regime_curr    = (int)els->slow_state.regime_state_current;     // from slow-path state (.F.4e + 5.1.2+)
    int regime_prop    = (int)els->slow_state.regime_state_proposed;

    resolved->k_state_word =
        MBS_PACK(K_BANDIT_ALGO_SHIFT,   bandit_algo) |
        MBS_PACK(K_ENGINE_ARCH_SHIFT,   engine_arch) |
        MBS_PACK(K_RISK_CURVE_SHIFT,    risk_curve) |
        MBS_PACK(K_BARRIER_BLEND_SHIFT, barrier_blend) |
        MBS_PACK(K_REGIME_CURR_SHIFT,   regime_curr) |
        MBS_PACK(K_REGIME_PROP_SHIFT,   regime_prop);
}
```

## Step 4 — Replace switch-on-enum dispatch with branchless predicates (~80 LOC across ~5-10 sites)

Search for sites that switch on these K-state fields:
```bash
rg "switch\s*\(.*bandit_algorithm" Strategies/ ML_Headers/
rg "switch\s*\(.*risk_degradation_curve|risk_curve" Strategies/
rg "switch\s*\(.*barrier_blend_mode" ML_Headers/
rg "switch\s*\(.*regime.*current" Strategies/ ML_Headers/
```

For each switch:

**Case A: pure dispatch (no side-effects in cases)** — convert to dispatch table:
```cpp
// Before:
switch (cfg->risk_degradation_curve) {
    case RISK_OFF:     factor = 1.0; break;
    case RISK_LINEAR:  factor = 1.0 - decay; break;
    case RISK_EXP:     factor = exp(-decay); break;
    case RISK_STEP:    factor = (decay < 0.5) ? 1.0 : 0.5; break;
}

// After (dispatch table; branchless):
static const double risk_factor_table[4] = {
    1.0,                          // RISK_OFF
    1.0 - decay,                  // RISK_LINEAR (note: needs runtime computation; use function table if complex)
    exp(-decay),                  // RISK_EXP
    (decay < 0.5) ? 1.0 : 0.5,    // RISK_STEP
};
factor = risk_factor_table[MBS_GET(resolved->k_state_word, K_RISK_CURVE_MASK, K_RISK_CURVE_SHIFT)];
// Note: function-pointer dispatch may be better when cases need runtime computation
```

**Case B: set membership check** — use MBS_IN_SET:
```cpp
// Before:
if (regime == REGIME_RANGING || regime == REGIME_MILD_TREND) { /* ranging-like */ }

// After:
constexpr uint16_t SET_RANGING_LIKE = (1u << REGIME_RANGING) | (1u << REGIME_MILD_TREND);
if (MBS_IN_SET(resolved->k_state_word, K_REGIME_CURR_MASK, K_REGIME_CURR_SHIFT, SET_RANGING_LIKE)) {
    // branchless 1-cycle check (mask AND + cmp)
}
```

**Case C: equality dispatch** — use MBS_EQ:
```cpp
// Before:
if (cfg->bandit_algorithm == BANDIT_THOMPSON) { use_thompson(); }

// After:
if (MBS_EQ(resolved->k_state_word, K_BANDIT_ALGO_MASK, K_BANDIT_ALGO_SHIFT, BANDIT_THOMPSON)) {
    use_thompson();
}
```

**When NOT to convert:**
- Broad control-flow dispatch (early-return, kill-switch path): switch stays
- Boot-set predictable branches (predictor learns; mispredict <1%): switch stays
- Cases with expensive side-effects: function-pointer table or stay switch

Per CLAUDE.md item 28: branchless wins on data-dependent dispatch with mispredict >30%; switches stay on predictable boot-set patterns.

## Anti-patterns to avoid

- **Don't convert ALL switches to branchless.** Only data-dependent switches with mispredict >30% benefit. Boot-set predictable switches stay (per CLAUDE.md item 28).
- **Don't reuse k_state_word bits for unrelated state.** Reserved bits (11-15) are intentional headroom for future K-state fields; using them for unrelated flags muddies the cohort + breaks bit allocation discipline.
- **Don't pack K-state into a hot-path-mutable bitmap.** k_state_word is populated at slow-path resolution; HOT path reads from ExecutionCore::params (seqlock-cached). If hot path needs K-state, publish a SEPARATE copy via seqlock.
- **Don't change enum value assignments after locking masks.** RISK_OFF=0, RISK_LINEAR=1, etc. are now load-bearing for the mask layout. Renaming the enum is fine; changing values breaks the cohort.

## If something goes wrong

- **Backtest determinism breaks (cmp shows divergence):**
  1. Single switch may have semantic difference (e.g., default case behavior). Bisect by reverting one switch at a time.
  2. Verify enum value assignments match the bit layout assumptions.
  3. MBS_GET may return value outside expected range — add `assert(value < N_STATES)` at each MBS_GET site for debug build.
- **Compile error in MBS_* macros:**
  - Most common: `(field) & (mask)` returns wider type than expected. Cast to uint16_t explicitly.
  - Macro arity mismatch: each MBS_* macro takes specific arg count; pass exactly.
- **Performance regression (slow-path slows down):**
  - Unlikely (branchless is faster), but possible if branch predictor was learning the original switch well.
  - perf record + compare before/after to identify which converted site regressed; revert that one specific conversion.
- **k_state_word doesn't fit uint16_t (overflow):**
  - Static_assert in Step 1 catches this at compile time.
  - Either split into uint32_t (low cost, more headroom) or remove a low-value K-state field from the cohort.
- **Rollback:** `git reset --hard pre-v5.15.5.F.4f` (anchor at Step 0).
