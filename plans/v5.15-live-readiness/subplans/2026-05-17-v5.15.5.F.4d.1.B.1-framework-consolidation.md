## Why this ship exists

Path γ-class structural critique #2: original `.B` v1.2 proposed β4 `FOREACH_DRIFT_GATE` sparse sidecar (~80 LOC NEW + DriftGateKind enum + dispatch table + 5 cohort gate fns + sparse arrays). Pre-coding `/merge-scan` caught: this duplicates canonical `FOREACH_CFG_DERIVED_INFERENCE_CFG` at `MemHeaders/CfgDerivedInferenceCfgRegistry.hpp:101-123` (93% row overlap; the 5th BANDIT_THOMPSON field β4 missed is ALREADY in canonical at line 113). Same structural shape as Path γ at `.A` — propose parallel infrastructure when canonical sister exists.

Batch 2 `/anti-spaghetti` first run (1st canonical of the NEW skill) revealed 3-way triplet `FOREACH_CFG_DERIVED_INFERENCE_CFG × FOREACH_CFG_DRIFT_CHECK × FOREACH_STAMP_BOUND_CFG` (93% overlap CFG_DERIVED ∩ DRIFT_CHECK; 16-row lockstep drift surface). Wider-scope direction validated. Plus dust-audit confirms β4 BITMAP_IS_SET cohort-gate copy-paste pattern at 4 sites is the structural class to close (M4 finding).

Per `feedback_overengineering_boundary_when_future_easier` + readiness audit split recommendation, `.B` split into 3 sub-ships:
- **`.B.1`** (THIS SHIP): framework consolidation — build canonical infrastructure + migrate FOREACH_CFG_DERIVED_INFERENCE_CFG consumers
- **`.B.2`**: cohort migration — 24-row STAMP_BOUND_CFG_DERIVED bit-add + ML_CFG_FLAG sig + Winsor + gap_acceptable_threshold + retroactive `.A.7` cohort + 4 ModelInference walker migrations
- **`.B.3`**: legacy empty-out — DELETE legacy registries + 14 test fixture migrations + CI Checks 9-12

**Defensive ordering:** framework first → exercise via cohort migration → cleanup. Each sub-ship <8h focused. `.B.3` irreversible step (DELETE) preceded by 2 working ships.

This sub-ship builds framework infrastructure. **Legacy registries STAY at `.B.1`** (orphaned for FOREACH_CFG_DERIVED_INFERENCE_CFG after consumer migration; still consumed for FOREACH_STAMP_BOUND_CFG). Both deleted at `.B.3` after `.B.2` cohort migration verifies framework works non-empty.
