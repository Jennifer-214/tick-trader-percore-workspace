1. **Reciprocal LUT drift (v5.11.2.A):**

   - Downstream consumers (XGBoost float32 ~1e-7, cfg thresholds ~1e-4) see NO visible change.
   - **Determinism baseline regenerated** as documented in v5.11.2.A commit; replay-determinism test at line 10258 **PASSES** with rows_with_diff=0.

2. **O(1) running sums (v5.11.2.C):**
   - Running sums (price_sum_running, price_sum_y2_running, price_sum_xy_running, volume_sum_running, vol_sum_xy_running) maintain incremental slide-in/slide-out.
   - Formula derivation: sum_xy_new = sum_xy_old - sum_y_old + oldest + (W-1)*new (full window); warmup case: sum_xy_new = sum_xy_old + count_old*new.
   - Branchless via FPN_BlendOnMask on eviction term; count_old + evict_int * (W - 1 - count_old) trick for position.
   - **Tests added:** 3 brute-force equality checks (price_sum/sum_y2/sum_xy at every step) across warmup → full → eviction regimes.
   - Result: **bytewise identical** to prior loop accumulation (FPN add is associative; integer math has no drift).
   - Test run 1684 → 1698 (+14 tests covering monotonic deque invariants, FPN_BlendOnMask correctness, deque size bounds).

3. **Cache-line isolation (v5.11.2.B):**
   - Outputs (price_avg, price_slope, ..., vwap_deviation) moved to struct head, occupying cache lines 0-4 (312 bytes).
   - alignas(64) on `head` forces write-heavy internal state to cache line 5+.
   - Static_asserts (RollingStats.hpp:127-133) verify head offset ≥ 64*5 (guards false sharing).
   - GUI thread reads outputs; engine writes head/count every Push → no longer share L1d line.
   - Layout W-independent (tested for W=128/256/512/1024).

4. **Feature registry unchanged:**

   - Feature_PackAll call site: unmodified (still calls RollingStats_Push).

   - No new hidden feature compute branches introduced.

### A. FPN_BlendOnMask Semantic Identity (User Question 5)

**Claim:** When vol_sum=0, the new code's `FPN_BlendOnMask(new_vwap, rs->vwap, vol_nz_mask)` evaluates to rs->vwap (the old value), matching old behavior.

**Verification:** ✓ VERIFIED

Implementation (RollingStats.hpp:250-257):
```cpp
uint64_t vol_nz_mask = -(uint64_t)(!FPN_IsZero(rs->vol_sum));  // 0 when vol_sum==0
FPN<F> safe_vol = FPN_BlendOnMask(rs->vol_sum, FPN_FromDouble<F>(1.0), vol_nz_mask);
FPN<F> new_vwap = FPN_DivNoAssert(rs->pv_sum, safe_vol);  // divide by 1.0 when vol_sum==0
rs->vwap = FPN_BlendOnMask(new_vwap, rs->vwap, vol_nz_mask);
```

When vol_nz_mask=0 (vol_sum==0):
- `FPN_BlendOnMask(new_vwap, rs->vwap, 0)` returns rs->vwap (second arg when mask=0) ✓
- Same as old `if (!FPN_IsZero(rs->vol_sum)) { rs->vwap = ... }` (keeps prior when false) ✓

Same pattern for vwap_deviation (line 257) and volume_delta (line 356).

Tests added (tests/controller_test.cpp:13681+): 4 FPN_BlendOnMask tests covering all-1s, 0, sign preservation.

**Verdict:** PASS (semantic identity confirmed).
