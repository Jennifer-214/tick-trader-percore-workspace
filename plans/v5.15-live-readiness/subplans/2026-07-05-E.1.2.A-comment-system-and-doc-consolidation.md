- **FULL focused conversion (tool-assisted) — NOT as-we-go** *(corrected 2026-07-05, operator)*. For load-bearing, tool-consumed tags, PARTIAL is unreliable (a half-tagged code-map/DAG/tag-query can't be trusted) and "as we go" never completes = itself a rot vector. **Completeness is a correctness property here.** So convert EVERY file in a focused sprint. The human pass = **rot-check** (migrated comment still matches code?) + gap-fill, NOT hand-typing blocks. The **`[SCHEMA]` migrator** applies a future new-tag/section across every relevant unit (scripted transform) → schema evolution stays painless *because* the baseline is complete.
- **Division of labor:** operator builds the plugin adapter (their session); orchestrator builds the CI validator + drives the mechanical audit bulk (dated-doc find · consolidation candidates · rot-flag · per-file scaffolding) → operator reviews + writes judgment-prose at boundaries (offloads the focus-scarce part).
