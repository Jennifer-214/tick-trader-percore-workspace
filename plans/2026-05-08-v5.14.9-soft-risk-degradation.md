## Implementation plan

### Step 1 — Confidence_DegradationScale fn

File: `ML_Headers/ConfidenceScore.hpp` (extend; same file as composite
confidence from v5.14.1)

```cpp
// Soft risk degradation: composite confidence → sizing multiplier.
// LINEAR curve (default; cfg.risk_degradation_curve=0):
//   conf >= full_size_threshold → return 1.0 (full size)
//   conf <= min_size_threshold  → return 0.0 (block; kill-switch
//                                  path takes over via existing infra)
//   else → linear interp between (min_size_threshold, min_size_pct)
//          and (full_size_threshold, 1.0)
//
// EXPONENTIAL curve (cfg=1): same endpoints but quadratic falloff
//   → preserves more size in the middle, sharper drop near min.
//
// STEPWISE curve (cfg=2): full_size or min_size_pct binary; no
//   intermediate scaling (paper-test debugging shape).
//
// Branchless: linear curve uses fmin/fmax + single fma; no branches.
// Exponential uses one square; still branchless. Stepwise uses one
// fmin/fmax + cmov; branchless.
//
// All paths: return value clamped to [0, 1] regardless of cfg
// pathology (defensive against operator typos in cfg).
template <unsigned F>
inline double Confidence_DegradationScale(
    double composite,
    int    curve_type,
    double full_size_thr,
    double min_size_thr,
    double min_size_pct);
```

### Step 2 — Wiring into v5.12.1.D sizing-multiplier path

File: `Strategies/StrategyParameters.hpp` (sizing site)

Replace existing `cfg.risk_scale_by_confidence ? scale : 1.0` with:

```cpp
double sizing_mult = 1.0;
if (config->risk_scale_by_confidence &&
    config->confidence_composite_enabled) {
    double composite = ConfidenceScorer_ComputeComposite(&ctx.confidence);
    sizing_mult = Confidence_DegradationScale(
        composite,
        config->confidence_degradation_curve,
        FPN_ToDouble(config->confidence_full_size_threshold),
        FPN_ToDouble(config->confidence_min_size_threshold),
        FPN_ToDouble(config->confidence_min_size_pct));
}
trade_size = FPN_Mul(trade_size, FPN_FromDouble<F>(sizing_mult));
```

If `composite < min_size_thr` → returns 0 → trade_size = 0 → entry
blocks (BG_Evaluate's existing zero-qty check kicks in). No new
gate machinery; reuses existing zero-trade-size = no-entry contract.

### Step 4 — Tests

- Linear curve at full_size_threshold → returns 1.0
- Linear curve at min_size_threshold → returns min_size_pct (NOT 0)
- Linear curve below min_size_threshold → returns 0.0
- Linear curve above full_size_threshold → returns 1.0 (clamped)
- Exponential curve preserves more size in middle than linear
- Stepwise curve: binary 1.0 or min_size_pct
- Default cfg (risk_scale_by_confidence=0) → sizing_mult always 1.0
  (preserves pre-v5.14 behavior bytewise)
- Composite confidence = 0 → sizing_mult = 0 → trade_size = 0 →
  entry blocks (existing infra)
