## The 7 readout axes — what a complete info-readout for a unit covers

1. **WHAT** — `[FILE]` / `[STRUCT]` / `[FUNCTION]` / `[REGISTRY]` (+ variants `[STRATEGY]` / `[ENUM]` / `[TYPE]` / `[MACRO]` / `[TEST]`)
2. **CLASSIFY** — `[TAG]` (surface/concern values, below) · `[SCOPE]` (scale-level) · structural (`[BIT_PACKED]`/`[SYNC]`/`[WIRE_FORMAT]`)
3. **LAYOUT** — `[DIAGRAM]` byte-map / bit-map · `[ALIGN]` · `[CACHE_LINES]` · `[STRADDLE]`
4. **COMPUTE** — `[BUILD]` (flags pin) · `[SIZE]_[instr]` · `[SIMD]` · `[FLOAT]` · `[BRANCHES]`  (instr count, NOT ns — must be reproducible)
5. **GRAPH** — `[UPSTREAM]` · `[CONSUMERS]` · `[ROW_COUNT]` · `[ENROLLED]` · `[TESTED_BY]` · blast-radius
6. **GOVERN** — `[REFERENCE]_[INVARIANT|DESIGN_SPEC|DECISION|TECH_DEBT|CLASS|PLAN|AUDIT]` · `[FUTURE_WORK]`
7. **HISTORY** — `[COMMENT]` dated partitions · `[EDIT]`/`[VERSION]` · `[ITERATIONS]` (git churn)

(Runtime/live telemetry = the DATA + MONITORING planes, NOT this dev-plane readout — separate `.E` decoupling ship.)

## CLASSIFY vocabulary — `[TAG]` values (orthogonal groups; each answers a DIFFERENT question)

- **Surface** (when/where it runs): `[HOT_PATH]` `[SLOW_PATH]` `[DRAINER]` `[BOOT_TIME]` `[PRODUCER]` `[LIVE_TRADING]` `[BACKTEST]`
- **Capital sensitivity** (is correctness = money?): `[CAPITAL_BEARING]` / `[NON_CAPITAL]`
- **Numeric repr** (H4): `[DECIMAL]` (Money) · `[BINARY_FP]` (FPN feature) · `[INT]` · `[FLOAT_DISPLAY_ONLY]`
- **Determinism / byte-identity**: `[DETERMINISTIC]` · `[WIRE_FORMAT]` · `[PERSISTED]` · `[FROZEN]`/`[GOLDEN]` (relies on staying byte-identical between changes — golden-master fixture / determinism baseline / wire-frozen body; **regen the golden deliberately, never casually edit**) + a `[REFERENCE]_[GOLDEN]_[<fixture>]` link to the protecting golden
- **Criticality / role**: `[CRITICAL]` / `[SUPPORTIVE]` · `[HELPER]` / `[ENTRY_POINT]`
- **Component / plane**: `[ENGINE]` `[GUI]` `[DATA_PLANE]` `[MONITORING_PLANE]` `[DEV_PLANE]` `[ML]`
- **DOD concern**: `[DATA_ORIENTED_DESIGN]` `[CONCURRENCY]` `[BIT_PACKED]` `[FRAMEWORK_DISCIPLINE]`

## Structural / concurrency annotations (curated; applied as-encountered)

`[BIT_PACKED]` (H14 `MASK_`/`SHIFT_`/`BITMAP_`/`MBS_`) + bit-map `[DIAGRAM]` · `[PADDING]` (H12) · `[SYNC]_[SEQ_LOCK|SPSC|ATOMIC|LOCK_FREE]` · `[THREAD]_[HOT_WRITER|SLOW_READER]` (curated) · `[WIRE_FORMAT]` (H9) · `[PERSISTED]`

## Rules that bound the readout

- **fork-b**: DERIVED = tool-written + CI-checked; must be **REPRODUCIBLE** (deterministic per binary — instr count / offsets / SIMD / branch class, pinned by `[BUILD]` flags). Machine-variable metrics (ns) are NEVER in-comment.
- **preserve-voice**: relocate existing prose VERBATIM.
- **hybrid layout**: compact orient ABOVE → `[CODE]`-framed body → bulky detail BELOW → `[END_*]`.
- **anti-sprawl**: vocabulary is 1-line extensible; add VALUES at real use-sites, don't pre-enumerate. Grammar (categories) locked; vocab (values) grows.

### Grammar-level gaps (DECIDE adopt / fold-vs-new BEFORE conversion)
1. **`[REGION]` sub-unit binding** (THE gap) — no structured level between block + inline-field-tag; a struct's per-region (byte-range) / per-bit-slot facts (thread/sync/residency/occupancy) collapse to lossy scalars or un-greppable `[DIAGRAM]` prose = comment-sprawl at region granularity. → `[REGION]_[name]_[byte-range]` + per-bit-slot form. (ExecutionCore 10 regions over 0..68352; Order packed bit-slots)
2. **`[INSTANTIATION]`** (systemic) — `template<unsigned F>` units have no single instr-count (RollingStats co-lives W=128/256/512/1024); `[BUILD]` pins flags not template-args → DERIVED reproducibility UNDEFINED on a bare template (even the spec's own Regime_Classify example). → `[INSTANTIATION]_[F=..,W=..]` (may be a SET) OR fold into `[BUILD]`.
3. **Registry→registry topology** — H16/H18/H19 (metadata-bit→cohort / sidecar-override / parent-level) have NO home; only H15 (`[ENROLLED]`) expressible. → `[PARENT]`/`[CHILDREN]`/`[SIDECARS]`/`[OVERRIDES]` (from MetaRegistry LEVEL/PARENT + FIELD_IDX + if-constexpr).
4. **`[COMPLEXITY]`** (curated) — amortized/worst-case trip-count; the p99 fact `[SIZE]_[instr]` misses on H8 slow kernels. (RollingStats O(1) amortized / O(W) worst)
5. **`[APPLY_AFTER]`** (curated) — walker last-wins expansion ORDER = capital-bearing (early apply "re-arms the founding bug"); lives only in `[WHY]` prose today. (FOREACH_PER_NODE_ARRAY_OVERRIDE)
6. **`[MUTATES]`/`[WRITE_SET]`** (DERIVED, clangd) — the write half; a void fn mutating ~25 fields has no write-set slot.
7. **`[WIRE_VERSION]` + `[PAIRED_BUMP]`** (borderline) — "what do I bump if I touch it": Position jointly gated by SHARDED=10 AND CONTROLLER=14 (paired, D-302); already drifted live (comment PORTFOLIO=6, ledger=7). → set-of-gating-versions, CI vs ledger.
8. **Clarifications** (bless, no new category): multiple `[DIAGRAM]_[kind]` per block; `[DIRECTIVE]` on an X()-row inside `[CODE]`; `[CODE]`/`[END_CODE]` for non-contiguous units.

### Two meta-findings (real premise-gaps)
1. **Prose can LIE about codegen, uncaught** — a `[WHY]` "CMOV/branchless" claim where DERIVED `[BRANCHES]` shows a real `je`; CI checks only the DERIVED tier, never the prose → preserve-voice relocation propagates the false claim. → need a **prose-vs-DERIVED codegen-keyword LINT** (or accept-risk documented).
2. **`[BUILD]` can't honestly hold `-march=native`** (host-resolved ISA) → asm-DERIVED golden false-REDs across build-hosts → `[BUILD]` must pin a **concrete microarch (x86-64-v3)**.
