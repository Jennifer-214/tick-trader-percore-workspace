### Step 2 — Compute fn implementations

File: `Backtest/LabelFunctions.hpp` (after existing Label_* fns)

```cpp
// CS Percentile Rank: per-timestamp rank / (N+1).
// Single-symbol degenerate case: N=1 → returns 0.5 always.
// Multi-symbol: scipy.rankdata-equivalent; 1-indexed ranks.
static inline float Label_CSPercentileRank(
    const HistoricalTick *ticks, int tick_idx, int total_ticks,
    const BacktestRunConfig *cfg) {
    int horizon = cfg->label_forward_ticks;
    if (tick_idx + horizon >= total_ticks) return NAN;  // skip last horizon ticks
    double future_return = (ticks[tick_idx + horizon].price -
                             ticks[tick_idx].price) / ticks[tick_idx].price;
    // For single-symbol case: N=1; rank=1; pct = 1/2 = 0.5
    // For multi-symbol: caller's CS bucket logic computes rank
    // (this Compute fn returns the raw return; CS bucketing happens
    //  in Backtest_ComputeLabelsFromSamples via per-timestamp groupby)
    // For v5.14.5 single-symbol case: identity (returns the future return;
    // CS rank applied later when multi-symbol architecture lands in v5.16+).
    return (float)future_return;
}

// CS Robust Z-Score: (r - median) / (1.4826 × MAD).
static inline float Label_CSZScoreRobust(
    const HistoricalTick *ticks, int tick_idx, int total_ticks,
    const BacktestRunConfig *cfg) {
    // Same shape; CS-bucketed normalization happens at the
    // BacktestResults level (cross-sectional aggregation post-Compute).
    // For single-symbol: returns the raw return.
    int horizon = cfg->label_forward_ticks;
    if (tick_idx + horizon >= total_ticks) return NAN;
    double future_return = (ticks[tick_idx + horizon].price -
                             ticks[tick_idx].price) / ticks[tick_idx].price;
    return (float)future_return;
}

// CS Vol-Scaled Demeaned: (r/vol) - mean_cs(r/vol).
static inline float Label_CSVolScaledDemeaned(
    const HistoricalTick *ticks, int tick_idx, int total_ticks,
    const BacktestRunConfig *cfg) {
    int horizon = cfg->label_forward_ticks;
    if (tick_idx + horizon >= total_ticks) return NAN;
    double future_return = (ticks[tick_idx + horizon].price -
                             ticks[tick_idx].price) / ticks[tick_idx].price;
    double vol = cfg->label_vol_estimate;  // per-tick vol estimate; cfg or rolling
    if (vol < 1e-9) return NAN;
    return (float)(future_return / vol);  // CS demeaning happens at aggregation
}
```

**Single-symbol degenerate path note:** For v5.14.5, all 3 Compute
fns return raw per-tick metric. The CS "per-timestamp" aggregation
(rank, median, mean) is a SEPARATE step that operates on the
returned vector across symbols. For single-symbol case (current
engine), each metric degenerates to identity — but the plumbing
is in place for the future multi-symbol port (v5.16+).
