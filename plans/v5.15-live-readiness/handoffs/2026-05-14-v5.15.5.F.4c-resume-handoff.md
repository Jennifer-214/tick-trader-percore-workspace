### Item 3 walker shape (skeleton; refine on integration)

```cpp
// AFTER the existing field_defs[] loop in Settings_RenderGlobalTab:

// v5.15.5.F.4c — bitmap-dispatch walker for FOREACH_CFG_FIELD rows
// (replaces EMIT_CFG_FIELD_DEF_FROM_REGISTRY; field_defs[] auto-extension
// of FOREACH_CFG_FIELD rows is removed in item 8 delete-old-paths).
{
    const char *current_cfg_section = NULL;
    bool cfg_section_collapsed = false;
    bool cfg_section_strat_hidden = false;

    CFG_FIELD_FOR_EACH_SET_BIT(g_cfg_render_mask, idx, {
        const CfgFieldDescriptor& desc = g_cfg_field_descriptors[idx];

        // Section header transition logic (mirrors lines 964-987 of existing loop)
        if (!current_cfg_section || strcmp(current_cfg_section, desc.section) != 0) {
            current_cfg_section = desc.section;
            int sec_strat = global_section_strategy(current_cfg_section);
            cfg_section_strat_hidden = (sec_strat >= 0 && !any_core_uses_strategy(s, sec_strat));
            if (cfg_section_strat_hidden) {
                continue;  // skip this row (and bitmap iteration will continue to next)
            }
            bool default_open = (strcmp(desc.section, "Trading") == 0 ||
                                  strcmp(desc.section, "Entry Filters") == 0 ||
                                  strcmp(desc.section, "EMA Gate") == 0);
            cfg_section_collapsed = !ImGui::CollapsingHeader(desc.section,
                default_open ? ImGuiTreeNodeFlags_DefaultOpen : 0);
            if (cfg_section_collapsed) continue;
        }
        if (cfg_section_strat_hidden || cfg_section_collapsed) continue;

        // Per-row render + per-edit persist via the helper
        ImGui::SetNextItemWidth(80);
        if (CfgRenderTable<64>::fns[idx](s->gui_engine_cfg, desc)) {
            // render returned changed → format + persist
            char buf[512];
            // Need template dispatch on T; use generic save fn here OR have
            // CfgRenderTable also expose a "save_and_persist" wrapper per field.
            // Simpler: just call cfg_render_and_persist directly via a per-field
            // dispatch table (similar to render table).
            // ALTERNATIVELY: render fn could itself do the persist (cfg_render_and_persist
            // is templated; CfgRenderTable could wrap it).
            // RESOLVE THIS DESIGN QUESTION AT INTEGRATION TIME.
        }
    });
}
```

**Design question for integration:** the render fn table currently calls
`tt::cfg_render_field<T>` only. For per-edit persistence, it needs to ALSO
call `tt::cfg_save_field<T>` + `cfg_write_field`. Two options:

**Approach 1 — Render-and-persist fn table:** make `CfgRenderTable<F>::fns[]`
call `cfg_render_and_persist<T>` instead of just `cfg_render_field<T>`. Each
per-field static fn becomes `bool render_<name>(cfg, desc, cfg_path)` and
internally calls the wrapper. Cleaner: walker is one line.

**Approach 2 — Two separate dispatch operations:** keep render table as-is;
walker calls `fns[idx](cfg, desc)` for render; on returned-true, walker must
ALSO call a save fn. Awkward: needs a parallel save fn table OR a unified
typed dispatch from idx.

**Recommendation: Approach 1.** Modify `CfgRenderTable<F>::render_<name>` to
take `(cfg, desc, cfg_path)` + call `cfg_render_and_persist`. Render table
becomes "render + persist on change" per row. Walker is trivial. 1 hour of
careful editing.
