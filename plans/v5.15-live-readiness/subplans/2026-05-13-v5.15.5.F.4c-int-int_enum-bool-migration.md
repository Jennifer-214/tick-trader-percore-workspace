## Key changes

1. **Add 3 tt:: specializations** in `CoreFrameworks/CfgFieldDispatch.hpp`:
   - `tt::cfg_parse_field<KIND_INT>` — strtol + clamp_min/clamp_max
   - `tt::cfg_parse_field<KIND_INT_ENUM>` — atoi + validate ∈ [0, count)
   - `tt::cfg_parse_field<KIND_BOOL>` — atoi → 0/1
   - Mirror specializations for cfg_save_field + cfg_render_field
2. **Extend `FOREACH_CFG_FIELD`** with the ~80 INT/INT_ENUM/BOOL rows. Examples:
   - INT: `lazy_rebuild_force_period_us`, `param_max_age_ticks`, `recovery_delay_secs`, `model_max_age_hours`, `thompson_rng_seed`, etc.
   - INT_ENUM: `bandit_algorithm`, `risk_degradation_curve`, `barrier_blend_mode`, `engine_arch`, `ensemble_blend_mode`, `csv_sort_check_mode`, etc.
   - BOOL: `momentum_require_last_win`, `require_mlockall`, `acknowledge_*` family (4 fields), `model_verify_strict`, etc.
3. **Migrate parser + panel + save** for these rows (delete manual sites; verify auto-flow).
4. **GUI for INT_ENUM**: use `ImGui::Combo` with the descriptor's `as_int_enum.labels[]` array.

## Key concerns / pitfalls

- **BOOL fields that already live in `*_cfg_flags` bitmap REGISTRIES are NOT migrated here.** The 5 bitmap domains (LIFECYCLE/GATE/ML/RISK/OPS) already auto-extend per `FOREACH_<DOMAIN>_CFG_FLAG` (v5.14.9.F.5). Only SCALAR uint8_t / int bool fields enter the new registry. Grep `rg "FOREACH_.*_CFG_FLAG" ML_Headers/ CoreFrameworks/` to enumerate the bitmap-resident bools to EXCLUDE.
- **INT_ENUM label storage:** `as_int_enum.labels` is `const char* const*` (pointer to static label array). Declare label arrays at namespace scope: `static const char* const BANDIT_ALGO_LABELS[] = {"Exp3-IX", "Thompson"};`. The X-macro emits the array name into the descriptor.
- **Macro arity:** registry X-macro arity is still 7 (kind_token, name, label, section, meta, payload, tooltip). KIND_INT_ENUM uses `ENUM2(...)` / `ENUM3(...)` / `ENUM4(...)` helper macros that expand into the payload union initializer with the label array reference.
- **Clamp validation:** INT fields with clamp_min == clamp_max == 0 mean "no clamp" — defensively check this at parse time.
