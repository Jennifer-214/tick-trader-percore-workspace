## Why this ship exists (charter)

**Primary charter:** activate the v5.12.1.D-era confidence-conditional sizing path which is currently silently broken when composite confidence is enabled.

**Verified-broken behavior (StrategyParameters.hpp:1291-1322 as of v5.14.8 close):**
- When `cfg.risk_scale_by_confidence != 0` AND `cfg.confidence_composite_enabled = 1`:
  - `conf_now` = composite output ∈ practical [0.001, 0.3]
  - `threshold` = `effective ml_buy_threshold` ∈ practical [0.5, 0.7]
  - Inner check: `if (denom > 1e-9 && conf_now >= threshold)` is essentially always FALSE
  - Falls to `else: factor = 0.0` → `trade_size *= 0` → block-everything
- Operator's intent ("scale by confidence") is silently violated

**Solution shape (this ship):**
1. Replace broken math with a `FOREACH_DEGRADATION_CURVE(X)` registry
2. Branchless curve compute fns (OFF / LINEAR / EXP / STEP)
3. X-macro-generated function-pointer dispatch table
4. Per-core override (`core_N_*` 4 cfg fields)
5. Composite-required-for-ladder boot REFUSE (engine-wide validation)
6. PerCoreSnap.ml_confidence_factor field for observability
7. SHALT_LOW_CONFIDENCE emission at ladder-bottom (factor=0)

**Adjacent debt absorbed (per "defer is last-ditch never effort-avoidance"):**
- TECH_DEBT-004 hard close: delete legacy `confidence_freshness_tau` cfg field (mathematically inert; `data_age=0` always in production; half-dead via stamp-bound drift check on a value that doesn't affect inference)
- TECH_DEBT-013 universalization sweep: all 5 remaining BIT_FLAG candidates close in this ship
- TECH_DEBT-015 close: bundled with TECH_DEBT-013 candidate (4) FOREACH_FEATURE 7-col extension
- TECH_DEBT-009 boolean subset close (v5.14.9.F-.F.6 expansion 2026-05-10): domain-grouped FOREACH_<DOMAIN>_CFG_FLAG registries (OMS / GATE / RISK / ML / OPS) replace 18+ scattered cfg booleans via 5 bitmap fields; parser auto-flow + GUI auto-layout + per-core override auto-flow close out the boolean N-site class. Non-boolean cfg fields (FPN<F> thresholds, ints, strings) stay OPEN under TECH_DEBT-009 broader scope as future FOREACH_CFG_FIELD ship

```cpp
// In ML_Headers/ConfidenceScore.hpp after line 480:

// Tuple: X(name, enum_value, compute_fn, doc_string)
#define FOREACH_DEGRADATION_CURVE(X)                                                           \
    X(OFF,    0, Confidence_DegradationScale_Off,    "disabled — factor=1.0; preserves pre-v5.14.9 behavior") \
    X(LINEAR, 1, Confidence_DegradationScale_Linear, "linear interp between (min, min_pct) and (full, 1.0)") \
    X(EXP,    2, Confidence_DegradationScale_Exp,    "quadratic falloff; preserves more size in middle")    \
    X(STEP,   3, Confidence_DegradationScale_Step,   "binary 1.0 above midpoint else min_pct (debug shape)")

// Auto-generated enum
enum DegradationCurve {
    #define X_GEN_ENUM(name, val, fn, doc) CURVE_##name = val,
    FOREACH_DEGRADATION_CURVE(X_GEN_ENUM)
    #undef X_GEN_ENUM
};

// Compute fns (BRANCHLESS — see DESIGN_SPECS/curve-registry-pattern.md)
inline double Confidence_DegradationScale_Off(double, double, double, double) {
    return 1.0;
}

inline double Confidence_DegradationScale_Linear(double conf, double full, double min, double min_pct) {
    double clamped = fmin(fmax(conf, min), full);
    double t = (clamped - min) / (full - min);
    return fma(t, 1.0 - min_pct, min_pct);
}

inline double Confidence_DegradationScale_Exp(double conf, double full, double min, double min_pct) {
    double clamped = fmin(fmax(conf, min), full);
    double t = (clamped - min) / (full - min);
    double t_sq = t * t;  // quadratic falloff
    return fma(t_sq, 1.0 - min_pct, min_pct);
}

inline double Confidence_DegradationScale_Step(double conf, double full, double min, double min_pct) {
    double mid = (full + min) * 0.5;
    double mask = (conf >= mid) ? 1.0 : 0.0;
    return fma(mask, 1.0 - min_pct, min_pct);
}

// X-macro-generated function-pointer dispatch table
typedef double (*CurveFn)(double, double, double, double);
#define X_GEN_FN_PTR(name, val, fn, doc) fn,
static const CurveFn curve_fns[] = { FOREACH_DEGRADATION_CURVE(X_GEN_FN_PTR) };
#undef X_GEN_FN_PTR

#define X_GEN_COUNT(name, val, fn, doc) +1
#define FOREACH_DEGRADATION_CURVE_COUNT (0 FOREACH_DEGRADATION_CURVE(X_GEN_COUNT))
#undef X_GEN_COUNT

// ToString / FromString for cfg parser + GUI
inline const char* DegradationCurve_ToString(int curve) {
    switch (curve) {
        #define X_GEN_TO_STRING(name, val, fn, doc) case val: return #name;
        FOREACH_DEGRADATION_CURVE(X_GEN_TO_STRING)
        #undef X_GEN_TO_STRING
        default: return "INVALID";
    }
}
```

```cpp
// slow-path entry by EventLoop_RebuildOneCore (item 18(c)). Default-off

        conf_now,
        FPN_ToDouble(config->risk_full_size_threshold),
        FPN_ToDouble(config->risk_min_size_threshold),
        FPN_ToDouble(config->risk_min_size_pct));

// early-return (preserves entry-log/ML-Status-panel attribution).

    out->tp_pct               = FPN_Zero<F>();
    out->sl_pct               = FPN_Zero<F>();

    out->strategy_id          = STRATEGY_ML;
    out->flags                = GATE_FLAG_BUY_BLOCKED;

    if (out_confidence)  *out_confidence  = conf_now;
```
