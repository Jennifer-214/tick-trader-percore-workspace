## Critical blockers

### Blocker #1 (YELLOW; per Check 25): TECH_DEBT-002 alignment

**Issue:** v5.14.4 Step 5 dispatch lands in `EngineSharded.hpp` boot (sharded engine path). TECH_DEBT-002 tracks centralized engine `ControllerEventLoop` removal — but until removal happens, centralized path may also have reconcile wiring.

**Possible scenarios:**
- (A) Centralized engine has its own reconcile call site → must apply same 3-mode dispatch OR explicitly skip
- (B) Centralized engine has no reconcile call site → no action; v5.14.4 sharded-only by construction

**Resolution:** Plan must confirm scenario (B). Add explicit guard / comment in Step 5 dispatch code:
```cpp
// v5.14.4 — sharded-only; centralized engine path is deprecated
// (TECH_DEBT-002). Reconcile dispatch lives in EngineSharded boot only.
```

If scenario (A): apply same 3-mode dispatch in centralized path OR document it skips reconcile entirely (preserve existing behavior of binary `reconcile_dry_run`).
