## Key changes

1. **tt:: specializations** for KIND_STRING + KIND_FILE_PATH:
   - Parse: strncpy with size check; STRING uses fixed-size buffer (e.g., `char[256]`); FILE_PATH validates non-empty path
   - Save: fprintf with quoting if value contains whitespace
   - Render: `ImGui::InputText` for STRING; `ImGui::InputText + ImGui::Button("Browse...")` for FILE_PATH (or just InputText with hint)
2. **Registry rows** (~30):
   - File paths: `core_N_model_path`, `core_N_model_dir`, `held_out_stamp_secret`, `auto_stamp_secret`, `source_cfg_path`, `health_log_path`, `exit_signal_model_dir`, `ensemble_blend_mode` (string variant), etc.
   - Strings: `core_N_ensemble_blend_mode`, `core_N_horizon_list`, `horizon_list`, etc.
3. **Metadata-driven GUI features:**
   - **HIDDEN_BY_DEFAULT:** wrap field render in `if (ImGui::CollapsingHeader("Advanced — Engine Diagnostics", ImGuiTreeNodeFlags_DefaultClosed))` block per section. Auto-collapse fields with this flag.
   - **RESTART_REQUIRED:** after the field widget, render `ImGui::SameLine(); ImGui::TextColored(YELLOW, "(restart needed)");`.
   - **SAFETY_CRITICAL:** wrap the field interaction in a confirmation prompt: changing the field opens a modal asking operator to confirm. Track which fields are pending-confirmed.
   - **DEPRECATED:** render with `ImGui::TextDisabled` + strikethrough font (or just gray + tooltip "(deprecated)").
4. **Delete manual remainder** in parser/panel/save (STRING fields).

## Key concerns / pitfalls

- **Fixed-size buffer vs heap-allocated string.** Cfg struct currently uses fixed-size `char[N]` arrays for paths to avoid malloc on hot paths. STAY WITH FIXED BUFFERS — don't introduce std::string in cfg struct (per coding rules — no malloc on data plane).
- **`core_N_X` parsing.** Per-core string overrides parse as `core_0_model_path=foo` — this is per-core override matching, not direct registry dispatch. Per-core override dispatch happens AFTER the registry pass via existing per-core matching logic. Verify per-core string fields STILL parse correctly — they're not in the registry directly; only their GLOBAL form is.
- **Browse button file dialogs.** ImGui doesn't ship a native file picker; either embed `ImGuiFileDialog` (external dep) or stick with plain `InputText` and document the path manually. **Recommendation:** plain InputText for now; defer file dialog to a future polish ship.
- **CI script:** at end of `.F.4d`, the manual parser is empty for scalar fields. NOW is the right time to add the CI script that diffs cfg struct fields vs registry. Catches future drift.
- **Stamp secret handling:** `held_out_stamp_secret` is SAFETY_CRITICAL and SHOULD NOT be displayed in clear text. Render with `ImGui::InputText(..., ImGuiInputTextFlags_Password)` to mask. Save to disk normally (cfg.cfg is operator-controlled).
