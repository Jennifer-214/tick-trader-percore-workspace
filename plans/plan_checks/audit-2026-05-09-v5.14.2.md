### ❌ Check 2: EnsembleModelZoo_LoadFromCfg signature [CRITICAL]

**Plan's call (line 93-95):**
```cpp
int total = EnsembleModelZoo_LoadFromCfg(swap_ezoo, new_base_dir,
    cfg.held_out_gate_strict,
    cfg.acknowledge_cross_binary_version_drift);
```

**Actual signature** (`CoreModelZoo.hpp:1351-1359`):
```cpp
inline int EnsembleModelZoo_LoadFromCfg(
    EnsembleModelZoo<F>* ezoo,
    const char* base_run_path,
    const int* horizon_list,           // MISSING in plan
    int horizon_count,                  // MISSING in plan
    int backend,                        // MISSING in plan
    const char* held_out_stamp_secret = nullptr,
    double gap_threshold = 0.05,
    int held_out_gate_strict = 0,
    int acknowledge_cross_binary_drift = 0)
```

Plan passes 4 args; function requires 5 mandatory + 4 optional.

**Root cause:** plan author confused this with `CoreModelZoo_LoadFromDir` (which uses cfg pointer instead of horizon list).

**Fix required:**
```cpp
// Reconstruct horizon_list from ezoo's cached state
int horizons[ENSEMBLE_HORIZON_MAX];
int h_count = 0;
for (int i = 0; i < ENSEMBLE_HORIZON_MAX; ++i) {
    if (swap_ezoo->horizon_ticks_at_idx[i] > 0) {
        horizons[h_count++] = swap_ezoo->horizon_ticks_at_idx[i];
    }
}
if (h_count == 0) {
    fprintf(stderr, "[hot_swap] ensemble core %d FAILED: no horizons cached\n", core_id);
    return 0;
}

int total = EnsembleModelZoo_LoadFromCfg(
    swap_ezoo,
    new_base_dir,
    horizons,                                             // reconstructed
    h_count,                                              // count
    swap_backend,                                         // ml_backend
    nullptr,                                              // held_out_stamp_secret
    0.05,                                                 // gap_threshold
    cfg.held_out_gate_strict,
    cfg.acknowledge_cross_binary_version_drift);
```
