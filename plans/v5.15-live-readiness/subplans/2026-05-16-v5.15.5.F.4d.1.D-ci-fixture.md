## `.F.4e` upgrade plan — uint16_t → uint32_t MetadataFlag (forward-reference; NOT executed at `.D`)

Per cache alignment investigation at `.F.4d.1` planning 2026-05-16:

### Current state (at HEAD `545b087`)

`CfgFieldDescriptor` header layout (`CfgFieldRegistry.hpp:170-174`):
```cpp
//---- Header (8 bytes) ----
Kind          kind;             // 1 byte (offset 0)
uint8_t       lives_in_struct;  // 1 byte (offset 1)
uint16_t      metadata_flags;   // 2 bytes (offset 2) — 13 bits used + 3 headroom
uint16_t      _reserved = 0;    // 2 bytes (offset 4) — explicit "future use" per CLAUDE.md item 27
uint16_t      field_idx;        // 2 bytes (offset 6)
```

The `_reserved` field at offset 4 is **explicitly intended for future expansion** (comment: "future use; default-init 0 per CLAUDE.md item 27").

### Upgrade design (Option Z2)

At `.F.4e` when adding HIDDEN_BY_DEFAULT/RESTART_REQUIRED/SAFETY_CRITICAL/IS_SECRET/DEPRECATED consumers (which exceed 13 + 2 + 5 = 20 bits required vs 16 bits in uint16_t):

```cpp
//---- Header (8 bytes; byte-equivalent total; Z2 reorder + promote) ----
Kind          kind;             // 1 byte (offset 0)
uint8_t       lives_in_struct;  // 1 byte (offset 1)
uint16_t      field_idx;        // 2 bytes (offset 2; moved up from offset 6)
uint32_t      metadata_flags;   // 4 bytes (offset 4; promoted from uint16_t + _reserved)
                                // — 13 bits used at `.D`; up to 32 bits at `.F.4e+`
```

**Properties:**
- Byte-equivalent struct size (1+1+2+4 = 8; same as before 1+1+2+2+2 = 8)
- ZERO Layer 4 fixture round-trip risk (CfgFieldDescriptor is runtime metadata, NOT wire-format)
- Consumer code `(d.metadata_flags & BIT) != 0` works for any bit 0-31 (no accessor needed)
- The H16 static_assert at `.A` updates: `EXEMPT_FROM_DERIVED_FILTER` constant moves 5 bits to `COVERED_DERIVED_FILTER_BITS` as `FOREACH_DERIVED_FILTER` gains rows for the 5 GUI metadata consumers
- Existing `static_assert(WARN_ON_CLAMP < (1u << 16))` (line 212) UPDATES to `static_assert(<HIGHEST_BIT_IN_USE> < (1u << 32))`

### Why NOT execute at `.D`

- Orphan struct change without consumers (anti-pattern; "no premature codification")
- Layer 4 v5.14 fixture round-trip stays safe whether upgrade is at `.D` or `.F.4e` (descriptor isn't wire-format), but the cleaner moment is WITH consumers
- Per `feedback_no_defer_for_effort`: this isn't deferring effort, it's right-placing it (the struct upgrade + consumer addition compose as one atomic ship)

### Why DOCUMENT at `.D`

- `.F.4e` planning has the upgrade pre-decided (no re-deriving)
- Sprint state can reference the codified plan
- Future contributors see the upgrade path documented (rather than discovering the uint16_t limit + reinventing)

### Item 7 — Check 10 cohort eligibility Python tool (KEEP per "don't defer" directive)

Per `cfg-flag-eligibility-criteria.md` 5-criteria check + cohort-audit rule (set 2026-05-11):

```python
#!/usr/bin/env python3
# tools/check_cohort_eligibility.py — Check 10
#
# Verifies: every new cfg field passes 5-criteria check (cfg-flag-eligibility-criteria.md);
# cohorts of 2+ siblings audited for harmonization.
#
# Pattern: registry-coverage-ci-check-pattern.md Shape A (positive coverage; runtime variant).
# Sister to tools/check_per_core_registry_integrity.py + tools/check_meta_registry.py.

import re
import sys
from pathlib import Path
from collections import defaultdict

ROOT = Path("/home/caramel/code/FoxML_Trader_v2")

def extract_cfg_rows():
    """Parse FOREACH_PER_CORE_CFG_FIELD + FOREACH_GLOBAL_CFG_FIELD rows."""
    text = (ROOT / "CoreFrameworks/CfgFieldRegistry.hpp").read_text()
    rows = []
    # Match X(KIND, name, label, section, metadata_flags, payload, tooltip, strat_cat, ...)
    for m in re.finditer(r"X\(\s*(KIND_\w+)\s*,\s*(\w+)\s*,\s*\"([^\"]+)\"\s*,\s*\"([^\"]+)\"\s*,\s*([^,]+),", text):
        rows.append({
            "kind": m.group(1),
            "name": m.group(2),
            "label": m.group(3),
            "section": m.group(4),
            "metadata": m.group(5).strip(),
        })
    return rows

def cohort_audit(rows):
    """Group by section; check 2+-sibling cohorts for metadata harmonization."""
    by_section = defaultdict(list)
    for r in rows:
        by_section[r["section"]].append(r)

    drift = []
    for section, cohort in by_section.items():
        if len(cohort) < 2:
            continue
        # If 1+ rows in cohort have STAMP_BOUND_CFG_DERIVED, check that all eligible ones do
        stamp_bound_rows = [r for r in cohort if "STAMP_BOUND_CFG_DERIVED" in r["metadata"]]
        non_stamp_bound = [r for r in cohort if "STAMP_BOUND_CFG_DERIVED" not in r["metadata"]]
        if stamp_bound_rows and non_stamp_bound:
            # Heuristic check: if all stamp_bound rows are ML-cohort, non-stamp-bound should be too
            for r in non_stamp_bound:
                # Whitelist exempt sections (e.g., "Operational" / "Engine Timing" never STAMP_BOUND)
                if section in {"Operational", "Engine Timing", "Tick Recording", "Logging"}:
                    continue
                drift.append(f"  - Section '{section}': '{r['name']}' lacks STAMP_BOUND_CFG_DERIVED but cohort has {len(stamp_bound_rows)} flagged sister(s)")

    return drift

def main():
    rows = extract_cfg_rows()
    drift = cohort_audit(rows)
    if drift:
        print(f"WARN: Check 10 cohort eligibility found {len(drift)} drift(s):")
        for d in drift:
            print(d)
        print("\nFix: audit cohort harmonization per cfg-flag-eligibility-criteria.md.")
        print("WARN-only at .D; promotes to ERROR after .F.4f cleanup sweep.")
        # Don't exit 1 at .D; sprint state allows WARN
        sys.exit(0)

    print(f"PASS: Check 10 — {len(rows)} cfg fields audited; cohorts harmonized.")

if __name__ == "__main__":
    main()
```

**Initial integration:** WARN-only at `.D` (per cfg-flag-eligibility-criteria.md initial deployment). Promotes to build-error after `.F.4f` cleanup sweep harmonizes existing cohort drift.
