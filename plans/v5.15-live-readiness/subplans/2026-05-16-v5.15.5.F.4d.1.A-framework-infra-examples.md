## § Step 1 — `DerivedFilterFramework.hpp` Variant 1 (GUI_ONLY)

### Macro definition

```cpp
// CoreFrameworks/DerivedFilterFramework.hpp
//
// Pattern: metadata-bit-driven-derived-filter-framework.md Stage 3 ACTIVE
// Composes: x-macro-registry-with-presence-dispatch.md
//
// 3 variants: GUI_ONLY (Variant 1) / WIRE_FORMAT (Variant 2) /
//             WIRE_FORMAT_TWO_SOURCE (Variant 3)
//
// v5.15.5.F.4d.1.A — NEW. First framework consumer: StampBoundDerivedFilter.hpp
// via WIRE_FORMAT_TWO_SOURCE variant.
//
// v1.1 revision (Option F): no LOCKED_HASH_VAR / FIXTURE_PATH params on
// Variants 2+3. Generic invariant tests auto-generated per macro expansion;
// domain-specific invariants live in consumer header.

#pragma once

#include <cstdint>
#include <cstddef>
#include "CfgFieldRegistry.hpp"          // CfgFieldDescriptor + g_*_cfg_field_descriptors

// ============================================================================
// VARIANT 1: GUI-only derived filter (cheap; no wire-format machinery)
// ============================================================================
// Use when: consumer walks the filtered rows for GUI presentation
// (collapse, badging, modal confirmation, password-masking) —
// NO HMAC chain, NO byte-preservation requirement.
//
// Example future apps (.F.4e): IS_SECRET → password-masking;
// HIDDEN_BY_DEFAULT → collapsed sections.
//
// Generated symbol (NAME = your filter name):
//   inline void NAME##_walk_filtered_rows(
//       const CfgFieldDescriptor* descriptors,
//       size_t count,
//       void (*per_row_fn)(size_t idx, const CfgFieldDescriptor& d, void* ctx),
//       void* ctx
//   );

#define DERIVED_FILTER_DECLARE_GUI(NAME, SOURCE_FOREACH, METADATA_BIT)        \
    inline void NAME##_walk_filtered_rows(                                    \
        const CfgFieldDescriptor* descriptors,                                \
        size_t count,                                                         \
        void (*per_row_fn)(                                                   \
            size_t idx,                                                       \
            const CfgFieldDescriptor& desc,                                   \
            void* ctx                                                         \
        ),                                                                    \
        void* ctx                                                             \
    ) {                                                                       \
        for (size_t i = 0; i < count; i++) {                                  \
            if ((descriptors[i].metadata_flags                                \
                 & (CfgFieldDescriptor::METADATA_BIT)) == 0) {                \
                continue;                                                     \
            }                                                                 \
            per_row_fn(i, descriptors[i], ctx);                               \
        }                                                                     \
    }                                                                         \
    /* dummy to require semicolon at invocation site */                       \
    static_assert(true, "DERIVED_FILTER_DECLARE_GUI requires semicolon")
```

### Design decision: fn pointer vs `std::function`
Plain C-style fn pointer (`void (*)(size_t, const CfgFieldDescriptor&, void*)`) chosen. H2 forbids `std::function`. Cost: 1 indirect call per matching row (~3-5 cycles); boot-time path, negligible.

### Design decision: void* ctx for caller state
Per-row callback needs caller state (e.g., accumulating canonical body buffer); void* ctx passes typed lambda state. Caller casts at consumer site (cross-layer pattern; see `type-erased-per-core-resource-handle-pattern.md` Stage 2 DRAFT).

## § Step 2 — `DerivedFilterFramework.hpp` Variant 2 (WIRE_FORMAT) + generic invariants

### Macro definition (revised — no LOCKED/FIXTURE params)

```cpp
// ============================================================================
// VARIANT 2: Wire-format derived filter (canonical body emit + invariant tests)
// ============================================================================
// Use when: consumer walks the filtered rows to produce wire-format bytes
// (HMAC chain participation). Generates canonical body emit fn + generic
// invariant test stubs (I1-I5) per wire-format-byte-preservation-discipline.md
// § 5b (revised at .F.4d.1 per Option F: structural invariant tests as
// canonical mechanism; NO LOCKED hash constant; NO fixture file).
//
// Example future apps: AFFECTS_STAMP_PARITY → training cfg stamp.
//
// Generated symbols (in addition to Variant 1 GUI walker):
//   inline size_t NAME##_emit_canonical_body(char* buf, size_t cap);
//      // returns body length (bytes written, excluding NUL terminator)
//   inline void NAME##_run_generic_invariants();
//      // runs invariants I1-I5; uses test framework's check() to assert
//      // each; called from controller_test.cpp test sections

#include <locale.h>                        // uselocale + newlocale
#include <cstdio>                          // snprintf
#include <cstring>                         // memchr (for I3 comma check)

#define DERIVED_FILTER_DECLARE_WIRE_FORMAT(NAME, SOURCE_FOREACH, METADATA_BIT) \
    /* Variant 1's GUI walker is the base; reuse it: */                       \
    DERIVED_FILTER_DECLARE_GUI(NAME, SOURCE_FOREACH, METADATA_BIT);           \
    /* Canonical body emit fn — locale-pinned per Layer 2 discipline */       \
    inline size_t NAME##_emit_canonical_body(char* buf, size_t cap) {         \
        size_t pos = 0;                                                       \
        /* Layer 2 locale pin per ModelInference.hpp:1697 precedent */        \
        locale_t pinned = newlocale(LC_NUMERIC_MASK, "C", (locale_t)0);       \
        locale_t prev = (locale_t)0;                                          \
        if (pinned) prev = uselocale(pinned);                                 \
        /* Walk per-core descriptors first, then global (canonical order): */ \
        struct EmitCtx { char* buf; size_t* pos; size_t cap; };               \
        EmitCtx ctx{buf, &pos, cap};                                          \
        auto emit_row = [](size_t /*idx*/, const CfgFieldDescriptor& d,       \
                            void* ctxp) {                                     \
            EmitCtx* c = static_cast<EmitCtx*>(ctxp);                         \
            if (*c->pos >= c->cap) return;                                    \
            /* At .A landing: empty filter → emit_row never invoked. */       \
            /* At .B+: tt::cfg_emit_synthetic_field<T>(d, c->buf + *c->pos,   \
                                                       c->cap - *c->pos)     \
                       handles per-type deterministic emit. Stub here for     \
                       .A scaffold; .B fills in tt::cfg_emit_synthetic_field. \
                       Stub format: "<name>=stub\n" */                        \
            int n = snprintf(c->buf + *c->pos, c->cap - *c->pos,              \
                              "%s=stub\n", d.cfg_field_name);                 \
            if (n > 0 && static_cast<size_t>(n) < c->cap - *c->pos) {         \
                *c->pos += static_cast<size_t>(n);                            \
            }                                                                 \
        };                                                                    \
        NAME##_walk_filtered_rows(g_per_core_cfg_field_descriptors,           \
                                   FIELD_IDX_PER_CORE_END, +emit_row, &ctx);  \
        NAME##_walk_filtered_rows(g_global_cfg_field_descriptors,             \
                                   FIELD_IDX_GLOBAL_END, +emit_row, &ctx);    \
        if (pinned) {                                                         \
            uselocale(prev);                                                  \
            freelocale(pinned);                                               \
        }                                                                     \
        return pos;                                                           \
    }                                                                         \
    /* Generic invariant tests I1-I5 — encode canonical body intent */        \
    inline void NAME##_run_generic_invariants() {                             \
        char body[8192] = {0};                                                \
        size_t len = NAME##_emit_canonical_body(body, sizeof(body));          \
                                                                              \
        /* I1: line count == flagged-row count (per scalar source) */         \
        size_t flagged_count = 0;                                             \
        auto count_cb = [](size_t, const CfgFieldDescriptor&, void* ctx) {    \
            (*static_cast<size_t*>(ctx))++;                                   \
        };                                                                    \
        NAME##_walk_filtered_rows(g_per_core_cfg_field_descriptors,           \
                                   FIELD_IDX_PER_CORE_END,                    \
                                   +count_cb, &flagged_count);                \
        NAME##_walk_filtered_rows(g_global_cfg_field_descriptors,             \
                                   FIELD_IDX_GLOBAL_END,                      \
                                   +count_cb, &flagged_count);                \
        size_t newline_count = 0;                                             \
        for (size_t i = 0; i < len; i++) {                                    \
            if (body[i] == '\n') newline_count++;                             \
        }                                                                     \
        check(#NAME " I1: line count == flagged-row count",                   \
              newline_count == flagged_count);                                \
                                                                              \
        /* I2: each line matches <name>=<value>\n pattern */                  \
        bool all_kv_format = true;                                            \
        size_t line_start = 0;                                                \
        for (size_t i = 0; i < len; i++) {                                    \
            if (body[i] == '\n') {                                            \
                bool has_eq = false;                                          \
                for (size_t j = line_start; j < i; j++) {                     \
                    if (body[j] == '=') { has_eq = true; break; }             \
                }                                                             \
                if (!has_eq) all_kv_format = false;                           \
                line_start = i + 1;                                           \
            }                                                                 \
        }                                                                     \
        check(#NAME " I2: every line matches <name>=<value> pattern",         \
              all_kv_format);                                                 \
                                                                              \
        /* I3: body contains no ',' decimal separator (Layer 2 locale-pin) */ \
        check(#NAME " I3: locale-pin Layer 2 (no comma decimals)",            \
              memchr(body, ',', len) == nullptr);                             \
                                                                              \
        /* I4: per-row name appears EXACTLY when bit set */                   \
        /* (delegated to consumer header's I7 for two-source case) */         \
                                                                              \
        /* I5: per-core descriptors emit before global descriptors */         \
        /* (verified by emit_canonical_body's walker invocation order;        \
            test asserts vacuously at empty body case; meaningful at .B+) */  \
    }                                                                         \
    static_assert(true, "DERIVED_FILTER_DECLARE_WIRE_FORMAT requires semicolon")
```

### Design decision: invariants encoded as test-section helpers, not auto-fired
The macro DECLARES `NAME##_run_generic_invariants()`; controller_test.cpp test sections CALL it. This gives the test framework control over test naming + failure reporting (vs auto-firing where failures are anonymous).

### Design decision: 8KB body buffer
Per `wire-format-byte-preservation-discipline.md`. `.F.4d.1` projects up to 24+ flagged fields × ~100 bytes = ~2400 bytes; 8KB buffer = 3× headroom. Stack-allocated (no malloc per H1).

### Design decision: stub format `<name>=stub\n` at `.A`
At `.A` ship close zero rows are flagged; emit_row never invokes; body stays empty. Stub format is placeholder for `.B`'s real `tt::cfg_emit_synthetic_field<T>` dispatch. Per-type deterministic values added in `.B`.

### Macro definition (revised — no LOCKED/FIXTURE params)

```cpp
// ============================================================================
// VARIANT 3: Wire-format + bitmap-resident two-source variant
// ============================================================================
// Use when: some flagged fields are bitmap-resident (in a sister
// FOREACH_*_CFG_FLAG registry) rather than scalar in the parent registry.
// Aggregates from BOTH sources; bitmap-bool ternary normalization
// `(get_cfg) ? 1 : 0` preserves HMAC byte-equivalence per v5.14.9.F.2.
//
// First canonical .A: STAMP_BOUND_CFG_DERIVED (14 scalar fields in
// FOREACH_CFG_FIELD + 4 bitmap-resident bools in cfg.ml_cfg_flags;
// counts grow at .B as cohort migrates).

#define DERIVED_FILTER_DECLARE_WIRE_FORMAT_TWO_SOURCE(NAME,                   \
    SOURCE_FOREACH, METADATA_BIT,                                             \
    BITMAP_SOURCE, BITMAP_FIELD)                                              \
    /* Variant 2's wire-format walker + emit + invariants is the base: */     \
    DERIVED_FILTER_DECLARE_WIRE_FORMAT(NAME, SOURCE_FOREACH, METADATA_BIT);   \
    /* Bitmap-source walker (.B activates when ML_CFG_FLAG gains              \
       metadata_flags column; at .A this is a stub): */                       \
    inline void NAME##_walk_bitmap_rows(                                      \
        const ControllerConfig<64>& cfg,  /* canonical F=64 instance */       \
        void (*per_bit_fn)(uint8_t idx, const char* bit_name,                 \
                            int value, void* ctx),                            \
        void* ctx)                                                            \
    {                                                                         \
        /* Stub at .A: bitmap source walking activated at .B when             \
           FOREACH_ML_CFG_FLAG gains 6-arg sig with metadata_flags column.    \
           At .A this is no-op; the walker is declared so the macro           \
           expansion compiles cleanly; .B populates the per-bit dispatch. */  \
        (void)cfg;                                                            \
        (void)per_bit_fn;                                                     \
        (void)ctx;                                                            \
    }                                                                         \
    static_assert(true,                                                       \
        "DERIVED_FILTER_DECLARE_WIRE_FORMAT_TWO_SOURCE requires semicolon")
```

### Design decision: bitmap walker is stubbed at `.A`
Per `metadata-bit-driven-derived-filter-framework.md` § Variant 3, this variant needs `FOREACH_ML_CFG_FLAG` to have a metadata_flags column (6-arg sig). At `.A` the registry is still 5-arg; migration to 6-arg is Item 4 at `.B`. Stubbing at `.A` is correct: macro expands cleanly; bitmap walker compiles but no-ops; `.B` activates by adding the 6-arg sig + STAMP_BOUND_CFG_DERIVED metadata bit to 5 ML_CFG_FLAG rows.

### Design decision: cfg pointer signature uses canonical F=64 template instantiation
`ControllerConfig<64>` is the canonical production F. Alternative (template the walker on F) rejected — macros + templates compose awkwardly.

## § Step 5 — Layer 5b structural invariant tests (Option F)

### Why this exists (Option F context)

Per Caramel's "principle beats registry for ELIMINATING" rule, the LOCKED-constant snapshot mechanism (v1.0 draft) was rejected:
- Magic number in source code
- Class 18 mirror at hash-constant layer (constant ↔ runtime walker)
- Per-cohort manual update toil (6+ updates across `.B`)

**Option F: structural invariant tests encode the intent directly.** Each invariant has a semantic name + meaningful failure message. Tests describe what the canonical body MUST look like; drift fires the specific invariant that broke.

### Generic invariants I1-I5 (auto-generated by framework macro)

Already implemented via `NAME##_run_generic_invariants()` in `DerivedFilterFramework.hpp` Variant 2 (Step 2). The 5 invariants:

| # | Invariant | Mechanism |
|---|---|---|
| I1 | Line count == flagged-row count | Count newlines in body; compare to walker count |
| I2 | Every line matches `<name>=<value>\n` pattern | Per-line `=` separator check |
| I3 | Body contains no `,` decimal separator | `memchr(body, ',', len) == nullptr` |
| I4 | Per-row name appears EXACTLY when bit set | (delegated to consumer for two-source) |
| I5 | Per-core descriptors emit before global descriptors | Verified by walker invocation order |

### Domain-specific invariants I6-I7 (in `StampBoundDerivedFilter.hpp`)

Implemented via `STAMP_BOUND_CFG_run_domain_invariants()` in `StampBoundDerivedFilter.hpp` (Step 4). The 2 invariants:

| # | Invariant | Mechanism |
|---|---|---|
| I6 | Bitmap-resident bits emit as `0` or `1` only | Scan body for bitmap-source-tagged lines; verify value ∈ {0,1} |
| I7 | Per-row presence matches bit-set state for both sources | Enumerate flagged rows from both walkers + verify each appears once in body |

At `.A` landing: both I6 + I7 are **vacuously true** (zero rows flagged; bitmap walker stubbed). At `.B+`: meaningful checks fire as cohort migrates.

### Test section (in `controller_test.cpp`)

```cpp
{

    STAMP_BOUND_CFG_run_generic_invariants();
    // Each invariant logs via check() inside the runner; named output per invariant
}

{
    SECTION("v5.15.5.F.4d.1.A: STAMP_BOUND_CFG domain-specific invariants I6-I7 PASS at empty body");
    STAMP_BOUND_CFG_run_domain_invariants();
}

{
    SECTION("v5.15.5.F.4d.1.A: Locale-pin Layer 2 byte-preservation");

    // Save current locale state
    locale_t prev = uselocale((locale_t)0);

    // Simulate LC_NUMERIC=de_DE (would emit "1,5" instead of "1.5" if unpinned)
    locale_t de = newlocale(LC_NUMERIC_MASK, "de_DE.UTF-8", (locale_t)0);
    if (de) {
        uselocale(de);
        // emit_canonical_body should pin LC_NUMERIC=C internally
        char body[8192] = {0};
        size_t len_under_de = STAMP_BOUND_CFG_emit_canonical_body(body, sizeof(body));
        bool no_comma_under_de = (memchr(body, ',', len_under_de) == nullptr);

        uselocale(prev);
        freelocale(de);

        check("body has no comma under simulated alternate locale (Layer 2 pin works)",
              no_comma_under_de);
    } else {
        check("locale simulation skipped (de_DE.UTF-8 not installed)", true);
    }
}
```
